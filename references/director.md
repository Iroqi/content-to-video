# 第 3 步 · SVG 导演（`director` / `evolve` / `derive`）

**什么时候该动、动多快** → `references/motion.md`（四职务、三条减法、节奏、入场、两档动画的选档）。本文件只讲**怎么写那几条 step**：`director` / `evolve` / `derive` 共用同一套锚点语义，写一次就够。写 `director` 的 SVG 由 `_svg_sanitize` 净化后内联进交付 HTML，再由 GSAP 按句驱动；可跑的 images.json 片段见 `motion.md`「SVG 动画：两档」末尾。

**先决定用哪张编排**——三张只差"这页要不要交出版面"与"中间态要不要真几何"：

| 编排 | 编排权 | 机位 | 中间态 | 什么时候用 |
|---|---|---|---|---|
| `director` | 接管整页（标题、句子流、配图入场都让位） | 可调 | 属性插值 | 整页画布上的一次完整演出、跨段接续 |
| `evolve` | **不接管**，只叠在图内元素上（槽位页照旧） | 不可调 | 属性插值 | 图要变，但读者得跟着字幕读 |
| `derive` | 不接管 | 不可调 | **每帧按参数重算** | 一个连续量驱动多个元素（角度、比例、进度） |

**每条 step 的键**（`director` / `evolve` 共用；`derive` 的 `steps` 只多一个 `param`）

| 键 | 规则 |
|---|---|
| `at` | 该段第几句（0 基，小数 = 句内偏移）。整数准、小数线性猜（无词级时间戳，实测最大偏 1.2 字≈0.15s）；超 5s 的长句会放大到 1s 量级——拆句。精确卡首拍用 `at_time: <onset+0.05>`，定位用 `silencedetect` |
| `at_time` | 与 `at` 二选一（都写/都不写报错）。数字 = 段内绝对秒，`"+N"` = 上一条之后 N 秒。**与语音无绑定**，改句长/动 `--gap` 会整体错位且不报错——只留给不跟旁白的拍 |
| `target` | 图内单个 `#id` 或 `.class`（作用域收到 `#img-<sid>`），不收逗号/后代/伪类。**落空不报错、只是静默没动画**，生成期按文件拦成 error |
| `draw` / `morph` | `draw` 描边自绘（目标必须带 stroke，收起态写在段起点，否则切页第一秒线先亮满再缩）；`morph` 同拓扑 path 形变（命令序列与每命令数值个数一致，`from` 必须等于 SVG 里的 `d`） |
| `set`/`to`/`from` | GSAP 补间变量，三者至少一个。只收 JSON 可序列化值，非 CSS 属性走 `attr:{}`（**必须是对象**：标量写法跨段烘焙时会当 CSS 属性写进 `style`）。禁一切 `on*` 回调 |
| `count` / `type` | `count` 数字滚动（`to`/`from`/`decimals`/`prefix`/`suffix`，target 指 `<text>`；console 探针用 `tl.seek(t, false)`）；`type` 逐字揭示，只认 `{}`，读 `<text>` 现成文本 |
| `stagger` | 配 `.class` 目标错峰揭示；只对有补间的 step 生效 |
| `duration`/`ease`/`delay` | 缺省取模板 `animation.director`；**只能写 step 级**，塞进补间变量会被拒 |
| `repeat`/`yoyo` | `repeat:N` = 再演 N 遍（`-1` 是 error），只有真会演的步能配；跨度按 `duration × 遍数` 算 |

生成期还查三件事（`_timeline.beat_positions`）：落点在本页可见窗外 → warn（窗外等于没演）；压在句间/段尾静音上不报（那是节奏）；起点在窗内而终点越过下段 → warn（被切在半路）。**觉得不同步**用 `gen_hyperframes.py … --beat-report` 逐拍列绝对秒与踩点（`in` 句内 / `gap` 句间 / `tail` 段尾 / `before`·`after` 窗外），别改代码。

**六个够用的"演"**（逐句推进＝一步挂一句点亮节点，不单列）：

- **运镜**：要动的场景包进 `<g id="cam">`，补间 `scale`/`x`/`y`；未写 `svgOrigin` 时渲染器钉本页 `#cam` 并集中心（运行期、接续烘焙、出画 warn 同一原点）。`#cam` 里只放主视觉，标题与结论句留外面。留白按**推完那一帧**算：`director_prepare` 按收尾位投影回画幅，出画打 warn（不上 error），但不判"撞字"。**两层视差**同法：背景 `scale:1.05`、主视觉 `scale:1.3`，同 `svgOrigin`。
- **自绘 / 数字 / 逐字**：`draw:true` + `stagger` 错峰，不必手写递增 `at`；数字滚动与逐字揭示用 `count` / `type`。
- **自由场景**：`layout:"canvas"` 不生成标题层与句子流，整屏是可编排舞台——**第一拍尽早落子**（0.1s 量级），否则切过来是空画布（生成期按"起始帧全空"盯着）；晚于段起点也行，渲染器在段起点给带 `from` 的目标前置一次 `tl.set`，不改节拍。
- **形变 / 立体感**：同拓扑 `morph` 表达 A 态到 B 态；立体感手算投影多边形 + `morph` 串姿态——不上 three.js，产物必须仍是可解析 SVG。
- **呼吸 / 聚光 / 歪元素**：呼吸用一条步配 `repeat`/`yoyo`、`duration` 0.4~0.7s、遍数写死；聚光压暗对照组比点亮主角省——要的是亮度差。歪就给元素 `rotation:-4`，别转相机（整页连文字一起斜＝页面坏了）。

### 槽位版式的演进（`evolve`：图跟着话变，版面不动）

槽位版式的图默认是 `<img>`——旁白讲到第三个状态，图还停在第一个。整页画布能演，但要交出版面。第三条路：**留在槽位，只让图里的元素跟着旁白演进**。images.json 里给该段写 `evolve`，结构就是把 `director` 那段的键名换掉、steps 一字不差：

- **steps 写法与 `director` 一样**（同一张键表），同样净化内联、按句驱动、逐帧可复现。区别两条：**不接管编排**（标题、句子流、配图收拢、Ken Burns 照旧，只叠在图内元素上）；**图里不调机位**（`svgOrigin` / `scale` / `rotation` 契约层报错，镜头归模板，要整页推镜请换 `layout:"canvas"` 写 `director`）。
- **起点态取图上的静态值**：`{"to": {"opacity": 0.35}}` 读作"从当前可见压暗到 0.35"，不是"从无到有"（要后者显式写 `from`）——配图落位那半秒因此不会是一块空框。
- **与 `director` 同段互斥**，与 `stage:"keep"` 也不组合：按段独立，每段从同一张图的静态初态起演。体检同一套：target 落空（error）、调机位（error）、起始帧全空（warn）、节拍出窗（warn）。
- **什么时候用**：这一页有一张图要**变**（数据在长、状态在换、对象在转移），但读者需要字幕跟着读；整页都该重新构图的，那是 `director`。

### 参数演绎（`derive`：一拍推一个量，几何自己算）

`director` / `evolve` 的补间是**属性级**的：三个元素一起动就写三条，同步全靠作者手抄（抄错一条就是"说着同步、看着脱节"），中间态还是插值——指针从 A 到 B 走弦，不走圆弧。`derive` 补这一层：场景有**一个主参数**（把 θ 从 0 转到 2π），几何全由它算。

```json
{"seg2": {"src": "images/seg2.svg", "derive": {
  "params": {"theta": 0},
  "steps": [{"at": 0, "param": "theta", "to": 90, "duration": 1.6}],
  "bind": [{"target": "#tip", "attr": "cx", "expr": "490 + 260*cos(theta*pi/180)"}]}}}
```

- **`params`**：参数名 → 初值。名字要能直接当标识符（字母/下划线开头，≤32 字符）——它同时出现在表达式里、进 JS 变量表。**SVG 静态值要与初值对齐**（`#tip cx="750"` 而 `theta=0` 也算出 750），否则第一拍前画面跳一下，生成期打 `[warn]` 报差值（`transform` 与 class 多元素目标不比对）。
- **`steps`**：一拍只写"把哪个参数推到多少"。`duration` **必须 > 0**（写 0 等于瞬跳，契约层直接拒）。**多拍累进**：后一拍的起点是前一拍的终值（写了 `from` 则以它为准）——"先转到 90°、第二句再转到 180°"就是两条 step。
- **`bind`**：一条绑定算**一个属性**。`attr` 只收几何属性：`x y cx cy r rx ry x1 y1 x2 y2 width height transform`；`d` / `points` 是复合几何，颜色与透明度归 `director`。
- **表达式**：算术 `+ - * / % ^ **`（`^` 乘方、右结合）、常量 `pi tau e`、白名单函数 `sin cos tan asin acos atan sqrt abs floor ceil round exp log min max pow`、声明过的参数。**别的都不收**：没有属性访问、下标、lambda、字符串、`random` 或时间函数（逐帧 seek 下不确定的两帧就对不上）。上限 240 字符；解析器自写 tokenizer + 递归下降，**不用 `eval`**，生成期就编译成 JS 字面代码。
- **中间态是真几何**：每帧按参数真值重算 `bind`，不在路径间插值——θ=45° 时尖到圆心**仍是 260**（走圆弧；属性级补间走弦会短一截，观众说不上哪里怪，只觉得"不像在转圈"）。属性只由 `(时刻 → 进度 → 参数 → 表达式)` 决定，无状态无缓存；渲染端是一条代理补间（每拍一个 0→1 的进度变量，`onUpdate` 重算全部绑定），"三拍串联"天然接着走。
- **可与 `director` / `evolve` 同段共存**（一个管出场、一个管连续演绎），但**同一属性不能两边都写**——两边都写时先写的白写、谁后写看脚本挂载顺序，生成期按 error 点名。
- **体检清单**（`_derive_prepare`）：target 落空、同属性冲突、`at` 越界、端点算不出来（除零/定义域外，那一帧 `onUpdate` 一抛后面全不演）——四条 error；节拍出窗、初值不一致——两条 warn。

**什么时候用它**：图上有一个**连续量**在驱动多个元素——角度、半径、比例、进度、坐标（圆的参数化、向量分解、函数图像上一点跟着走、比例条同步伸缩）。只是"元素从 A 变到 B"用 `evolve`，整页重新构图用 `director`。
