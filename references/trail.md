# 第 3 步 · 残影档：让一帧里有多张时间回声

**"演什么"在第 1 步就定了**（`beats` 写在稿件里）。这一档只答一件事：当这一拍要「快得留下痕迹」，而不是「一个东西从 A 走到 B」，怎么写。画图 → `references/canvas.md`；入场 → `references/look.md`；该不该动 → `references/motion.md`。

## 一、对标：前沿在打的是「每帧只有一个状态」

2025/2026 的前沿 MG 有一支很一致的语言，几份独立来源说的是同一件事——

| 来源 | 点名的手感 | 落到画面上是什么 |
|---|---|---|
| ACM SIGGRAPH MIG'25《Trajectory-aware Smears for Stylized 3D Animations》 | elongated in-betweens / smear frames 被当成正式运动语言（Spider-Verse、Arcane 那一支）；沿轨迹拉长的中间画 | 一帧里同时读到一个物体的几个相邻时刻 |
| DEmotion《Five Motion Graphic Styles》2026 | "Motion trails are created by duplicating a layer multiple times, offsetting each duplicate slightly in time, reducing the opacity of each subsequent copy"，典型 2–5 帧间隔 | 同形副本、逐层滞后、逐层降透明度 |
| ReelMind《Smart Video Time Echo: Ghosting and Trailing》2025 | ghosting / trailing 从压缩瑕疵翻成叙事工具；frame delay algorithms、user-adjustable decay rates | 时间回声、可调衰减、只在高速区出现 |
| VHS 合成波风格实现解析（2025） | YIQ 色度按 9 帧指数衰减取样产生真实拖影 | 一串指数衰减的过去帧叠在同一帧上 |
| Adobe / Canva 2026 设计前瞻 | 动能字体 "Fast can stretch through motion blur"；intentionally imperfect | 速度本身成为可见的材料 |

把这一叠词翻成工程语言，是三个约束：**同时可见**、**起止干净**、**逐帧可复现**。第三条是本仓库的硬纪律，前两条是这套体系从没做过的。

## 二、域地图：时间叠加一直是空的

先看已有档位各自消费了哪个「域」：

| 档 | 消费的量 | 一帧里有几个状态 |
|---|---|---|
| `to` / `morph` / `draw` | 位置 / 形状 | 1 |
| `spring` | 阻尼 | 1 |
| `momentum` | 速度包络（做形变） | 1 |
| `drag` | 相位（多个**不同**元素共享一条曲线） | 每个元素各 1 |
| `step` | 时间量化（**一张画占几帧**） | 1 |
| `hold` | 静止 | 1 |
| `stagger` / `decode` | 时序 / 锚点 | 1 |
| `arc` | 空间曲率 | 1 |
| `organic` | 值域不规则 | 1 |

它们有一条从没被写破的共同前提：**每个时刻，一个主体只有一个状态**。即使 `drag` 让一条链同时可见，链上每一节也是不同的真实元素、各自演一条自己的曲线；即使 `step` 让一张画停 K 帧，那一帧里也只有一张画。

`step` 与这一档正好互为镜像：`step` 把「一帧一张画」变成「一张画占几帧」（减少每帧的新信息），`trail` 把它变成「一帧里有多张画」（增加每帧的可见状态）。两者都在时间域动手，方向相反，所以互不替代也不叠加。

最接近「残影」的既有写法有三条，但都不成立：

- `repeat` / `yoyo` 是**顺序重放**，不是同时叠加；而且它把落定演成「又冲一次」。
- `stagger` 是一组元素**各自完整演一遍**，观众读到的是「逐个出现」，不是「同一个主体的过去」。
- `drag` 的链是**不同真实元素**沿相位传一条波，且全链重参数化后一起落定；残影要的是同一形状的时间副本，永远不该追上现在。

**所以这一档不是「第十二条位移曲线」，是补上第一个时间叠加域。**

## 三、几何：回声 → 速度门 → 端点

难点不是「复制几层」，而是**逐帧可复现**：本技能明确禁 `random` / `time`（见 `references/motion.md`「参数演绎」），AE 的 Echo 效果、运行时 `onUpdate` 叠影、低通滤波式拖尾都带内部状态，第 N 帧与直接跳到第 N 帧就对不上。解法是把每一层都写成 `t` 的**纯函数**：

```
u   = t / D                                    主体进度（时刻先夹回 [0,D]）
f   = curve(ease)                              钉固的无过冲缓动，f(0)=0, f(1)=1
主体  x₀(t) = distance · f(u)
影子  uᵢ = clamp((t − i·lag)/D, 0, 1)          i = 1..K，**不重参数化**
      xᵢ(t) = distance · f(uᵢ)            ← xᵢ(t) = x₀(t − i·lag)  时间回声恒等式
W(u) = sin²(πu)                               端点窗口：W(0)=W(1)=W′(0)=W′(1)=0
G(u) = W(u)·f′(u) / max[W·f′]                 速度门：端点精确归零、峰值归一到 1
      oᵢ(t) = decayⁱ · G(u)                   整串共用一个门，层间只差 decayⁱ
```

`f′` 由中心差分取得（不另写一份解析曲线）；`G` 的峰值在生成期扫一次算死，所以第一层影子最亮约等于 `decay`（相对静态可见的主体 `opacity=1`），后面按 `decayⁱ` 递减。把窗口与速度各自归一再相乘是踩过的坑：两个门叠成 0.14 量级，影子暗到看不见——**归一到峰值 1 才是「门」，不是两级衰减**。

三条设计决定，都是被成片纪律逼出来的：

**1. 故意不重参数化。** `drag` 必须把局部进度除以 `(1−φᵢ)`，否则链尾永远停在半路、全链不能一起落定；残影恰好相反——它是**过去**，永远不该追上现在。若也做重参数化，`xᵢ(D)=distance`，落定那一帧仍有 K 张画叠在主体上，读成一坨实心影子而不是速度感。这是两档最本质的分界，也是唯一能让「收尾时影子全部隐去」成立的做法。

**2. 速度门控整串、衰减只管层间。** `G` 只由主体当前时刻决定：起步那一瞬 `uᵢ=0`，影子与主体重合、门为 0，本来也不该看见；主体跑起来门开到峰值，一串影子才拉开；落定时 `W` 与 `f′` 一起收零，影子同时收干净。若让每层各自读 `G(uᵢ)`，层间大小就不再只由 `decay` 决定，「逐层递减」这条判据会随 ease 漂移。

**3. 端点窗口而不是淡入淡出。** `W=sin²(πu)` 让 `oᵢ(0)=oᵢ(1)=0` **精确**成立：切过来不会先挂一串影子，页界处也不会把残影留给下一段。主体本身有终点位移，所以这一档不像 `organic` 那样「收尾态 = 起始态」，跨段接续仍需显式折一次（见第七节）。

**生成期采样成离散 `tl.set`**，沿用 `morph` / `momentum` / `drag` / `step` / `organic` 的老路：渲染端零脚本、零 `onUpdate`、零依赖，`ease` 只在生成期读，成片里是一串确定的数值，逐帧 `seek()` 下每一帧都是时间的纯函数。

**影子必须是图里真实存在的元素**：离散 `tl.set` 没法凭空造 DOM，也不该在渲染端克隆节点（同一张 SVG 内联两份时，图内 id 重复、`url(#id)` 只认第一份，见 `references/motion.md`「跨段接续」）。所以 `ghosts` 收一列有序 `#id`，由作者在图里画好同形副本并静态写 `opacity="0"`；生成期按文件逐个拦，落空一层就是「这条拖尾短了一截」而不是报错。

**红线**（写死在 `_trail.py`，不进模板、不给 `--set` 改）：影子层数 2～6；层间滞后上限 0.25s，且不得小于一帧（24fps 下 0.0417s）；可见度衰减比上限 0.85；总滞后 ≤ 拍长 75%；最短拍长 0.12s（帧时刻锁两位，短于此会让两个采样撞进同一格、静默少一帧）；`ease` 只收无过冲、终点速度归零的 `out` / `inOut` 档。

## 四、被否掉的五个方案

| 方案 | 为什么不收 |
|---|---|
| **AE Echo / 渲染端 `onUpdate` 叠影** | 带累计状态，逐帧 `seek()` 下第 N 帧与跳到第 N 帧对不上；Python 侧判据只能退化成对着另一份 JS 自证（`decode.md` / `spring.md` 记过这笔账）。 |
| **GSAP `repeat` + `stagger` 伪造一串副本** | repeat 是顺序重放、stagger 是各自起跑，两者都给不出「同一时刻同一个主体的几个过去」。而且重放会把落定演成又冲一次。 |
| **把 `drag` 的链当残影用** | 链上每一节是不同的真实元素、各自有行程，且重参数化后全链一起落定——落定那一帧 K 个形状叠在一起，正是残影最显眼的错。相位与曝光是两个域。 |
| **CSS `filter: blur()` / `box-shadow` 拖影** | 模糊是空间卷积，不沿轨迹、不随主体速度变化；而且它把「快」读成「糊」，前沿要的是离散的时间副本。 |
| **渲染端自动克隆 DOM 造影子** | 同一张 SVG 在接续页内联两份，克隆出来的 id 会重复，图内引用只认第一份；克隆还把「哪些元素在演」藏进生成期黑箱，契约层与按文件拦都失效。另有一条实测过的静默错：作者手改 `ghosts` 落空时成片只是短一截，零报错。 |

另外试过、又删掉的一条判据：在产物上做**自相关 / 频谱**去证明「影子是延迟副本」。短拍里主体走的是 `power3.out`，前段极快、后段几乎不动，逐帧位移本身就高度自相关，纯延迟与「各自独立的相似曲线」在 20 帧内分不开。最后改成直接读**时间回声恒等式** `xᵢ(t) = x₀(t − i·lag)` 的残差（恒为 0）——这是结构性事实，不靠在短信号上做谱分析。

## 五、契约与旋钮

一拍写 `trail`，整段负责主体与全部影子。六个旋钮：

| 键 | 默认 | 读什么 |
|---|---|---|
| `ghosts` | 必填 | 2～6 个有序 `#id`，图里画好的同形影子副本，静态写 `opacity="0"` |
| `axis` | 必填 | `"x"` / `"y"`，主体与影子共用的位移轴 |
| `distance` | 必填 | 主体行程（SVG 用户单位，非零） |
| `lag` | `0.08` | 每层错开多少秒；24fps 下约 2 帧，前沿工作流的 2–5 帧口径 |
| `decay` | `0.62` | 逐层可见度比；第一层最亮约 `0.62`，第三层约 `0.24` |
| `ease` | `"power3.out"` | 主体主运动曲线；速度门由它的导数给，只收无过冲的 `out` / `inOut` |

```json
{"seg2": {"src": "images/seg2.svg", "animate": {"steps": [
  {"at": 0, "target": "#hero", "duration": 1.2,
   "trail": {"ghosts": ["#g1", "#g2", "#g3"], "axis": "x", "distance": 320,
             "lag": 0.08, "decay": 0.62, "ease": "power3.out"}}
]}}}
```

图里要有一组同形元素，`#hero` 静态可见、`#g1`~`#g3` 静态写 `opacity="0"`，四者起始坐标相同：

```svg
<g id="hero"><rect x="10" y="300" width="40" height="40"/></g>
<g id="g1" opacity="0"><rect x="10" y="300" width="40" height="40"/></g>
<g id="g2" opacity="0"><rect x="10" y="300" width="40" height="40"/></g>
<g id="g3" opacity="0"><rect x="10" y="300" width="40" height="40"/></g>
```

**没有拍级 `ease`**：这一档的缓动写在 `trail.ease` 里，它同时决定主体轨迹和速度门；拍级 `ease` 会被渲染端忽略，契约层也不收。step 级 `duration` 照常从模板 `animation.animate` 取或拍级覆盖，它决定整段有多长、也决定采样帧数。

**互斥**：`trail` 与 `from` / `to` / `set` / `draw` / `morph` / `count` / `type` / `momentum` / `drag` / `step` / `organic` 同拍即 error——两条时间线抢同一条 transform 通道，GSAP 后写的那条静默覆盖前一条。不收 `stagger` / `repeat` / `yoyo`（一条拖尾不拆、不重放），不能打在 `#cam`（相机层归整页取景），`ghosts` 不能含 step 级 `target` 自己或 `#cam`。

## 六、生成期会拦什么

| 现象 | 级别 | 怎么消 |
|---|---|---|
| 未知键 / `ghosts` 数量或格式越界 / 重复 id / `axis` 非法 / 距离为零 | error（契约层） | 只认六个键；红线见上一节 |
| `ghosts` 含 `target` 自己或 `#cam` | error | 主体由这一拍自己驱动；相机层给折层 |
| 与别的「演」同拍 / `stagger` / `repeat` / `yoyo` 挂在 trail 上 | error | 删掉一边；要一条链用 `drag`，要逐个出现用 `stagger` |
| `lag` 小于一帧 | error（生成期） | 加长 `lag`，否则两层撞进同一渲染帧、读成一张叠影 |
| 总滞后 > 拍长 75% | error（生成期） | 调小 `lag` 或加长这一拍；否则最后一层到落定还几乎没动过 |
| 拍长 < 0.12s / 帧时刻撞进同一个 0.01s 格 | error（生成期） | 加长 `duration`；否则产物静默少一帧 |
| 影子在 SVG 里找不到 | error（生成期） | 按文件逐个拦；落空一层只会静默少一段拖尾 |
| 时间回声恒等式被破坏 / 影子跑到主体前面 / 逐层没严格递减 | error（生成期） | 生成期自查会拦，正常配置不会出现 |
| 端点没把影子收干净 | error（生成期） | 端点窗口保证精确归零，正常配置不会出现 |

## 七、判据落在哪

`tests/test_trail.py` 一个文件压完，判据全部**从产物里抠补间来读**，不在 Python 侧另写一份「应该生成什么」的实现。

| 组 | 钉住什么 |
|---|---|
| 信号 | 纯函数（正序/逆序/乱序一致、窗口外夹回端点）、时间回声恒等式残差恒为 0、端点精确归零、速度门峰值归一到 1 与逐层 `decayⁱ` |
| 轨迹 | 影子永不追上主体（故意不重参数化，收尾仍严格在主体身后）、层序与选择器、主体只写位移而影子多写一条 opacity |
| 网格 | 采样带两端、帧时刻严格递增且不撞 0.01s 格、条数 = (帧数+1)×(层数+1)、lag 一帧地板与总滞后红线 |
| 契约 | 红线、与十一种「演」互斥、不收错峰/重放、相机层与自指影子、绕过契约层的坏值在生成期炸 |
| **产物级对账** | 从 HTML 抠出的 `tl.set` 序列，锚点、帧数、逐层选择器与逐帧变量必须与 `_trail.frames` 逐项相等；两画幅各验，两次生成字节相同 |
| 作用域与接续 | 没写 trail 的页零新增补间；接续页主体折到 `distance`、**每个影子只折 `opacity:0`**，不出声 |

最后一条是本档独有的跨页错：速度门在上一页收尾时归零是**运行期补间**写进去的，静态 SVG 副本里根本没有这份归零。不显式折一次，接续页第 0 帧就挂着一串影子，直到本段第一条补间才收掉——页界一次静默的闪，生成期零报错。与 `references/drag.md` 里「只折链头时链尾弹回原位」是同一类错。影子的 `x`/`y` 不折：它们不可见，位置由下一段自己的第一帧接管。

## 八、什么时候不要

- **这一拍要「到位停住」**：用 `.out` 档或 `spring`。残影档收尾时主体确实精确落位，但整段都在带着一串影子跑，安静的落位不该有拖尾。
- **要的是「一张画停几帧」的手作节奏**：用 `references/step.md` 的定格档——那是时间域的量化，跟本档的时间叠加方向相反，别叠。
- **一组元素要逐个出现**：用 `stagger`；要主体带动一条真实元素的链，用 `references/drag.md` 的拖曳档。
- **要「不规则但可复现」的呼吸 / 漂浮**：用 `references/organic.md` 的有机档；它动的是值域，本档动的是每帧的可见状态数，两者正交。
- **文字 / 数据图**：本档只写 `x`/`y` 与 `opacity`，逐字揭示与数字滚动各有自己的整段语义；给标题挂三层残影会把可读性一起拖没。
- **只想让画面轻微持续活动**：先问 `--perceptual` 的四道验收够不够；一屏同时动的不超过三处，别给每个元素都挂一串影子。
