# 第 3 步 · 动静对比：静止窗口与 hold 慢推

`beats` 决定这一页演什么 → `references/motion.md「一、该不该动」`；落位曲线怎么选 →
`references/motion.md「曲线的行程预算」`；跨页怎么接 → `references/motion.md「场景相连：页界不留主体真空」`。
**这一份只管落位之后到换页之前那段时间**：什么时候该全静，什么时候该让画面继续活
着，以及凭什么说它真的动了。

这是代码绘制的 motion graphics 里最容易被略过的一层。大家盯着曲线、弧线、弹簧、
错峰，成片却仍像"一页页 PPT"，缺的往往不是曲线，是**时间结构**——快切之后留不
住，hold 期间又真的死成一张静帧。

## 一、对标：缺的是时间结构，不是又一条曲线

逐帧可复现的动效里，节奏对比反复被点名的三条：

| # | 原则 | 一句话 | 本仓库此前 |
|---|---|---|---|
| 1 | 快切对抗停顿 | 密集的入场之后要有一段什么都不动的留白 | 入场阶梯已成，留白**没有** |
| 2 | 揭示前静止 | 重要揭示前留 300~600ms，让眼睛先读清这一屏 | 无 |
| 3 | hold 期间 2% 慢推 | 保持段用极慢的推镜维持"活着"，不是死帧 | 明确禁止（见 `references/look.md「动画：实现要点」`） |

第 3 条此前被否，理由是对的：`look.md` 量过，4%~8% 的持续推近会把 `cover` 之外
的内容再放大一截，SVG 正文贴着画布边缘时配文被推出槽位。**但"不要大幅推近"不等于
"一帧不动"**。这两件事被同一句话打包禁掉，代价落在
`references/look.md「观感门禁：这一页在屏幕上到底有没有东西」` 的 `dead_seconds`
上：旁白还在讲第二、第三件事，画面从落位那一刻起就是静帧。

所以本轮不是撤回那条禁令，是把它**拆成两个可分别判定的量**：幅度有上限（2%，
留在安全边距内），时间有结构（先静后动）。原先"不动"是唯一能守住边缘的办法，
现在不是了。

## 二、可测量口径：这一帧主视觉在不在动

上一轮的 brainstorm 把这件事列为待办，并点明难点：得先在产物上定义"这一帧有没有
新增动的元素"的可测量口径。**按"同时在动的元素数"数是走不通的**——慢推期间永远
只有一个元素在动（主视觉），数元素区分不出"入场"与"hold"，也区分不出"静止"与
"几乎没动"。

改量**主视觉的单帧变化量**：`Δscale(t) = |scale(t + 1/fps) − scale(t)|`。

| 档 | Δscale 的量级 | 读者看到什么 |
|---|---|---|
| 入场落位 | ≥ 4px 位移（980px 槽位上 ≈ 0.0041） | 一次明确的到位 |
| hold 慢推 | 峰值 ≤ 入场的 1/4，且处处 > 0 | 画面还在呼吸，但没在"演" |
| 静止窗口 | 恒 0 | 这一屏停住了，可以读 |

三档用同一个量、同一把尺，于是"该静的地方静了""该动的地方真动了""慢推没变成
第二次入场"三句话都能被门禁钉住，而不是靠翻 contact sheet 时的印象。解析上界
（不是抽样最大值）由 `_hold.max_step_bound` 给出：`sine.inOut` 的 `max f′ = π/2`，
单帧上界 = `amp · π/2 ÷ (duration · fps)`，它必须 ≤ 入场首帧的 **1/4**。

**这个 1/4 是反解出来的，不是拍的。** 早先一版写"比入场慢一个数量级"（1/10），
按 24fps、2% 幅度反解需要 `duration ≥ 3.21s`——连默认那份 3.12s 的保持段都过
不了，慢推整层会被自己的判据关掉。把"慢"当成"几乎不动"，读到的仍是一张静帧。
改成 1/4 后下限落在 1.28s：短段自动跳过，正常段留得住，且慢推峰值仍只有入场
首帧的 1/10 量级（实测 0.000425 vs 0.0041）。**最短窗口因此不写进模板**，由
`_hold.min_drift_duration` 从幅度、帧率、缓动算出来；写死一个秒数，换帧率时就
会静默失守。

还有一处边界要归清楚：跨在静止窗口末尾的那一帧**算慢推**（终点已经在动了），
按起点归类会把它记成"静止窗口没空出来"，判据恒红一条假阳性。

旧行为（落位到换页全程静帧）在这个口径里是整段 Δ=0——判据要能同时证明新行为
"动过"、旧行为"没动"，这条反证不能省。

## 三、窗口几何：先静、后慢推、末帧留白

三个时刻全部取现成的时间轴锚点，不在这一层重推一遍：

```
t_settle = card.s + _entrance_lead        # 收拢补间的终点（入场收尾）
t_still  = t_settle + 0.45s               # 静止窗口末尾 = 慢推起点
t_end    = card.win_start + card.vis − 1帧 # 可见窗口末尾前留白
下限 = max(0.30s, amp·max f′·4 / (fps·(4px/980px)))   # 24fps 下 1.28s
t_end − t_still < 下限  →  整段不慢推
```

- **静止窗口 0.45s**（合法带 0.30~0.60s）：`t_settle → t_still` 之间主视觉一条
  补间都没有。不是"补间幅度为 0"，是**不生成补间**——幅度 0 的 tween 仍会占住
  元素的 transform 通道，与收拢、跨段接续抢同一条属性。
- **慢推 `1 → 1.02`**：一条 `tl.to`，`sine.inOut`，只写 `scale`。起点接住收拢的
  `scale:1` 终态，GSAP 按时间线顺序承接，不需要把起点再写一遍（写第二份就是漂移
  的开始）。
- **末帧留白**：可见窗口是半开区间，补间结束态压在右端时那一帧永不渲染，不报错、
  只是少一拍。留一帧让 `1.02` 真的落到画面上。
- **短段整段不慢推**：下限取 `minDriftSeconds` 与反解窗口的较大值。余量不足时
  一条 0.1s 的推镜只有两三帧，读到的不是"活着"是"卡了一下"；短段宁可安静地
  停住——这也是"快切对抗停顿"该有的样子。

**作用域与收拢同集合**（`_still_image_carrier_sid`）：

| 页面 | 慢推 | 理由 |
|---|---|---|
| 槽位版式静态图 | 有 | 模板管这块主视觉，且只有 `scale` 一个合成层通道 |
| 并置对比两格 | 每格一条 | 两格同起点同时长，仍读成一整块 |
| 整页画布 | 无 | 画面归作者，在 SVG 里自己演；模板没有合法补间目标 |
| 接续页 | 无 | 这一页的第一帧必须精确等于上一页的收尾态 |
| 视频 / 写了 `animate` 的内联 SVG | 无 | 已有自己的运动，别叠两层 |
| 开屏 / 结尾 agenda 卡 | 无 | 本来就是"停在那里让人读"的一屏信息，动了反而干扰 |

## 四、被否掉的四个方案

**A. 常驻 CSS 动画 / `repeat:-1` 的呼吸循环。** 最像"让画面活着"，也最错：墙钟
动画与口播无关、逐帧 `seek()` 下不可复现，`repeat:-1` 还会把 GSAP 总时长撑到
`1e10`（预览进度条、按时刻取帧一起坏）。仓库对这一类的判据在
`references/look.md「三条换版式时会坏的」`。

**B. 把慢推做成入场补间的延长（收拢直接落到 1.02）。** 省一条补间，但没有静止
窗口：观众读到的是"一次没停稳的二次入场"，正是原则 1 要消灭的。而且收拢的落点
不再是精确值，跨段接续、边缘安全全跟着变。

**C. 用"同时在动的元素数"当活动度口径。** 见第二节：一个元素在动时，它分不出
入场、慢推与几乎静止，判据恒为真。

**D. 幅度给到 4%~8% 的"看得见"的推近。** 实测会把贴边的配文推出槽位
（`references/look.md「动画：实现要点」` 有账）。2% 只从两侧各裁掉约 9.8px，
在安全边距内；再大就不是慢推，是又一次入场。**慢推的价值在"持续"，不在"幅度"**。

## 五、契约与旋钮

没有新的稿件键，也没有 `--ctv-*` 令牌：这是模板行为，作者不写任何东西就生效。
四个旋钮都在 `_template.py` 的 `animation.hold`，`--set animation.hold.scale=0`
是明确关掉这一层。

| 旋钮 | 缺省 | 管什么 |
|---|---|---|
| `stillSeconds` | `0.45s` | 落位之后留多久全静（红线 0.30~0.60s） |
| `minDriftSeconds` | `0.30s` | 别切半条推镜的地板；实际下限还会被判据反解的窗口抬高 |
| `scale` | `0.02`（2%） | 慢推幅度，上限 0.02；写 0 关掉 |
| `ease` | `sine.inOut` | 只收无过冲的 `inOut` 档 |

红线（窗口带、幅度上限、末帧留白、缓动族白名单）在 `_hold.validate`，**不放进
模板**：`--set` 能把观感旋钮调坏，所以护栏必须在消费侧。写法 `spring(0.85)`、
`back.out(1.7)`、`power3.out` 都会在生成期直接报错——hold 没有"落位"可看，冲过去
再收回来读成画面抖了一下，方向为 `.out` 的档还会把变化全堆在开头，静止窗口之后的
"持续"就没了。

## 六、判据落在哪

`tests/test_hold_drift.py` 用六条压完，其中两条是方法论上的坚持：

| 判据 | 拦的是什么 |
|---|---|
| 窗口几何与短段跳过 | 慢推起手落在收拢还没演完的地方、末帧压线、短段被切一半 |
| 曲线是纯函数、端点精确、单调 | 逐帧 seek 下靠累计状态算出来的第 N 帧对不上 |
| 逐帧活动度（含旧行为反证） | 静止窗口没空出来 / 慢推其实没动 / 慢推变成第二次入场 |
| **产物级对账** | 从 HTML 抠出的那条补间，锚点、时长、幅度必须与 `_hold.plan` 逐项相等；两画幅各验，且两次生成字节相同 |
| 作用域与禁用属性 | 画布/接续/agenda/animate 段混进慢推；补间里出现 `opacity`/`width`/颜色 |
| 模板是唯一真源 | 改 `stillSeconds`/`scale` 产物不跟着走；`scale=0` 关不掉 |

最后一条尤其要紧：观感常量写进模板、别在 CSS 或 JS 里存第二份，是
`README.md` 第 6 节那三条不许破的规则里的同一件事。

## 七、什么时候不要

- **这一段本来就该是静帧**：一屏对照表、一段要逐字读的结论，慢推是干扰。
  `--set animation.hold.scale=0` 全局关掉，或把该段改成整页画布由作者自己演。
- **段长很紧**：余量不足反解窗口（24fps 下 1.28s）时自动不生成，不需要作者处理。
- **图内文字贴着边缘**：2% 仍会各裁掉 1%，先按
  `references/canvas.md「整页画布的密度与层次」` 留够安全边距。
- **已经写了 `animate`**：那一页的运动归导演，模板不叠第二层。

写完跑 `run.py --until html`，产物里那条 `tl.to(... scale:1.02 ...)` 的锚点应当
落在收拢终点之后 0.45s；全片动得对不对仍要按
`references/look.md「交付前四道」` 翻 contact sheet——判词只证明"没有明显坏"。
