# 术语表

全仓库唯一术语真源。正文（README / SKILL.md / references/ 其余文件 / scripts / templates）里
只允许出现**规范词**；别称一旦在 glossary 里登记，其它文件再出现就会被
`tests/check_docs.py` 判为术语漂移并报错。新概念先在这里定词，再写进正文。

| 规范词 | 别称（一律改用规范词） | 说明 |
| --- | --- | --- |
| 槽位 | 图栏、配图框 | 段落默认版式里 `layout.<画幅>.image` 那一块媒体区，两画幅各有一个 4:3 的框（竖屏 980×735、横屏 1067×800） |
| 方式 C | C 路线 | 手绘 SVG 数据图那条素材路线（见 `imagery.md`），与检索照片、生图并列 |
| 整页画布 | 画布段、canvas 段 | 段落 `layout: "canvas"` 时配图铺满整个画面、渲染器不生成标题层与句子流层的版式 |
| 导演档 | 导演模式、director 编排 | `images.json` 里 `director` 块驱动的 SVG 净化内联 + GSAP 逐句补间（见 `directing.md`） |
| 句子流 | 字幕带 | 段落底部跟随时间轴滚动高亮的旁白字幕窗口（DOM 类名 `.verse`，技术名不在锁定范围） |

改词纪律：写新内容时从本表取规范词；发现正文里出现别称，改回规范词并在这里补登记（别称是给读者
"旧文档里看到这个词 = 同一个东西"的对照，不是允许继续使用）。
