# 第 3 步 · 群集档：让元素之间互为源

**"演什么"在第 1 步就定了**（`beats` 写在稿件里）。这一档只答一件事：当这一拍要「一整片点自己散开、互相避让、绕着彼此盘旋、再干净地收回去」，而不是「一组元素逐个出现」「一个扰动从中心扩散」「一整片沿曲线流走」或「一枚透镜扫过」，怎么写。画图 → `references/canvas.md`；入场 → `references/look.md`；该不该动 → `references/motion.md`；按距离传播 → `references/wave.md`；沿曲线输运 → `references/flow.md`；瞬时折射 → `references/lens.md`。

## 一、对标：前沿在打的是「谁影响谁」

2026 的前沿 MG 里，与 liquid glass 并行的一支几份独立来源说的是同一件事——

| 来源 | 点名的手感 | 落到画面上是什么 |
|---|---|---|
| Generative Systems: Coding Chaos at Scale | Boid flocking 三规则：Separation / Alignment / Cohesion，"complex, emergent behavior" | 整片的行为**不能分解到个体**，由两两之间的相对位置长出来 |
| 同上（Generative Grid / attractor） | 物理引擎 + 磁吸子，"swarms can react to … magnetic attractors" | 每个成员既是受力者也是源，没有谁在旁边统一指挥 |
| Motion Luma 2026 趋势 | Procedural node-based animation、field manipulators、"swarming data nodes" | 一整片数据点按规则自组织，不是逐个打关键帧 |
| Videobacks 2026 粒子趋势 | 实时粒子模拟、增强粒子物理与动力学、粒子间 attraction / repulsion / collision | 群的运动读成「互相推挤」，不是「一起飘」 |
| 中文圈的同一句话 | 「粒子从效果变成有行为的实体」「从渲染什么到如何交互」 | 作者定的是**交互规则**，不是每个点的轨迹 |

把这一叠词翻成工程语言，还是那三个约束：**几何不许手写**、**起止干净**、**逐帧可复现**。第三条在这里比别的档更狠：真实的 boids 是逐帧积分速度的仿真，第 N 帧依赖第 N−1 帧，成片按时刻 `seek()` 取帧时根本对不上。所以本档把三规则写成**闭式的邻域场**——方向在生成期由图上静态几何一次算死，时间只经一个 `sin²` 窗口缩放。

**发光、拖影、粒子质感不归这一档**。半透明、渐变与滤镜由 SVG 自己画（经 `_svg_sanitize` 保留，见 `references/extensions.md`），或贴一段离线渲好的视频素材。档位只负责确定性的位移场，视觉质感是素材管线的活。

## 二、域地图：第十五个维度是「相互作用的来源」

| 档 | 消费的量 | 从哪读出来 | 收尾在哪 |
|---|---|---|---|
| `to` / `morph` / `draw` | 位置 / 形状 | 作者写在补间里 | 终点 |
| `spring` | 阻尼 | 作者选曲线 | 终点 |
| `momentum` | 速度包络（做形变） | 作者给距离 | 终点 |
| `drag` | 相位（一条链共享曲线） | 链序 `φᵢ = i·φ` | 全链一起落定 |
| `step` | 时间量化 | 帧号 | 终点 |
| `hold` | 静止 | 无 | 原位 |
| `stagger` / `decode` | 时序 / 锚点 | 序号 + 分配曲线 | 逐个留在终态 |
| `arc` | 空间曲率（**单个**元素的两条轴） | 作者给幅度 | 终点 |
| `organic` | 值域不规则 | 不公度谐波 | 精确回原位 |
| `trail` | 时间叠加 | 层间 `lag` | 影子收干净 |
| `wave` | 距离 → 波前 → 延迟 | 元素到**固定**震中的欧氏距离 | 每格回原位 |
| `flow` | 一条 path 的弧长 + 切线 | 曲线自身的形状 | 曲线算出的新位置 |
| `lens` | 方向的时间域 | 场心当前位置与元素中心的瞬时连线 | 精确回原位 |
| `swarm` | **相互作用的来源** | **全体元素两两之间的相对几何** | 精确回原位 |

前面十四档有一条从没人写破的共同前提：**驱动源是画面之外给定的**——一个震中、一条曲线、一枚透镜、一个序号、一条作者手写的算术式。元素只是被动接受那个场。于是「改图即改编排」在这几档里的形状都一样：挪动一个元素，**只有它自己的位移序列变，邻居一格不动**（`test_wave.py` / `test_flow.py` / `test_lens.py` 各钉了一份）。

群集档把这条反过来：**每个元素既是受力者也是源**，`sepᵢ` / `cohᵢ` / `vorᵢ` 都是对 `j≠i` 求和，连影响半径 `R` 都由全体元素的最远间距给出。于是挪动一个元素，**至少另一个元素的位移序列也跟着变**——这条产物级判据与前面十四档恰好相反，是本档唯一无法被别的档伪装的特征。与 `wave` 正交（那里增加的是延迟的空间来源），与 `flow` 正交（那里增加的是方向的曲线来源），与 `lens` 正交（那里增加的是方向的时变来源）：本档增加的是**「场」本身的来源**——它不再存在于画面之外，它就长在这群元素中间。

## 三、几何：两两相对位置 → 闭式邻域场

难点不是「让几个点散开」，而是**几何不许手写、且不许有状态**。作者一旦能填坐标、半径或权重，那串数字就是几何的第二份真源；一旦引入逐帧速度积分，逐帧 `seek()` 就复现不出来。解法是让生成期直接从 SVG 量出中心，再解一个不含时间的场：

```
cᵢ   = center(cells[i])                     每个元素的包围盒中心（图上真实元素）
R    = maxᵢⱼ |cⱼ − cᵢ|                      影响半径：**全体元素自己**的最远间距
dᵢⱼ  = (cⱼ − cᵢ)/R,  qᵢⱼ = |dᵢⱼ| ∈ (0,1]  归一化相对位置，q=1 是最远那一对
K(q) = (1 − q²)²,  q∈[0,1)，否则 0         聚合/对齐核：q=1 处值与导数精确归零
S(q) = (1 − q)²                            分离核：近邻更陡，与 K 不共线
Wᵢ   = Σⱼ K(qᵢⱼ)                           邻域权重和（活跃度真源）
sepᵢ = −Σⱼ S(qᵢⱼ)·ûᵢⱼ / |Nᵢ|              远离近邻（separation）
cohᵢ = Σⱼ K(qᵢⱼ)·dᵢⱼ / Wᵢ                 朝邻域加权质心（cohesion）
vorᵢ = rot90(cohᵢ)                          绕邻域质心盘旋（确定性版 alignment）
vᵢ   = w_sep·sepᵢ + w_coh·cohᵢ + w_vor·vorᵢ  按 mode 取三项权重
ûᵢ   = vᵢ/|vᵢ|                              **方向**由全体邻居共同决定
aᵢ   = min(1, Wᵢ/2)                         活跃度：离群的元素动得少
u(t) = sin²(πt/D)                           时间包络：u(0)=u(D)=0，端点导数为 0
Δᵢ(t)= amplitude · u(t) · aᵢ · ûᵢ            端点精确回原位
```

`ûᵢ` 是整条式子的关键：它不来自任何一个锚点，而是把**其它每一个元素**对 `i` 的作用加出来的。分离与聚合用的是两条不同的核（`S` 近邻更陡、`K` 平缓），否则两项方向恒相反、只会互相抵消成一串零——那正是「照着三规则各写一遍却什么都没动」最常见的死法。

包围盒与祖先仿射走与波场档、透镜档共用的那份实现（`_cam_crop._box` + `_wave.affine_to`），不另写第二套「大概在哪」；旋转/斜切读不准就判废并出声，不猜一个中心。图元可以是 `rect` / `circle` / `ellipse` / `line` / `polygon` / `polyline` / `path` / `text` / `image`，或包住这些图元的一层 `<g>`。

## 四、七条设计决定，都是被成片纪律逼出来的

**1. 元素互为源，这是本档存在的全部理由。** 挪一个元素，邻居的方向也变；测试从 HTML 抠出的 `tl.set` 序列逐帧对账。前面十四档的同类测试断言的是「其余元素一格不动」，这里断言的是「至少还有一个元素跟着变」。

**2. 几何一个字都不进契约。** `cells` 只写「哪些元素参与」，`amplitude` 是唯一的幅度旋钮。没有震中、没有曲线、没有透镜、没有半径、没有权重：三规则权重是成片纪律的一部分，不是作者该调的旋钮（调了就变成第二套物理）。这是「延迟不进契约」「相位不进契约」「场心不进契约」之后的第四次落地，且更彻底——**连场的中心都不存在**。

**3. 没有状态、没有积分步。** 方向在生成期由图上静态几何一次算死，时间只通过 `u(t)` 缩放。`state_at(t)` 不读墙钟、不存上一帧、不依赖调用顺序；正序、逆序、乱序求值得同一串数。渲染端零脚本、零 `onUpdate`、零物理迭代。

**4. 方向必须真的散开。** 至少两个活跃元素的位移方向夹角 ≥ 20°（**方向发散 ≥ 20°**）。元素全挤成一团、或全部共线且同侧时，合成方向几乎平行，成片读成「整块平移」——那就是 `wave` 的同步脉动或一条 `to`，按文件拦，不是参数越界。

**5. 端点精确归零，不是「接近 0」。** `u(t)=sin²(πt/D)` 在 `t=0/D` 处解析值为 0，但浮点 `math.sin(math.pi)` 不是精确 0；`state_at` 对端点与拍外显式短路返回 `0.0`，并把负零归一。于是 **收尾态 = 起始态**，跨段接续没有残留姿态可折。

**6. 紧支撑与活跃度。** `K(1)=0` 且一阶导数归零：`R` 是最远间距，所以最远那一对之间**精确没有直接作用**（不是「很小」），边界不出现速度突变。`aᵢ` 让孤立、离群的元素趋于不动，避免「一整片里有个点莫名其妙也在飘」。

**7. 三种手感，权重不进契约。** `flock`（缺省）= 分离 + 聚合 + 盘旋合成，读成一群点互相避让着盘旋；`scatter` = 纯分离，读成一次炸开又收回；`vortex` = 纯盘旋，读成绕着彼此转。三者逐帧给不同的方向，生成期自查会拒「mode 写了却与缺省完全相同」的静默失效。

**跨段接续**：每个元素收尾都精确回 0，没有残留。`_stage_carry` 仍必须**显式认这一拍**并返回空态，不能靠「这一拍没有 `set`/`to`、恰好 no-op」的巧合——将来给这一档加任何终态，那条巧合就会变成页界处一次静默的闪。

## 五、契约与旋钮

一拍写 `swarm`，整段负责全部参与元素。三个键，参与元素 3～12 个：

| 键 | 默认 | 读什么 |
|---|---|---|
| `cells` | 必填 | 3～12 个有序 `#id`，图里真实存在的一片元素；`cells[0]` 必须等于 step 级 `target` |
| `amplitude` | 必填 | 峰值位移（SVG 用户单位，非零有限数）；实际峰值再乘活跃度 `aᵢ`，不必精确达到它 |
| `mode` | `flock` | `flock` 三规则合成 / `scatter` 纯分离 / `vortex` 纯盘旋 |

```json
{"seg2": {"src": "images/seg2.svg", "animate": {"steps": [
  {"at": 0, "target": "#d1", "duration": 1.2,
   "swarm": {"cells": ["#d1", "#d2", "#d3", "#d4", "#d5", "#d6"],
             "amplitude": 60, "mode": "flock"}}
]}}}
```

图里只要一片**散开**的元素，不需要任何锚点、路径或透镜；顺序随作者写（只决定产物里 `tl.set` 的写入顺序，不影响邻域场）：

```svg
<rect id="d1" x="290" y="290" width="20" height="20"/>
<rect id="d2" x="490" y="250" width="20" height="20"/>
<rect id="d3" x="670" y="330" width="20" height="20"/>
<rect id="d4" x="350" y="490" width="20" height="20"/>
<rect id="d5" x="550" y="550" width="20" height="20"/>
<rect id="d6" x="750" y="510" width="20" height="20"/>
```

**互斥**：`swarm` 与 `from` / `to` / `set` / `draw` / `morph` / `count` / `type` / `momentum` / `drag` / `step` / `organic` / `trail` / `wave` / `flow` / `lens` 同拍即 error——两条时间线抢同一条 transform 通道，GSAP 后写的那条静默覆盖前一条。不收 `stagger`（把一个场拆成各自起跑）、`repeat` / `yoyo`（包络在收尾精确归零，重放会半路截断）、拍级 `ease`（包络是生成期算死的 `sin²` 窗，不是缓动），不能打在 `#cam`。

## 六、生成期会拦什么

| 现象 | 级别 | 怎么消 |
|---|---|---|
| 未知键 / `cells` 数越界、重复、含 `.class` 或 `#cam` / `amplitude` 为零或非有限 / `mode` 非法 | error（契约层） | 只认三个键；成员必须单个 `#id` |
| `cells[0]` ≠ step 级 `target` | error（契约层） | 群头就是这一拍的目标，接续烘焙与按文件拦只认 `target` |
| 与别的「演」同拍 / `stagger` / `repeat` / `yoyo` / 拍级 `ease` / 打在 `#cam` | error | 删掉一边；要逐个出现用 `stagger`，要按距离传播用 `wave` |
| `cells` 在 SVG 里找不到 | error（生成期，按文件拦） | 落空一个不会报错，只会让那一片区域静默不动 |
| 包围盒读不出 / 祖先带 rotate、matrix、skew | error（生成期，按文件拦） | 改成可量几何的图元或包一层 `<g>` |
| 所有中心重合（`R=0`）/ 两元素净空 < `max(1, 0.05·R)` | error（生成期） | 把这一片散开；`û=d/q` 在 `q→0` 未定义而分离核恰是峰值 |
| 方向发散 < 20°（读成整块平移） | error（生成期） | 把元素排成一片，别全挤在一条线同侧；要同步脉动用 `references/wave.md` |
| 整片没被邻域带动 / 只有一个元素在动 / mode 与缺省方向完全相同 | error（生成期自查） | 峰值由几何决定，按帧实采判；把元素挪得彼此更近一些 |
| 段首有位移 / 收尾没收回 / 拍外还在动 / 采样网格不递增 | error（生成期自查） | 正常配置不会出现；出现即说明邻域场被改坏了 |
| 拍长 < 0.12s / 帧时刻撞进同一个 0.01s 格 | error（生成期） | 加长 `duration`；否则产物静默少一帧 |

## 七、判据落在哪

`tests/test_swarm.py` 一个文件压完 18 条，判据全部**从产物里抠补间来读**，不在 Python 侧另写一份「应该生成什么」的实现。

| 组 | 钉住什么 |
|---|---|
| 信号 | 纯函数（正序/逆序/乱序一致、窗口外夹回端点）、端点精确归零且无负零、峰值时刻是 `D/2` 闭式解、核在 `q=1` 值与导数归零、三种 mode 方向两两不同 |
| **耦合（本档独有）** | 挪一个元素 → **至少另一个元素**的位移序列也变（前面十四档断言的恰好是「其余不变」）；R 由全体最远间距量出，改一个点整组活跃度跟着变 |
| 几何 | 中心 / R / 方向只从 SVG 量出；重合、净空不足、方向不散、包围盒读不出、元素落空、`_animate.check_animate` 按文件拦 |
| 网格 | 采样带两端、帧时刻严格递增且锁两位、条数 = (帧数+1)×元素数、写入顺序是 `cells` 序、短拍与非法 fps 被拒 |
| 契约 | 红线、与其余十五种「演」互斥、不收错峰/重放/拍级缓动、相机层与群头对齐、绕过契约层的坏值在生成期炸 |
| **产物级对账** | 从 HTML 抠出的 `tl.set` 序列，锚点、帧数、逐元素选择器与逐帧变量必须与 `_swarm.frames` 逐项相等；两画幅各验，两次生成字节相同；`amplitude` / `mode` / `cells` 各自真的改产物 |
| 作用域与接续 | 没写 swarm 的页零新增补间；`_stage_carry` 显式认这一拍并返回空态，六个元素在接续页的 transform 为零 |

「元素互为源」是本档独有的一条判据：既有档位要么根本不读 SVG 坐标、要么只读「元素到一个外部锚点」的关系，没有哪一档需要读**全体元素两两之间**的距离才能判断这一拍成不成立。

## 八、什么时候不要

- **一组元素要逐个出现并留在画面上**：用 `stagger`；要逐行锁定结论文字，用 `references/decode.md`。群集档演完全部元素精确回原位，读完就散。
- **一个扰动从某处按距离扩散、每个格子波过回原位**：用 `references/wave.md`。那是延迟的几何来源，方向由固定震中一次定死，元素之间互不影响。
- **要一整片元素沿画好的曲线持续走、落在新位置**：用 `references/flow.md`。流线档是输运，本档是一次散开又收回。
- **要一枚透镜扫过、同一元素在拍内转向**：用 `references/lens.md`。那里方向是时间的函数，本档方向不随 t 变（只有幅度随 `u(t)` 缩放）。
- **要主体带动一条真实元素的链、全链一起落定**：用 `references/drag.md`。本档没有链序，谁也不跟谁。
- **要到位停住 / 安静落位**：用 `.out` 档或 `spring`。本档整拍都在散，中途不该背着一片群集去落位。
- **文字 / 数据图 / 只有两三个元素**：本档只写 `x` / `y`，逐字揭示与数字滚动各有自己的整段语义；两三个点排不出相互作用的场，读成「一起斜着走」。
- **一屏同时动的不超过三处**：一开 swarm 就是一整片元素在动，别再叠一层 `organic` 呼吸或 `trail` 残影。先问 `--perceptual` 的四道验收够不够，交付前翻 `references/look.md「交付前四道」` 那张 contact sheet。
