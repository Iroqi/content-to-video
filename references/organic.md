# 第 3 步 · 有机档：让不规则可复现

**"演什么"在第 1 步就定了**（`beats` 写在稿件里）。这一档只答一件事：当这一拍要「像活的」而不是「算出来的」，怎么写。画图 → `references/canvas.md`；入场 → `references/look.md`；该不该动 → `references/motion.md`。

## 一、对标：缺的是值域，不是又一条曲线

2025/2026 的前沿 MG 有一股很一致的反潮：干净、几何、严格收敛的补间读了快十年，现在被点名的是**有机与不完美**。几份独立来源说的是同一件事——

| 来源 | 点名的手感 | 落到画面上是什么 |
|---|---|---|
| Identicube《Design Trends 2025》 | "Fluid, Organic Motion: Imperfection is the New Perfect"；curved paths、varied timing that mimics breathing、soft rebounds | 不严格对称、不精确重复的起伏 |
| The Nice Guys《Motion graphics trends 2025》 | 动能字体"letters breathe, stretch"；liquid / organic motion 让人「跟着流动的、不可预测的运动看」 | 字重与基线的呼吸、blob 的准周期形变 |
| Design Deluxe《Kinetic typography 2026》 | 可变字轴动态化、"text that breathes or pulses" | 一个连续量在整段里来回走 |
| Cpluz《10 Uncommon Trends 2025》 | Variable Speed and Timing、liquid animation | 速度不恒定、形状像流体 |

把这一叠词翻成工程语言，是三个约束：**不完全重复**、**起止干净**、**逐帧可复现**。第三条是本仓库的硬纪律，前两条是这套体系从没做过的。

## 二、域地图：值域的不规则一直是空的

先看已有档位各自消费了哪个「域」：

| 档 | 消费的量 | 形状 |
|---|---|---|
| `to` / `morph` / `draw` | 位置 / 形状 | 一条 `f(p)`，从 A 到 B |
| `spring` | 阻尼 | 二阶系统的闭式解 |
| `momentum` | 速度 | `f′(p)` 的归一包络 |
| `drag` | 相位 | 链序相位 `φ_i` |
| `step` | 时间量化 | 唯帧网格 + 双频抖动核 |
| `hold` | 静止 | 静止窗口 + 单调慢推 |
| `stagger` / `decode` | 时序 / 锚点 | 窗口与分配曲线 |
| `arc` | 空间曲率 | 两轴异缓动 |

它们有一条**从没被打破过的共同前提**：每一条都是「从 A 收敛到 B」的一次性、单调、完全解析的曲线。唯一跟不规则沾边的是 `step` 的双频抖动核，而 `_step.py` 把边界划得很清楚——**抖动只进时间域（哪帧换画），不进位置域（这一帧偏多少）**。于是值域的不规则是空的。

现有体系里最接近「呼吸」的写法是「一条拍配 `repeat`/`yoyo`、`duration` 0.4~0.7s」（见 `references/motion.md`「六种够用的演法」）。但它给的是一条**完全周期**的正弦：观众看完第一遍就预告了后面每一帧，恰好是前沿说的「机械感」。CSS `@keyframes` 与 SMIL 氛围循环能做出不规则，代价是墙钟驱动、与口播无关、逐帧 `seek()` 下同一时刻取到不同帧——本技能明令不收（见 `references/canvas.md`）。

**所以这一档不是「第十条位移曲线」，是补上第一个值域不规则信号。**

## 三、几何：窗口 → 谐波 → 端点

难点不是「加个随机」，而是随机与逐帧可复现直接冲突：`params` 白名单禁 `random`、禁时间函数，渲染端禁 `onUpdate` 里的累计状态（见 `references/motion.md`「参数演绎」）。解法是**确定性的不公度多频谐波**——不重复，但每一帧都是 `t` 的纯函数：

```
u = t / D
W(u) = sin²(πu)                          端点窗口，W(0)=W(1)=W′(0)=W′(1)=0
w_k = 1/k^1.35，归一化 Σw = 1            谱斜率 1.35，4 层谐波严格递减
F = (1, √2, √3, √5)                     两两之比无理 → 永不精确重复
φ_k(s, a) = 2π·frac((s+1)·α_k + a·γ)    整数种子 + 轴号 → 纯算术确定性相位
N(u; a) = Σ_k w_k·sin(2π·F_k·cycles·u + φ_k)
off(u; a) = amplitude · W(u) · N(u; a)
```

`α_k = frac(√2), frac(√3), frac(√5), frac(√7)`，`γ` 是黄金比共轭。相位只由整数 `seed` 与轴号 `a` 经 `sqrt` / `floor` 算出：没有 `random` 模块、没有全局状态、没有墙钟，同 `seed` 在任何机器上给出逐位相同的序列。

三条设计决定，都是被成片纪律逼出来的：

**1. 端点窗口而不是淡入淡出。** `W = sin²(πu)` 让物体在段首段尾**精确回原位**，且一阶导也归零——不会「切过来先歪着」，也不会在页界处带着速度撞停。它是全仓库唯一**收尾态等于起始态**的档：跨段接续没有任何残留姿态可折，`_stage_carry` 天然连续，不会出现 `references/motion.md`「跨段接续」里那类「字从来就不在」的静默错。

**2. 两轴必须异相。** `axis:"xy"` 时 x 取 `a=0`、y 取 `a=1` 两组不同相位。若同相，`(x,y) = off·(c,c)` 恒落在过原点的一条直线上，垂距恒为 0——那不是有机游走，是「沿斜线来回滑」，与 `references/motion.md`「位移走弧线」里「两轴同缓动 = 直弦」是同一个陷阱。端点重合时「弦」退化成一个点，量不了垂距，所以判据改用协方差两根之比的**各向同性比 ≥ 0.20**（实测异相约 0.39，同相恒为 0.0）。

**3. 生成期采样成离散 `tl.set`。** 沿用 `morph` / `momentum` / `drag` / `step` 的老路：渲染端零脚本、零 `onUpdate`、零依赖。`seed` 只在生成期读，成片里是一串确定的数值——逐帧 `seek()` 下每一帧都是时间的纯函数。

**红线**（写死在 `_organic.py`，不进模板、不给 `--set` 改）：幅度上限 60 SVG 用户单位；起伏密度 0.5～4.0 周期/段；整数种子 0～9999；谱斜率 1.35、4 层谐波；各向同性比 ≥ 0.20；逐帧位移 ≤ 幅度的 0.75；最短拍长 0.12s（帧时刻锁两位，短于此会让两个采样撞进同一格、静默少一帧）。

## 四、被否掉的五个方案

| 方案 | 为什么不收 |
|---|---|
| **`random` / Perlin 噪声** | 逐帧 `seek()` 下第 N 帧与直接跳到第 N 帧对不上；噪声实现要是搬进渲染端，Python 侧判据就退化成对着另一份 JS 自证（`decode.md` / `spring.md` 记过这笔账）。 |
| **GSAP `RoughEase` / `CustomEase` 扩展档** | ease 只能改位置曲线，且 `RoughEase` 的随机点在生成期与渲染端各存一份；更根本的是「不规则」要落在**独立信号**上，不该寄生在某条 `f(p)` 里。 |
| **`repeat` + `yoyo` 的正弦呼吸** | 完全周期，读完第一遍就预告后面每一帧。前沿要的正是「不完全重复」。 |
| **CSS `@keyframes` / SMIL 氛围循环** | 墙钟驱动、与口播无关、逐帧不可复现，`check_svg.py` 会 warn。 |
| **把 `step` 的抖动核搬进位置域** | `step` 的 `w_j` 是台阶时刻的抖动，台阶本就少（常常十几张），位置再抖会让落位前一张反向，是整段最显眼的错；而且那条核的端点归零是给「什么时候换画」用的，不是给「这一帧偏多少」用的。 |

另外试过、又删掉的一条判据：在窗口上做**单频拟合 / 自相关**，想用它证明「不是单频机械呼吸」。实测 4 层谐波在 1~2 个周期的短窗口里，单频拟合 R² 能到 0.98，纯单频反而因端点窗口只有 0.58——两个方向都分不开。最后改成读频率表本身的**不公度性**：任意两层频率比与最近有理数 `p/q (q ≤ 12)` 的距离 ≥ 0.001（本组实测最小 0.00219）。这是结构性事实，不靠在短信号上做谱分析。

## 五、契约与旋钮

一拍写 `organic`，整段负责这条轨迹。四个旋钮：

| 键 | 默认 | 读什么 |
|---|---|---|
| `axis` | `"xy"` | `"x"` / `"y"` 单轴，或 `"xy"` 双轴异相 |
| `amplitude` | `12` | 峰值幅度上界（SVG 用户单位） |
| `cycles` | `1.6` | 整段内主频走几个周期：越大越密 |
| `seed` | `7` | 整数，换一版「手作感」；同 seed 逐帧一致 |

```json
{"seg2": {"src": "images/seg2.svg", "animate": {"steps": [
  {"at": 0, "target": "#blob", "duration": 1.2,
   "organic": {"axis": "xy", "amplitude": 14, "cycles": 1.8, "seed": 7}}
]}}}
```

**没有 `ease`：这一档不消费缓动曲线**，起伏由谐波自己给。step 级 `duration` 照常从模板 `animation.animate` 取或拍级覆盖，它决定整段有多长、也决定采样帧数。

**互斥**：`organic` 与 `from` / `to` / `set` / `draw` / `morph` / `count` / `type` / `momentum` / `drag` / `step` 同拍即 error——两条时间线抢同一条 transform 通道，GSAP 后写的那条静默覆盖前一条。不收 `stagger` / `repeat` / `yoyo`（连续轨迹 + 端点精确回原位），不能打在 `#cam`（相机层归整页取景）。

## 六、生成期会拦什么

| 现象 | 级别 | 怎么消 |
|---|---|---|
| 未知键 / `axis` 非法 / 幅度越界 / 密度越界 / 种子非整数 | error（契约层） | 只认四个键；红线见上一节表 |
| `seed` 写成小数或布尔 | error | 必须是整数，布尔值在 JSON 里也算非法 |
| 与别的「演」同拍 | error | 删掉一边；要一条链用 `drag`，要逐个出现用 `stagger` |
| `stagger` / `repeat` / `yoyo` 挂在 organic 上 | error | 连续准周期轨迹不拆、不重放 |
| `target` 打在 `#cam` | error | 给主视觉元素单独命名 |
| 逐帧位移过大，读成抖动 | error（生成期） | 调小 `cycles` 或加长这一拍；报错会点名这条 |
| 帧时刻撞进同一个 0.01s 格 / 拍长 < 0.12s | error（生成期） | 加长 `duration`；否则产物静默少一帧 |
| 双轴轨迹共线 | error（生成期） | 两轴相位退化成同相才会触发，正常配置不会出现 |
| 端点没回原位 / 峰值越过幅度 | error（生成期） | 生成期自查会拦，正常配置不会出现 |

## 七、判据落在哪

`tests/test_organic.py` 一个文件压完，判据全部**从产物里抠补间来读**，不在 Python 侧另写一份「应该生成什么」的实现。

| 组 | 钉住什么 |
|---|---|
| 信号 | 纯函数（正序/逆序/乱序一致）、端点精确回原位且一阶导归零、幅度有界、同 seed 逐位相同 / 不同 seed 确实不同、谱严格递减与频率不公度 |
| 轨迹 | 双轴异相（各向同性比 ≥ 0.20，人为并成同相必须塌到 0）、单轴只写一条 transform |
| 带宽 | 逐帧位移 ≤ 幅度的 0.75（短拍满密度被点名、长拍同配置放行）、采样网格严格递增且落在共用采样带 |
| 契约 | 红线、与十种「演」互斥、不收错峰/重放、相机层、绕过契约层的坏值在生成期炸 |
| **产物级对账** | 从 HTML 抠出的 `tl.set` 序列，锚点、帧数、逐帧变量必须与 `_organic.frames` 逐项相等；两画幅各验，两次生成字节相同 |
| 作用域与接续 | 没写 organic 的页零新增补间；接续页不折任何 transform、不弹回、不出声 |

## 八、什么时候不要

- **这一拍要「到位停住」**：用 `.out` 档或 `spring`。有机档的收尾是回原位，不是落在目标上。
- **要的是「落位之后别整段静帧」**：那是 `references/hold.md`「静止窗口与 hold 慢推」的活，`hold` 回答「有没有动」，本档回答「动得像不像活的」，两者不互相替代。
- **一组元素要逐个出现**：用 `stagger`；要主体带动一条链，用 `references/drag.md`「相位一直是隐含量」那一档。
- **要「一张画停几帧」的手作节奏**：用 `references/step.md`「被否掉的五个方案」里对应的定格档——那是时间域的不规则，跟本档正交。
- **文字 / 数据图**：本档只写 `x`/`y`，逐字揭示与数字滚动各有自己的整段语义。
- **只想让画面轻微持续活动**：先问 `--perceptual` 的四道验收够不够；一屏同时动的不超过三处，别给每个元素都挂一条有机轨迹。
