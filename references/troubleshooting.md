# 第 4 步 · 画面翻车速查表

**按看到的症状查，不按知识点查。** 表里"去处"给到文件与章节，改法在那里；查不到再看每节末尾的认定口径。

## 三种成功率最低的画面

先认这三条。它们都不报错，`check` 全绿，只有人眼或 `perceptual.py` 看得见：

| 症状 | 为什么门禁看不见 | 怎么办 |
|---|---|---|
| 一页十几秒只有字幕在走 | 图是静态的、也没写 `animate`；`check` 只看结构 | `perceptual.py` 的 `dead_seconds`；给该段写 `animate`（`motion.md`「一条判据：写字还是不写」）或整页画布演 |
| 首帧一片背景色 | 那是社交平台的分享封面。开屏的标题/光斑/agenda 都从零态进场 | 开屏写 `opening_layout: "canvas"` 出静态海报；或给标题一条起点非零的编排 |
| 图内标签在成片里看不见、零报错 | `<img>` 载入的 SVG 文字不属于 HTML 文本流 | `canvas.md`「图内文字的对比度」 |

## 动画

| 症状 | 成因 | 去处 |
| --- | --- | --- |
| 标题"没进场"或从半路弹出来 | CSS 与 GSAP 抢 `transform`（**生成期就 error**） | `_css_guard.py` 报错；改绝对定位 + auto 外边距 |
| 入场"看得出在变、看不出在动" | 首帧位移 <4px ＝ 淡入 | `motion.md`「曲线的行程预算」 |
| 整页画布一来就浮上来 | 满幅页吃了配图入场 | `look.md`「三条换版式时会坏的」 |
| 片长不对、取帧全是同一帧 | 某处 `repeat:-1`（**契约层直接拒**） | `motion.md`「拍级键」的 `repeat`/`yoyo` |
| 动画与旁白差 0.1s | 句内小数是线性猜的（整数句序准） | 同上，`at` 条 |
| 推镜时页底标签不见、页顶标题贴边 | `scale>1` 绕 `svgOrigin` 放大，留白要按**推完那一帧**算 | 同上，运镜条 |
| 推近的图形压到旁边静止的标题上 | 出画 warn 只判出画、不判撞字 | 同上，「机器兜不住的那件事」 |
| 接续页界图形跳一下 | 没写 `svgOrigin` 时绕 `#cam` 并集中心缩放 | `motion.md`「镜头：谁能调机位」的原点条 |
| 接续页界整幅换色但图形接上了 | 每页 accent 不同，氛围光与进度条整幅换色 | 同上，实测段（按柱子边沿量） |
| 两页同图，后一页却从头演了一遍 | 前一页不是整页画布：接续只在满幅页上成立（槽位页的页界是版式语义） | `motion.md`「跨段接续」首条约束 |
| 开场最后几行像没出现 / 整体快一拍 | 苹果开场按可见窗口压缩，压到地板仍装不下 | `look.md`「苹果风开场」；写长 `opening` |

## 字幕

| 症状 | 成因 | 去处 |
| --- | --- | --- |
| 高亮几帧不动、然后跳一个字宽 | 读取头只用了整数部分 | `look.md`「读取头」 |
| 念完一句还整句亮着抢焦点 | 没有收束 | `look.md`「焦点衰减五维」末段 |
| 换句瞬间硬跳（亮度和尺寸还是柔的） | 滚动那一维没插值 | 同上 |
| 上一句"啪"地暗下去 | 退场没走插值 | 同上 |
| 没挪档的行也跟着暗一下再亮回来 | 入场浮出叠给了所有行 | `look.md`「换句与浮出」 |
| 离焦行糊成一团 | 景深档太大；先 `--set subtitle.focus.blur=0` 对照 | `look.md`「焦点衰减五维」 |
| 画布页字幕换句时整行硬跳 | 换灯回来了：列没滚（`#pl-{sid}` 那条没生成，或 `subtitle.relay` 是 0） | `look.md`「动画：实现要点」的字幕层一条 |
| 画布页字幕一直停在首句 | 滚动补间没进时间线——首句不滚是对的，别把首句也排上 | 同上 |
| 画布页字幕一句话念一半就没了 | 超 `captionMaxLines` 本该 error（字幕层不钳句，第三行被钳掉） | `canvas_layout_errors`；压短那句 |
| 画布页字幕盖住了画面底部 | 页底那条留白不够（竖屏要 ≥220px） | 把结论画在字幕带之上；或 `--set plate.<画幅>.captionFontSize=…` 缩字号 |

## 画面（SVG 与配图）

| 症状 | 成因 | 去处 |
| --- | --- | --- |
| 图槽空荡荡只有一行小字 | 配图信息量撑不住 4:3 槽位 | `look.md`「四条判据」的 `canvas_thin`；主视觉占页宽 ≥70% 重画 |
| 图内文字右缘出血 | `text-anchor="end"` 要按量出来的字宽倒推 | `canvas.md`「整页画布」 |
| 两行文字压在一起（`content_overlap`） | `canvas_kit` 柱标签固定落在 `base_y+32` | `canvas.md`「画布几何」末条 |
| 整页画布是均匀死色 | 铺了满幅底板盖掉背景三层 | `canvas.md`「不铺满幅底」 |
| 暂停一帧像空白（中段整条空带） | 标题/主视觉/注脚没分三段、没有中景 | `canvas.md`「整页画布的密度与层次」 |
| 只有开头一秒是空的 | 逐拍揭示，前 1 秒无内容 | 同上 |
| 压缩后轴线/网格像没画 | 色档太暗 + 线宽 <3px 被抹平 | 同上 |
| 浏览器里颜色分明、成片里发闷 | 图内最大/最小字号比值 <2 | `canvas.md`「整页画布」 |
| 整张发闷像一片渐变加一块图 | 网格太暗再合成一次，或氛围光边界可见 | `look.md`「氛围与底色」 |
| 某段画面糊、虚 | 素材像素不够铺满那一页的框 | `imagery.md`「统一使用同一个内容画布」 |
| 配图够清晰却报"不够大" | 按实际落地框判（整页画布按整幅） | 同上 |

## 官方门禁

| 症状 | 成因 | 去处 |
| --- | --- | --- |
| 五阶段全是空结果 | Lint 有 error，浏览器阶段被整个跳过 | `rendering.md`「官方校验命令」 |
| Layout 报 `text_occluded` 但快照里文字好好的 | 滚出窗口的行 rect 仍在原位，属误报 | 同上 |
| `check` 全绿但成片明显有问题 | 它只证明没坏，证明不了该不该动 | 本页最上面那三条 + `look.md`「观感门禁」 |
| 渲染太慢 / worker 崩 / 内存不够 | 默认值以 `--help` 为准，经验值会随机器与稿件规模失效 | `rendering.md`「渲染性能」 |
