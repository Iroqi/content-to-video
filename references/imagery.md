# 第 3 步 · 配图：形式选择与 ImageGen 产出

"这一页要不要交给导演演"在写稿那一步答完（见 `references/writing.md`「哪些段值得交给 canvas」）；SVG 怎么画与怎么演都在 `references/canvas.md`，本文件不复述。

## 两种形式的统一规则

### 1. 先选“表现方式”，再选素材来源

| 内容特征 | 首选方式 | 原因 |
|---|---|---|
| 画面里**不需要出现可读文字**：抽象概念、原理、氛围、场景 | **ImageGen 生图** |
| 画面里**必须有准确文字/数字**，或必须精确矢量几何、严谨数据 | **SVG 矢量示意** |

**分界线只有一条：图内要不要文字。** 要（标签、步骤名、数值、图例、公式）→ SVG；不要 → ImageGen，哪怕内容复杂——生图文字崩率高。

**只有 SVG 能"演"**：ImageGen 图是一张静帧，只能当素材贴进画面（外加一层模板给的缓慢推近，逐段要不要、推多快由 `images.json` 的 `drift` 定）；要画面跟着旁白逐拍走（推导、数据生长、运镜、逐字揭示）只有 SVG 能进导演档（`director` 净化内联、GSAP 按句驱动，见 `references/canvas.md`「SVG 动画：两档」）。

数据图和公式归到 SVG：坐标刻度、柱长比例、扇区角度全自己算自己标（自查见 `canvas.md`「数据图的几何自查」）。何时从 4:3 槽位换整页画布见 `canvas.md`「整页画布」。

按**信息结构**定形式：

| 信息结构 | 首选形式 | 形式 |
|---|---|---|
| 数值比较 / 占比 / 趋势 / 双变量关系 | bar / pie / line / scatter | SVG |
| 时间演进（要标年份） | 时间线 | SVG |
| 步骤 / 机制流程（要标步骤名） | 流程图 | SVG |
| 层级 / 关系 / 系统结构（要标节点名） | 树状图 / 网络图 / 架构图 | SVG |
| 几何 / 空间关系，**不带文字** | 生图（isometric / 3D 风格词） | ImageGen |
| 外观、场景、氛围 | 图片 | ImageGen |

同一张图能不说清楚就不写文字，降级交给生图（省一次重画、免掉图内文字对比度自查）。图只承担**增量信息**：标题和 verse 已说清时不画，不为"高级感"堆 3D / 仪表盘 / 拼贴。

### 2. 统一使用同一个内容画布

- 内容画布（真源见 `canvas.md`「画布几何」）：竖屏 980×735，横屏右侧槽位 1067×800（4:3 按整数像素取整）。**两个画幅的图槽都是 4:3 横版**——竖屏成片的图也是横图，别按竖屏比例出图。
- 配图规格两条：**按 4:3 出图**、**像素要够铺满**。渲染端是 `object-fit: cover`——**裁边铺满，不是 contain 留黑边**：比例不一致的部分上下/左右对称裁掉，裁哪块由 cover 定不由你定；只保证填满、**不保证清楚**——放大超过 1.25 倍（`_media_size.UPSCALE_WARN`）打 `[warn]` 点名哪段、素材多大、要放大几倍；超过 2.0 倍（`UPSCALE_SEVERE`）直说细节基本没了。**别把这条 warn 当噪音**：它是"这一段成片是不是糊的"唯一的机器证据。ImageGen 图按最接近 4:3 的档位出；**SVG 不验尺寸**（矢量放大不失真）。比例差得远（cover 裁掉超过 20% 画面，`_media_size.CROP_WARN`）另有一条 warn 说明裁掉多少、去哪换档位——生成期就喊，别等渲染完才发现构图被切。
- **整页画布（`layout:"canvas"`）是唯一例外**：铺整个画面，尺寸对账按整幅算（规格见 `canvas.md`「整页画布」）。

### 3. 统一的制作流程

每段同一条链：选形式 → 生图/画 SVG → **预处理**（去水印 → 裁成槽位比例）→ 落 `images/` 并写 `images.json` → **人工审关键帧**（主体、构图、文字可读性、与旁白关系）。预处理两步都是**入库前的标准动作**，不是看到成片不对劲再回来补救；最后一步不因形式不同省略。

### 4. images.json 是唯一统一入口

两种形式最终都映射到同一份 `images.json`：

```json
{
  "seg1": {"src": "images/seg1.png"},
  "seg2": {"src": "images/seg2.svg"}
}
```

字段（封闭键集，写清单外的键不生效且 `_normalize_images` 打 `[warn]` 点名；`_` 开头的键按草稿处理——放行但同样不生效；裸字符串路径 `{"seg1": "images/seg1.png"}` 直接报错）：

- `src`：必填，相对 HTML 输出目录的媒体路径。
- `type`：可选，`auto`/`image`，缺省 `auto`（按扩展名判；`.gif` 走 `<img>`，与 ImageGen 图同档）。
- `director`：可选，**仅 `.svg`**，导演档编排块（见 `canvas.md`「SVG 动画：两档」）。写了才净化内联、由 GSAP 逐句驱动；不写就是普通 `<img>` 静态图。
- `stage`：可选，**仅 `.svg`**，只认 `"keep"`——跨段接续（见 `canvas.md`「跨段接续」）。**通常不用写**：与上一段同一张 `src`、且上一段末拍把相机停在非原位时，生成期自动按 `"keep"` 处理并在日志里点出段名；想让这一页独立重演，换开 `src` 或去掉那条运镜即可。显式写了就照你写的来。
- `media_start`：可选，**仅 video**，从源片第几秒起播（缺省 0）。它能用的长度是"片长 − media_start"：起播点越过片尾时这一段**整段没有画面**，生成期直接拦（exit 1）；不够这一段长会打 `[warn]`（末帧停在画面上），超出则尾部被截断。
- `provider`/`license`：可选，素材来源记账（生图记录生成工具与授权）；二次整理保留旧值不要覆盖，画面不读。
- `drift`：可选，**仅静态图**（image/svg/gif），逐段覆盖这页的运镜（Ken Burns）。`false` = 这一段完全不动（正对镜头的人脸、图表页，"推近一点"反而是干扰）；对象 = 只写要改的那几项（`ratePerSec`/`maxScale`/`panX`/`panY`），其余走模板缺省。整片换手感用 `--drift off|subtle|boring`，别逐个段写。

## ImageGen 素材：生图

### 生图规格与 prompt

**三档尺寸，选 `1536×1024`**。能力端只有 `1536×1024`（横）/ `1024×1024`（方）/ `1024×1536`（竖），**没有 4:3 档**，而两个画幅的图槽都是 4:3 横版：选横图（约裁 11%），方图裁 25%、竖图裁一半——机器会在生成期按段打 `[warn]` 点名哪段裁了多少，别等渲染完才发现构图被切。

每段一张图，同一批保持同一背景明暗与风格词。Prompt 先写"讲什么"再写"怎么画"（主体/场景 → 核心动作或结构 → 视觉关系 → 风格 → 背景与色调）。`diagram / chart / schematic / infographic` 这类词会把轴标签和文字带进来，末尾补 `no text, no labels, no letters, no numbers`。出图后**逐张看有没有崩字**——生图文字崩率高（错字、缺笔、乱码），崩在图里的字改不动。

### 水印：逐张看，平滑背景补、复杂纹理裁

水印**因模型而异，没有通用的关闭开关**（`footnote` 之类的参数传不传都一样）。所以只能**出图后逐张看右下角**：盖了就在**入库前处理掉**，与"裁成 4:3"合并为同一步预处理。

**背景平滑的用印章式补，别裁**——从水印正上方裁一块同尺寸的干净区域贴回原处，构图一点不损失（实测水印区残留从 65 降到 1）：

```bash
# 例：水印 bbox 左上角 (1206,956)、尺寸 288×34；取样区取它正上方同一块 (1206,922)
ffmpeg -i in.png -filter_complex \
  "[0:v]split=2[a][b];[a]crop=288:34:1206:922[c];[b][c]overlay=1206:956" out.png
```

**补之前先判背景平不平滑**——取样区与水印区纹理不一致时会留下一块明显的"补丁"，比水印本身更显眼；取错区域甚至比不处理更糟：

```bash
# YAVG < 40 → 印章式安全；≥ 40 → 别补，走下面的裁切
ffmpeg -i in.png -filter_complex \
  "[0:v]crop=288:34:1206:956[a];[0:v]crop=288:34:1206:922[b];\
[a][b]blend=all_mode=difference,signalstats,\
metadata=print:key=lavfi.signalstats.YAVG" -f null - 2>&1 | grep YAVG
```

**裁掉是兜底**：复杂纹理（密集图案、人脸、文字密集区）或判据说别补时才走裁切——先裁水印、再裁比例，一次裁好保住主体。裁完按上面那张表的算术重算一遍，别让裁掉一圈的图掉进放大告警。

### 选图标准

- 主体与段落讲的是同一个人、产品、地点或事件。
- 长边低于约 1200px 时进成片容易发虚。
- **入库前裁成 4:3**（去水印见上一节，先做那一步），保留哪块主体由看图的人判断——cover 只认框的中心，你要保的主体不在中心就得自己裁。

### 透明通道：ImageGen 也能直接贴背景（无需抠图）

带 alpha 的**透明 PNG / WEBP** 与 SVG 等价：渲染端把它当 `<img>` 放进同一张场景图，透明处透出主题渐变与 `--seg-accent` 辉光，不必抠图。边界：

- **透明只在「同一 scene 内」成立**：渲染一次性把背景+前景合成成帧，没有第二次 overlay 的机会。
- **透明由出图端保证，契约层不校验像素**：前景被填了不透明底色就会盖死画布（信源问题）。看到前景盖背景，回去查出图端有没有填底色。
