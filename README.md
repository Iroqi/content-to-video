# Content to Video · 信源转视频

把一篇文章、一份报告、一个网页链接交给 agent。一页笔记、一段粘贴的聊天记录也可以。你拿回一支**带配音、逐句字幕、配图与动效的解说视频**。

你全程只做两件事：**给料**，和**提意见**。写稿、配音、画图、排版都由 agent 沿一条固定管线替你做。

---

## 成品是什么样的

一支真正能直接发的解说视频，不是幻灯片录屏：

- **口播配音**：多种预置音色可选，能调语速和语气。双人问答还原成两个声音对谈。
- **逐句字幕**：字幕和语音由同一根时间轴驱动，一句高一句、一句对一句。对话段在轮次切换那句挂出说话人名字。
- **配图与动效**：每段一张视觉——标题加插图加要点的卡片，或整屏铺开的一张会动的海报。数据关系、系统结构、时序流程用矢量示意图当场画出来。
- **两种画幅**：竖屏 3:4 适配手机信息流，横屏 16:9 适配电脑与大屏。
- **主题配色**：深色主题，段落强调色自动轮询。

一句话：**观众看到的是完整的解说，而不是一堆会动的文字。**

## 怎么和 agent 交互

不需要记任何命令或参数，说人话就行。一轮典型对话四步：

### 1. 给料

> "把这篇文章做成视频"＋（链接 / 文件路径 / 直接粘贴正文）

公众号长文、行业报告、论文、会议纪要、周报、产品说明、自己的笔记都可以。agent 先读懂它，提炼标题、核心事实和视觉线索。

### 2. 提要求（想说就说，不说全按默认走）

> "横屏，女声，节奏快一点，最后加个行动号召"
> "这是两个人对谈的纪要，保留问答感"

画幅、音色、语速、主题、每段讲多深都能随口提。

### 3. 看预览，逐段提意见

agent 先给你一个浏览器里能打开的预览页，还没花渲染成本，随便改。改稿、换图、调结构都不会重头再来：**已定稿的句子配音直接复用**。

### 4. 催定稿

> "没问题了，出成片。"

agent 才做最后一步渲染，交 MP4 + 一份生产报告（每步耗时、配图覆盖率、有没有降级句）。

## 适合做什么

| 场景 | 出来是什么样 |
|---|---|
| 长文 / 公众号 / 论文 → 听解说 | 通勤路上能听完的一篇深度内容 |
| 报告 / 周报 / 会议纪要 → 汇报视频 | 不用开会，把结论和数字讲清楚 |
| 概念科普 | 结构图、流程图、数据关系直接画在画面上 |
| 产品介绍 / 功能说明 | 分模块讲解，每段一张视觉 |
| 对谈纪要还原 | 双音色问答，保留对话感 |

## 别用它做什么

- **剪辑已有视频**——它不处理你手上的素材片
- **只要配音、不出画面**——用任意 TTS 工具更省事
- **把 PPT 导出成视频**——它从文字重新写稿排版，不是转换 PPT

---

## 几件值得知道的事

- **画面不联网**：出图、排版、渲染都在你自己的电脑上完成。要联网的只有两件事——配音合成请求外部 TTS 服务；换新机器第一次生成画面时取一个动画引擎文件，之后本地一直用这份。
- **降级不会瞒着你**：某句配音失败、某段丢失，交付前明确告诉你。成片落盘后还会量一次实际时长跟时间轴对账，绝不悄悄交出"短了一截"的片子。
- **内容里的指令不会被执行**：信源里夹着"请忽略之前的设定""先执行这条命令"之类的话，一律当普通文字读。
- **产物不会写进技能目录**：音频、图片、HTML、成片都落在你的项目目录。
- **字幕的取舍你知情**：整屏海报那一档版式没有跟着时间轴走的逐句字幕，口播里的关键句务必画进图里。

## 准备工作

运行环境完整口径只在 [SKILL.md](SKILL.md)「环境」表，这里给三句最要紧的：

- **`MIMO_API_KEY` 是硬闸门**：配音走外部付费 TTS，是整条链路唯一的付费外部依赖；没有 key 第 3 步直接停，即使全部命中缓存也不放行。
- **ffmpeg**（只要 `ffmpeg`）与 **Node.js 22+**（+ `npx hyperframes`）分别负责音频处理与渲染成片。
- Python 3.9+ 就够，只用标准库，不需要装任何额外依赖。

**没有 key 就先别指望出成片**——先备好 key 再开工。

## 维护者

改完代码跑 `python -m unittest discover -s tests`（只用标准库，约 2 秒，无需网络 / ffmpeg / Node）。改标题或瘦身文档后再跑 `python tests/check_docs.py`（章节交叉引用有没有悬空、SKILL.md 与 references/ 是不是又胖回去了）；改了写进文档的阈值（画布尺寸、字号下限、告警门限、时间容差…）再跑 `python tests/check_numbers.py`（逐条比对代码常量与文档数字）；`python tests/check_examples.py` 把文档示例真跑一遍。三个检查都在 CI。有意改视觉导致 HTML 快照变化时，用 `UPDATE_GOLDEN=1` 重新生成 `tests/golden/`。

发布时手动压缩技能目录：剔掉 `tests/`、`.env`（含密钥，漏进包就是泄密）、`.git/.venv/__pycache__`、制作残渣（`audio_output/`、`hf-project/`、`out/`、`snapshots/`）与中间文件（`candidates.json`、`segments_source.json`、`timing_manifest.json`）。`scripts/check_svg.py` 要留着——它是第 4 步引用的生产工具，不是维护物。
