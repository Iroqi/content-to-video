# Content to Video

把一篇文章、一份报告、一个网页链接或任何文字信源，交给 agent，拿回一支带配音、逐句字幕、配图与动效的解说视频。

## 成品长什么样

- 口播讲解视频：旁白配音 + 与语音逐句同步的字幕 + 画面动效
- 竖屏 3:4（适合手机信息流）或横屏 16:9（适合电脑与大屏），两种画幅任选
- 每个段落一张视觉：卡片版式（标题 + 配图 + 要点）或整页画布（整屏就是一张会动的海报）
- 可选背景音乐、响度归一化，成片是标准 MP4
- 全程离线渲染：除了配音合成要联网，画面生成不依赖任何在线服务

## 怎么和 agent 交互

不需要记任何命令，直接说人话即可。典型的一轮对话：

1. **给料**——"把这篇文章做成视频"，附上文本、文件路径或网页链接
2. **提要求**——想说的都说，不说就按默认走：画幅、音色、语速、主题配色、要不要 BGM
3. **看预览**——agent 会先出一个可以在浏览器里看的页面，点播放就能看画面听配音逐句过；觉得哪段不对，直接说"第二段图换掉""标题太长了""改成横屏"
4. **催定稿**——满意了说"渲染成片"，agent 才做最后一步

改稿、换图、调结构都不需要重头再来：之前的配音会复用，只有变了的句子重新合成。中途随时可以叫停。

## 什么时候用它 / 不用它

- 适合：文章转视频、报告转讲解、科普短视频、会议纪要转口播、长文转"听解说"
- 不适合：剪辑已有视频、只配音不出画面、把 PPT 导出成视频

## 准备工作

- 一个 MiMo 的 API key（配音用，唯一硬依赖）
- 电脑上装有 ffmpeg 和 Node.js（渲染成片用）
- 详细的运行条件和参数说明在 [SKILL.md](SKILL.md)，那是给 agent 看的说明书，人不必读
