# 第 3 步 · 波场档：让延迟由画面几何量出来

**"演什么"在第 1 步就定了**（`beats` 写在稿件里）。这一档只答一件事：当这一拍要「一个扰动从某处传过去」，而不是「一组元素逐个出现」，怎么写。画图 → `references/canvas.md`；入场 → `references/look.md`；该不该动 → `references/motion.md`；一条链沿相位传 → `references/drag.md`。

## 一、对标：前沿在打的是「延迟由序号排出来」

2025/2026 的前沿 MG 有一支很一致的语言，几份独立来源说的是同一件事——

| 来源 | 点名的手感 | 落到画面上是什么 |
|---|---|---|
| 品牌页与数据叙事的 dot-matrix / halftone ripple、kinetic point-cloud wave | 一个扰动从中心扩散，点阵按到中心的距离依次起伏，波过之后回到原位 | 波前是**空间**的，不是排队的 |
| Adobe After Effects 的 Wave Warp / displacement wave 工作流 | 位移按「离波源多远」传播，波速与波长是两个独立旋钮 | 时间与空间被绑在一起 |
| GSAP `stagger` 的 `grid:"auto"` + `from:"center"` | 按网格单元到锚点的距离分配 delay，是这一支里最接近的工程写法 | 但它量的是**行列号**，不是真实坐标 |
| 2026 动效趋势里的「intentionally imperfect / 有机的连锁反应」 | 远端幅度渐弱、近端先动，一屏里只有一处波在跑 | 幅度随距离衰减，不是整齐划一 |

把这一叠词翻成工程语言，是三个约束：**延迟不许手写**、**起止干净**、**逐帧可复现**。第三条是本仓库的硬纪律，前两条是这套体系从没做过的：已有档位的错峰全由作者排出来的序号给，一张图里二十个点排成圆还是排成一列，编排完全一样。

## 二、域地图：空间传播一直是空的

先看已有档位各自消费了哪个「域」：

| 档 | 消费的量 | 延迟从哪来 | 收尾在哪 |
|---|---|---|---|
| `to` / `morph` / `draw` | 位置 / 形状 | 无 | 终点 |
| `spring` | 阻尼 | 无 | 终点 |
| `momentum` | 速度包络（做形变） | 无 | 终点 |
| `drag` | 相位（一条**链**共享曲线） | 链序 `φᵢ = i·φ` | 全链一起落定 |
| `step` | 时间量化（一张画占几帧） | 帧号 | 终点 |
| `hold` | 静止 | 无 | 原位 |
| `stagger` / `decode` | 时序 / 锚点 | 序号 + 分配曲线 | 逐个留在终态 |
| `arc` | 空间曲率（**单个**元素的两条轴） | 无 | 终点 |
| `organic` | 值域不规则 | 不公度谐波 | 精确回原位 |
| `trail` | 时间叠加（一帧里多个过去） | 层间 `lag` | 影子收干净 |

它们有一条从没被写破的共同前提：**没有任何一个量是从「这些元素彼此离多远」读出来的**。`stagger` 的错峰由序号给，`drag` 的相位由链序给，`arc` 的两条轴属于同一个元素；改图里一个点的坐标，成片里所有时刻都不变。

**所以这一档不是「第十三条位移曲线」，是补上第一个空间传播域。** 它与 `trail` 正交：`trail` 增加的是每帧可见的**时间副本数**，`wave` 增加的是每帧参与演算的**空间坐标**。与 `organic` 也正交：那是值域不规则，本档是延迟的几何来源；两者都是「收尾 = 起始」，但一个没有波前、一个有。

最接近「波」的既有写法有三条，但都不成立：

- `stagger` 是**一组元素各自演完整行程并留在终态**，观众读到「逐个出现」；波要的是每个格子只在波前经过的一小段时间里动一下，然后回原位。
- `drag` 的链是**一维序号**，且重参数化后全链在 `dur` 处一起落定；波的每个格子在不同时刻回原位，链尾不会等链头。
- `type.decode` + `stagger` 的「解码波」按锚点逐行锁定文字，落点也是终态；它服务的是可读性，不是几何。

## 三、几何：距离 → 波前 → 紧支撑脉冲 → 端点

难点不是「让几个元素依次动」，而是**延迟不许手写**：作者一旦能给每个元素填一个 `delay`，那串数字就是几何的第二份真源——挪动图里一个点，成片里的波前仍停在旧位置，而且零报错。解法是让生成期直接从 SVG 里量坐标：

```
c₀   = center(origin)                       震中元素的包围盒中心（图上真实元素）
cᵢ   = center(cells[i])                     每个格子 likewise
rᵢ   = |cᵢ − c₀|                            欧氏距离，唯一真源是 SVG 几何
rₘ   = max rᵢ
τᵢ   = span · rᵢ / rₘ                       波前到达时刻，严格随距离单调
sᵢ(t)= (t − τᵢ) / width                     该格子的局部进度
E(s) = sin²(πs),  s∈(0,1)，否则 0            紧支撑脉冲：端点与端点导数精确归零
qᵢ   = (rᵢ − rₘᵢₙ) / (rₘ − rₘᵢₙ)            相对距离，最近格子 0、最远 1
Fᵢ   = exp(−falloff · qᵢ)                   距离衰减，最近精确 1、最远 e^−falloff
aᵢ(t)= amplitude · Fᵢ · E(sᵢ(t))            位移标量，radial 档再乘方向单位向量
```

包围盒走共享的 `_cam_crop._box`（与 `check_svg` 的空带/越界、运镜取景同一份），祖先的 translate/scale 由 `decompose_transform` 复合；旋转/斜切读不准就判废并出声，不猜一个中心。目标元素内部不再折 transform——那要在这里复刻第二套仿射栈，与「真源不分家」相冲。

衰减归一到**最近格子**而不是原点：若写成 `exp(−falloff·rᵢ/rₘ)`，连最近格子都会先被削掉一截，`amplitude` 就不再是「峰值位移」，而成了「峰值位移再乘一个谁也算不准的系数」。归一之后 `amplitude` 就是这一拍真正能达到的最大位移。

**四条设计决定，都是被成片纪律逼出来的**：

**1. 延迟不进契约。** `cells` 只写「哪些元素参与」，`span` 只写「波前扫完整个场用多久」；τᵢ 由 `rᵢ/rₘ` 归一算出，换画幅不改波速。产物里 `tl.set` 的写入顺序是作者给的 `cells` 序（导演意图），峰值时刻却只按距离排——**波前不听序号的话**，这是本档与 `stagger` 最本质的分界，也是判据里专门从产物抠出来对账的一条。

**2. 紧支撑脉冲，不是位移曲线。** `E` 在 `[τᵢ, τᵢ+width]` 之外精确为 0：波前没到时格子完全静止，过去之后精确回原位。于是 `state_at(0) == state_at(D) == 0`，**收尾态 = 起始态**，跨段接续没有残留姿态可折。`drag` 一起落定在 `distance`、`stagger` 逐个留在终态，两者都不会回去——「波过无痕」是这一档独有的语义。

**3. 波必须在拍内收干净。** `span + width ≤ duration` 是生成期硬红线：τᵢ 依赖几何，作者根本没法在写稿时预知最远那排格子什么时候演完。放宽这条，最后一排会在被切到下一段时还在位移，页界一次静默的「半截波」。另有两条地板：`span` 与 `width` 都不得小于一帧，否则波前扫得比渲染帧还快，观众只看见整场一起动。

**4. 至少两个不同距离。** 所有格子等距（比如排成一圈）时 τ 全相同，波退化成「一组同步脉动」——生成期按文件拦，让它改用 `stagger`。这不是参数越界，是**这一拍根本不是波**。

**生成期采样成离散 `tl.set`**，沿用 `morph` / `momentum` / `drag` / `step` / `organic` / `trail` 的老路：渲染端零脚本、零 `onUpdate`、零依赖，成片里是一串确定的数值，逐帧 `seek()` 下每一帧都是时间的纯函数。这一档不收拍级 `ease`：脉冲包络是生成期算死的 sin² 窗，不是 GSAP 缓动，写进去只会静默失效。

**格子与震中必须是图里真实存在的元素**：离散 `tl.set` 没法凭空造 DOM，也不该在渲染端克隆节点（同一张 SVG 内联两份时 id 重复、`url(#id)` 只认第一份，见 `references/motion.md`「跨段接续」）。生成期按文件逐个拦，落空一个不会报错，只会让那一片区域静默不动。

**红线**（写死在 `_wave.py`，不进模板、不给 `--set` 改）：格子数 2～12；衰减强度上限 2.0；最短拍长 0.12s（帧时刻锁两位，短于此会让两个采样撞进同一格）；`span` / `width` 各不小于一帧；`span + width ≤ duration`；`origin` 不能是格子之一或 `#cam`；格子不能与震中重合、不能全都等距。

## 四、被否掉的五个方案

| 方案 | 为什么不收 |
|---|---|
| **渲染端 `onUpdate` 按距离实时算延迟 / AE Echo 式位移场** | 带累计状态，逐帧 `seek()` 下第 N 帧与跳到第 N 帧对不上；Python 侧判据只能退化成对着另一份 JS 自证（`decode.md` / `spring.md` 记过这笔账）。 |
| **GSAP `stagger` 配 `grid` + `from:"center"`** | 延迟按**网格行列号**而非真实欧氏坐标；每个元素演完整行程并留在终态；没有距离衰减也没有波速。它把「波前」藏进 `amount`，改图不会改编排。 |
| **把 `drag` 的链当波用** | 链是一维序号、重参数化后全链一起落定，链尾不会比链头晚回原位；而且它只写位移，没有「波前未到时完全静止」这回事。相位与空间是两个域。 |
| **作者手写每个格子的 `delay`，契约层只收数字** | 几何的第二份真源。挪动图里一个点，成片里的波前仍停在旧位置，且零报错——本档存在的全部理由就是消灭这份手写。 |
| **`trail` 的影子层数当格子数用** | 影子是**同一主体的时间副本**，全部跟着主体跑；波场的格子是不同真实元素，各有自己的到达时刻与幅度。时间叠加与空间传播正交。 |

另外试过、又删掉的一条判据：在产物上做**互相关**去证明「远格子是近格子的延迟副本」。波场的脉冲带距离衰减，两串波形本就不等幅，互相关峰值随 `falloff` 漂移，判据会变成「调衰减就红」。最后改成直接读**波前单调性** `rᵢ < rⱼ ⟹ τᵢ ≤ τⱼ` 与紧支撑残差（恒为 0）——都是结构性事实，不靠在短信号上做谱分析。

## 五、契约与旋钮

一拍写 `wave`，整段负责全部格子。七个旋钮：

| 键 | 默认 | 读什么 |
|---|---|---|
| `cells` | 必填 | 2～12 个有序 `#id`，图里真实存在的一组格子；`cells[0]` 必须等于 step 级 `target` |
| `origin` | 必填 | 单个 `#id`，震中元素；生成期从图上读它的中心，**不写坐标** |
| `axis` | 必填 | `"x"` / `"y"` / `"radial"`：前两档单向位移，`radial` 沿「格子 − 震中」方向推开 |
| `amplitude` | 必填 | 峰值位移（SVG 用户单位，非零）；最近格子精确达到它 |
| `span` | `0.50` | 波前从震中扫到最远格子用多少秒；纯时间量，与画幅无关 |
| `width` | `0.34` | 单个格子被波前经过时动多久 |
| `falloff` | `0.45` | 距离衰减强度；`0` = 全场等幅，最远格子在 `2.0` 时只剩约 13.5% |

```json
{"seg2": {"src": "images/seg2.svg", "animate": {"steps": [
  {"at": 0, "target": "#d1", "duration": 1.2,
   "wave": {"cells": ["#d1", "#d2", "#d3", "#d4"], "origin": "#epicenter",
            "axis": "y", "amplitude": -36, "span": 0.50, "width": 0.34,
            "falloff": 0.45}}
]}}}
```

图里要有一个震中与一组离它远近不同的格子，`cells` 顺序随作者写（只决定产物里 `tl.set` 的写入顺序）：

```svg
<circle id="epicenter" cx="490" cy="367" r="4"/>
<rect id="d1" x="450" y="350" width="20" height="20"/>
<rect id="d2" x="300" y="200" width="20" height="20"/>
<rect id="d3" x="100" y="100" width="20" height="20"/>
<rect id="d4" x="700" y="500" width="20" height="20"/>
```

**互斥**：`wave` 与 `from` / `to` / `set` / `draw` / `morph` / `count` / `type` / `momentum` / `drag` / `step` / `organic` / `trail` / `flow` / `lens` / `swarm` 同拍即 error——两条时间线抢同一条 transform 通道，GSAP 后写的那条静默覆盖前一条。不收 `stagger` / `repeat` / `yoyo` / 拍级 `ease`，不能打在 `#cam`，`origin` 不能是格子之一。

## 六、生成期会拦什么

| 现象 | 级别 | 怎么消 |
|---|---|---|
| 未知键 / 格子数越界 / 重复 id / `origin` 非法 / 与震中重合 / `axis` 非法 | error（契约层） | 只认七个键；红线见上一节 |
| `cells[0]` ≠ step 级 `target` | error（契约层） | 波头就是这一拍的目标，接续烘焙与按文件拦只认 `target` |
| 与别的「演」同拍 / `stagger` / `repeat` / `yoyo` / 拍级 `ease` 挂在 wave 上 | error | 删掉一边；要逐个出现用 `stagger`，要一条链用 `drag` |
| `cells` / `origin` 在 SVG 里找不到 | error（生成期，按文件拦） | 落空一格不会报错，只会让那一片静默不动 |
| 包围盒读不出 / 祖先带 rotate、matrix、skew | error（生成期，按文件拦） | 改成 rect / circle / ellipse / line / polygon / polyline / path / text / image，或包住这些图元的一层 `<g>`；transform 只留 translate / scale |
| 格子全等距 / 与震中重合 | error（生成期） | 排成不同距离；等距是同步脉动，不是波 |
| `span` 或 `width` 小于一帧 / 波没在拍内收干净 | error（生成期） | 加长这一拍或调小 `span` / `width`；否则页界留半截波 |
| 拍长 < 0.12s / 帧时刻撞进同一个 0.01s 格 | error（生成期） | 加长 `duration`；否则产物静默少一帧 |
| 波前没随距离递增 / 脉冲窗不紧支撑 / 远端峰值反而更大 / 端点没收干净 | error（生成期） | 生成期自查会拦，正常配置不会出现 |

## 七、判据落在哪

`tests/test_wave.py` 一个文件压完，判据全部**从产物里抠补间来读**，不在 Python 侧另写一份「应该生成什么」的实现。

| 组 | 钉住什么 |
|---|---|
| 信号 | 纯函数（正序/逆序/乱序一致、窗口外夹回端点）、紧支撑残差恒为 0、端点精确归零、峰值 = `amplitude·Fᵢ` 与距离衰减单调 |
| 传播 | 波前 τ 与峰值时刻严格随**距离**递增、与 `cells` 序号无关；改图里一个坐标，τ 跟着变（改图即改编排） |
| 网格 | 采样带两端、帧时刻严格递增且不撞 0.01s 格、条数 = (帧数+1)×格子数、一帧地板与「波收干净」红线 |
| 契约 | 红线、与其余所有「演」互斥（含后加的流线档与透镜档）、不收错峰/重放/拍级缓动、相机层与自指震中、绕过契约层的坏值在生成期炸 |
| **产物级对账** | 从 HTML 抠出的 `tl.set` 序列，锚点、帧数、逐格选择器与逐帧变量必须与 `_wave.frames` 逐项相等；两画幅各验，两次生成字节相同 |
| 作用域与接续 | 没写 wave 的页零新增补间；`_stage_carry` 显式认这一拍并返回空态（收尾 = 起始，无残留） |

「改图即改编排」是本档独有的一条判据：把最远那个格子往震中挪一半，产物里它的波前时刻必须提前，其余格子的不变。既有档位全都不读坐标，所以不可能有这条。

## 八、什么时候不要

- **一组元素要逐个出现并留在画面上**：用 `stagger`；要逐行锁定结论文字，用 `references/decode.md`。波场档演完所有格子都回原位，读完就散。
- **要一整片元素沿一条画好的曲线持续走、各处朝不同方向拐弯并落在新位置**：用 `references/flow.md`。波场档给的是「谁先动」的延迟，流线档给的是「往哪走」的方向与一个有几何来源的落点。
- **要一枚透镜扫过画面、同一元素的位移方向在这一拍之内跟着转，扫完精确回原位**：用 `references/lens.md`。波场档的方向由固定震中一次定死，透镜档的方向是场心当前位置的函数。
- **要主体带动一条真实元素的链、全链一起落定**：用 `references/drag.md`。波场档的每个格子自己回原位，链尾不等链头。
- **要一帧里同时看见主体的几个过去**：用 `references/trail.md`。那是时间叠加，本档是空间传播。
- **要到位停住 / 安静的落位**：用 `.out` 档或 `spring`。波场档整段都在传，收尾确实干净，但中途不该背着一串起伏去落位。
- **文字 / 数据图 / 只有两三个元素**：本档只写 `x` / `y`，逐字揭示与数字滚动各有自己的整段语义；两三个点排不出波前，读成「抖了两下」。
- **一屏同时动的不超过三处**：波场档一开就是一整片格子在动，别再叠一层 `organic` 呼吸或 `hold` 慢推。先问 `--perceptual` 的四道验收够不够。
