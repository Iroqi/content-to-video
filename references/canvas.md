# 第 3 步 · SVG：把画面画对

**怎么画**（几何、密度、对比度、字号、数据自查）→ 本文件。**怎么让它跟着话变**（`animate` 的拍法、镜头、参数演绎、跨段接续）→ `references/motion.md`。

> **动笔前先读这五节**：「画布几何」「不铺满幅底」「图内文字的对比度」「数据图的几何自查」「文字与尺寸」——画错不会有任何报错，只在成片上看出来。整页画布（`layout:"canvas"`）再加「整页画布的密度与层次」。选不选 SVG 见 `references/writing.md`「哪些段值得交给 canvas」与 `references/imagery.md`；画面出问题按 `references/troubleshooting.md`查。

## SVG 矢量示意图

数据图、公式、示意图走这一条；不带文字的画面先走生图。**图不等于简笔线框图**：渐变、光影层次、等距视角、装饰细节都该上。

数据红线：数字直接来自信源或可追溯数据源，估算值标出来；不用截断坐标轴、面积失真这类误导性比例，不藏单位；不编造数据点。

来源三条，手绘优先：**手绘 `.svg` 放进 `images/`**；**官方 registry 现成块**（`npx hyperframes catalog --query "<英文效果>"`——查询必须英文，中文返回空且不提示——再 `hyperframes add <name>` 装，进导演档要重写成补间驱动，不许墙钟动画与 `Math.random`）；**SVG 图库**（logo/图标用 simple-icons、lucide、tabler，同一期同一套、统一线宽，来源与 license 记进 provenance）。

要不要动、怎么动见 `references/motion.md`（该不该动看「四职务」，怎么写看「契约」）。映射走 `{"seg4": {"src": "images/seg4.svg"}}`——外部 SVG 以 `<img>` 载入（内部脚本不执行）。

### 画布几何：根节点尺寸按版式分两种

**先看这段是哪种 `layout`，两种根节点尺寸不一样，写错判 error。**

| 版式 | 根节点尺寸（竖屏） | 横屏 | 比例 | 门禁 |
| --- | --- | --- | --- | --- |
| 槽位（不写 `layout`，默认） | 980×735 | 1067×800 | 4:3 | `check_svg.py`（默认档） |
| 整页画布（`layout: "canvas"`） | 1080×1440 | 1920×1080 | 3:4 / 16:9 | `check_svg.py --layout canvas --aspect ...` |

槽位版式写死在根节点上：

```svg
<svg xmlns="http://www.w3.org/2000/svg" width="980" height="735" viewBox="0 0 980 735">
```

画布 `cover` 铺满：viewBox 不是 4:3 时短边对齐、长边居中裁掉，贴边的文字/图例/描边会缺一块——改根节点尺寸再重排，**别靠缩内容凑比例**。图库图标（24×24）只能套进 `<g transform="translate(…) scale(…)">` 当画布里的一个元素。

**整页画布写当前画幅原生尺寸**（见上表，不是 4:3）——照 980×735 画会被 `check_svg --layout canvas` 判"根节点比例不是 3:4"拒收。真源是 `scripts/_template.py` 的 `canvas.vertical` / `canvas.landscape`，**别手写 px 当权威值**，用 `canvas_kit.py` 出图自带门禁自查。整页画布不 `cover` 裁切、整幅铺满，viewBox 与画幅不一致时整张图被拉变形。

**图内两行文字压字只有 `hyperframes check` 能量到**（Layout 阶段 `content_overlap`）。最常踩 `canvas_kit` 的 `bars`：数值标签写在 `base_y + label 档字号`，下方再起一行只差十来像素——留够一行字号（`TIERS` 最大档 1.2 倍）。

画完跑 `python scripts/check_svg.py images/`（整页画布加 `--layout canvas --aspect portrait|landscape`，**档位与稿件对得上**；混用给 `--layout auto`）。它管不到三处：文字溢出、互相压字、刻度与比例。

### 不铺满幅底

根节点下**不要写铺满 viewBox 的底板**（`<rect>` / `<polygon>` / `<path>` 三种写法一样算满幅）。确实要自画满幅底（浅色页、照片感场景）时忽略那条 `[warn]` 即可。

`check_svg.py` 与生成期 `gen_hyperframes` 按**同一份判据**打 `[warn]`。判不了的两类留给真浏览器：CSS class 控宽高的 `<rect>`，以及 98% 阈值之下的"几乎满幅"。

透明处透出主题渐变与该段 `--seg-accent` 的氛围光。三条连带：

- **图内留白从此算版式**：竖屏槽位左边缘正落在 `segCard.padding` 的 50px 轴上，图内再缩进 60 就是 110px，明显不同轴。要么缩进收到 0，要么明确当图例、不追求对齐。
- **图内文字只在起指示作用时才写**：轴标签、刻度、单位、数值、图例、步骤名——判据是"不写这行字就读不出这张图"。**标题不在其中**。
- **局部底板照旧可画**，取消的只是"整幅满铺"。

### 图内文字的对比度：定色在前，自查在后

**SVG 以 `<img>` 载入，内部文字不属于 HTML 文本流，没有任何一道检查会量它**，所以取色要按下面的表。

要机器量对比度/压字：把该 SVG **内容**临时内联成 DOM 副本跑 `hyperframes check`。**副本只用来问门禁，绝不能当产物**——交付的 `index.html` 必须保持 `<img>` 形态。**唯一例外**是写了 `animate` 的那张：交付时就是内联活 DOM，内联前必过 `scripts/_svg_sanitize.py` 净化（见 `references/motion.md`「契约」）。

**判定线**（WCAG）：正文与标签 ≥ 4.5:1；最大字号档（≥24px，或 ≥18.66px 加粗）≥ 3:1，低于 3:1 重画；次要文字按 ≥ 7:1 取色。

**深色主题取色表**（底 = 页面渐变叠上该段 accent 辉光；**页底**列不叠辉光，**最坏**列是全部预置 accent × 渐变 stop × 竖屏 15%/横屏 13% 全组合的最低值）：

| 用途 | 取色 | 对比度 |
|---|---|---|
| 图内最大字号 | `#f2f6fc` | 页底 17.7–18.6，最坏 12.7 |
| 主标签 | `#dbe6f5` | 页底 15.2–16.0，最坏 10.9 |
| 次要说明下限 | `#a8bdd6` | 最坏 7.2，刚好守住 ≥7 |
| 不要用 | `#6b7c93` | 页底 4.5–4.7、最坏 3.2，两档都越线 |
| 不要当文字色 | `#060709` `#0d0f13` `#080a0c`（页底渐变各档） | 1.0:1，出现在 `fill` 上就是瞎字 |

**三条最常踩的**：

- **深色文字只能待在明确的浅色底板上**：符号常写成近黑 `#0c1320` 摆到浅色渐变圆盘上（圆盘上 15.1:1），圆盘一挪或换了渐变立刻瞎掉。改任何底板颜色都要复核压在它上面的文字；`fill` 能就近写死就别靠 `<g>` 继承。
- **页底色不得当文字色**：填充色只要对主题渐变最坏一档低于 3:1 就是瞎字。`check_svg.py` 对字面 hex 填充按最坏一档逐一算 WCAG：槽位版式低于 3:1 判 error、低于 4.5:1 判 warn，**整页画布只 warn**——**这一档门禁数不到渐变底、`class` 里的色、局部底板上的字**，那三种只能靠上面的取色表。
- **半透明按合成后的颜色算**：50% 的 `#dbe6f5` 叠在 `#0c1320` 上合成 `#747c8a`，只剩 4.4:1。要弱化文字就换更暗的实色。唯一例外是导演元素 `opacity="0"`——那是**起始态**（终帧才亮），`0.1~0.79` 中间档照报。

### 整页画布：这一张 SVG 就是整个画面

段落 `layout: "canvas"`（结构性页走顶层 `opening_layout` / `closing_layout`）。字段语义见 `references/writing.md` 段落 `layout`；版式与门禁变化见 `references/look.md`「画面结构」。

**什么时候换整页**：选型判据（一个画面能不能讲清一件事、配比下限）见 `references/writing.md`「先定编排」；本节只讲换整页之后的渲染事实。

**整页画布不演怎么写**：整页画布**不等于**必须逐拍演——`layout:"canvas"` 只承诺"这张图就是整个画面"，不承诺手绘、不承诺逐拍（判据见 `references/writing.md`「先定编排」）。两种合法写法：**静态 SVG**（一个画面讲清一件事）与**栅格图**（照片／生图）。两者都只铺满、不变形，不写 `animate` 就不会逐拍动。

但门禁**不替你兜底**：画布档只校验 SVG，**栅格图只 warn 不拦**——比例（画幅原生尺寸见上表）与最小字号（26px）得你自己保证，check_svg 管不到。写成 SVG 时这两项由 `check_svg.py --layout canvas` 按档位验。

**和槽位版式只有六处不同**：

1. **几何换成整个画幅**（尺寸见上表）。两画幅都要出片就**各画一张**（生成期按文件验：根标签读不出纯数字 `width/height`/`viewBox`，或比例与画幅不等比，直接 exit 1）。
2. **按画幅原尺寸画**：成片按 `画幅宽 ÷ viewBox 宽` 整体缩放。按 2560×1440 画的 16:9 塞进 1920 画幅，28px 折算只剩 21px——跌破下限就读不出来。字号写成 px 才验得到；写 `em`/`%`/class 时只在图真被缩小（viewBox 宽 > 画幅宽）时打 `[warn]`。
3. **安全边距照页面走**：竖屏四周 50px、横屏 96px。`text-anchor="end"` 的落点按量出来的字宽倒推，不按字符数估（量法见「数据图的几何自查」）。
4. **"不铺满幅底"在这里更要紧**：留透明才能透出模板那三层背景。
5. **图内可以有标题，字号按整页读**：标题 72–76px、小标题 38–48px、正文 30–40px、kicker/图例 26–28px。字越大越要自己复查对比度——**这一版的 `Contrast` 门禁数不到你**。字体名写死（`'Microsoft YaHei','PingFang SC',…`）：`<img>` 载入读不到页面 `--ctv-font-*` 变量。生成期那条 `[warn]`（"该段 N 句旁白不会上画面 / 这张 SVG 里有 M 个 `<text>`"）是"要点有没有画进图里"唯一的机械判据。
6. **机械劳动交给脚手架**：`python scripts/canvas_kit.py --spec spec.json --aspect portrait -o images/seg1.svg` 吐一张按画幅原生尺寸画的透明底画布 + 一份能塞进 images.json `animate` 的 steps 草稿（`--emit-steps` 另存；落在技能目录内会被守卫拦，先 `cd` 到项目目录）。**完整 spec 与七种 kind 的最小片段在 `python scripts/canvas_kit.py --help`**；写错时当场列出该 kind 的合法键与必填键。最小骨架：

```json
{
  "aspect": "portrait",
  "elements": [
    {"kind": "text", "id": "t", "x": 80, "y": 200, "content": "季度营收", "tier": "title"}
  ]
}
```

动笔前有两件报错替代不了的事：**`axis` 的 `from`/`to` 是轴两端的像素坐标、不是起止数据值**（竖轴把较大的 y 写在 `from`、数值就朝上长；`at` 是那条轴所在的像素线）；**`tier` 只有三档**（要更大的字就手写 SVG 绕过脚手架）。

   **它只收机械部分**（画布几何、三档字号、线宽、取色压暗、初始 `opacity` 分档——`draw`/`count`/`type` 不写 `opacity="0"`，写了就永远不亮）。`duration`/`ease`/`stagger`/`repeat`/`yoyo` 写进元素即可（`yoyo` 必须带 `repeat`）；`roughness` 0–10 只作用于 `panel`/`polyline`/`bars`/`circle`/`rule` 的坐标（按 `roughness × 该画幅线宽` seeded 抖动），**坐标轴与文字不吃这个键**。

   **给上 `--sentences <该段句数>`，草稿才真能用**：不给时按元素顺序一路 `at=0,1,2…`，内容元素比旁白句子多时最后几拍落到句序之外，生成期按 `error` 整条拒掉（"at=N 越界：该段只有 M 句旁白"）。给了句数，游标按它取模回绕；**显式钉拍**（元素里写 `beat`）的越界提前打 `[warn]`。`--emit-steps <path>` 另存 `{"steps": […]}`，直接当 `"animate"` 的值。

照片当画布不做比例与字号校验，但该段整段时间屏幕上不出现任何标题——生成期照样给一条 `[warn]`。想留标题就把要点画成 SVG；确实要"只有画面"的过场，忽略它。

### 整页画布的密度与层次：这一页经得起暂停吗

判据不是"画了多少个元素"，是**随便暂停一帧，画面还成不成立**。用 `npx -y hyperframes snapshot --at <秒>` 截出来看。

- **竖向不许有整条空带**（`check_svg.py --layout canvas` 会 warn，阈值 25% 页高）：标题在上 1/4、主视觉占中部并**撑到接近页宽**（≥70% 页宽、≥45% 页高）、注脚与结论压在下 1/4，三段之间用中景元素连起来。
- **一页至少三层**：背景层（模板那三层，别铺满幅底盖掉）、中景（主视觉 + 局部底板/面板/分隔带，自身也有"面板 < 底板 < 页底"三档）、前景（标注文字、数值、accent 强调）。辅助线敢用亮档：轴线/网格/分隔线不低于 `#64748b`、线宽 ≥3px——层次靠**明度差与大小差**，不靠透明度。
- **字号最多三档 + 一档 accent**（脚手架竖屏 64/40/32、横屏 62/33/28；最大档与最小档比值 ≥2）。一个 accent 负责"现在看这里"，其余走中性灰阶。
- **数信息单元**：一页有几个独立可看的东西（一块图、一行结论、一组标注各算一个）？**少于 3 个就别当整页画布做**——那本质是字卡，按海报重写或退回槽位。
- **导演页还要看"起始帧"**：前 1 秒画面是空的，而整页画布**没有转场遮这一下**（见 `references/look.md`「动画：实现要点」）。只要不铺满幅底，第一帧至少不是死平一块色；把**结构底**（坐标轴、外框、分隔带、面板格子）不写进 `animate.steps`，让它和页面同时到位、只逐拍长"内容"，或把第一拍放在 `at_time` 0.1s。这是**生成期门禁**：所有可渲染元素都从 `opacity=0` / `visibility:hidden` 起步时，`gen_hyperframes` 按段落打 `[warn]`「起始帧全空」。

### 字幕层：页底留一条给旁白

整页画布默认带**一条页底字幕**（`subtitle:true`，不写就是开）。它不改构图：不放标题、不画 tagline、不进 SVG。关掉它写 `"subtitle": false`，画面上就只剩你画的那张图。

两种写法是同一页，不是两种版式：

| 写法 | 屏幕上有什么 |
|---|---|
| `layout:"canvas"`（默认） | 你画的整页 + 页底一句字幕 |
| `layout:"canvas", "subtitle": false` | 只有你画的整页 |
| `layout:"plate"` | 内容段写它当场报错，改法就是上两行之一 |

**页底那一条要留空**：字幕带占页高 **竖屏 216px**（两行窗 132px ＋ 页底内边距 84px）、**横屏 177px**（113px ＋ 64px）；页顶不用留——画布上没有标题层。**安全边距**：竖屏左右 50px、横屏 96px（与 `check_svg.py` 同一条）；**下边距**在开字幕时留 **≥220px**（竖屏）/ **≥180px**（横屏），把结论句画在这条之上。

**它怎么动**：一屏一句，换句时整列上移一格、首句不滚（口径与句子流同源：`subtitle.relay` 与 `subtitle.scroll.ease`）。不做焦点衰减。

**写稿侧**：字幕单句 ≤ 两行（竖屏 42px 字号下约 44 字），超了生成期报 `error`——它不是"滚进来"，而是被 CSS 钳掉。要更长的句子就拆句。

**什么时候关**：这一页本身就是一张海报（章首、金句、结尾），字已经画在图里；或者旁白只是陪衬的氛围段。**别在同一支片子里一会儿开一会儿关**。

### 数据图的几何自查

手绘数据图（柱状、折线、饼环、散点、时间轴）里**长度/角度/坐标本身就是数据**，而这条错误链上没有任何检查看得到：

- **先定标尺，再画图形**：映射写成一行线性式（`y = y0 - (v - vmin) * (h / (vmax - vmin))`）放进 SVG 注释，所有柱高/点位由它反算，不凭手感调。刻度取整档（1/2/5×10ⁿ），别为了对齐图形改数据。
- **用两端点回算验证每一档**：最大值柱顶减最小值柱顶应等于"量程 × 标尺"，对不上是映射写错。**pie / 环形先查总和**：各扇区角度相加必须等于 360（`占比 × 3.6`）。
- **量文字，不数文字**：定宽元素（刻度、数值标签、图例）按实测宽度排版——`text-anchor="end"` 的落点倒推字宽。两条量法：浏览器 `getBBox()` 读左右缘，或 `npx -y hyperframes snapshot` 按时刻截一帧（命令见 `references/rendering.md`「官方校验命令」）。整页画布安全边距（竖屏 50px / 横屏 96px）同样按量出来的右缘判。
- **公式就是图内文字**：`E = mc^2` 这类本体用 `<text>` 画——上下标靠 `baseline-shift` 或两个 `<tspan dy>`，字体栈照「文字与尺寸」，下标字号同样受 26px 下限约束。

### 文字与尺寸

图内文字按"**进入内容画布后**的最终可读性"设计，不是按原始文件尺寸设计。

图内只有起指示作用的文字，**没有"标题"这一档**；最大一档 35–40px 给图例名或底板大字，正文级从 35px 起步（槽位按 980×735、整页画布按当前画幅原生尺寸）；内容很密就优先减少文字、扩大图形。**26px 是下限**：宁可换行或加长底板，也别缩字号。底板内还要**估一次宽度**：一行汉字数 ≈（容器宽 − 左右内边距）÷ 字号；980 画布留 48px 内边距、52px 字号 → 一行约 17 个汉字，溢出时换行或加宽底板。

SVG 以 `<img>` 载入时是独立文档，页面 `--ctv-font-family` 渗不进去，`<style>` 里要自带中文无衬线字体栈（`"Microsoft YaHei", "PingFang SC", "Noto Sans SC", "Noto Sans CJK SC", "Noto Sans CJK JP", sans-serif`——Linux 沙箱里 `Noto Sans SC` 会回落到无 CJK 字形的 NotoSans-Regular，`Noto Sans CJK SC/JP` 才是能匹配上的名字，别省）。
