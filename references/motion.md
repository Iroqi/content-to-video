# 第 3 步 · 动效与 SVG 编排

**"演什么"在第 1 步就定了**（`beats` 写在稿件里）。画图 → `canvas.md`；转场入场 → `look.md`；官方校验 → `rendering.md`。

## 一、该不该动

### 先写台词板，再写补间

动笔前先把**这一段在第几句旁白时画面变成什么**写成表（`segments_source.json` 的 `beats`）：

```json
{"id": "seg3", "text": "先看左边这个状态。然后它变成了右边这个状态。合起来就是答案。",
 "beats": ["点亮左侧的状态", "把左侧压暗、点亮右侧", "两条并成一条"]}
```

简写时**下标即句序**；跳句用全写 `[{"on": 0, "change": "…"}, {"on": 2, "change": "…"}]`——两种写法不可混用（"第几拍"有两个来源，契约层拒）。

- `on` 必填：没有门禁替你兜住（`check` 只证明能渲、`--perceptual` 只知道画面在动）。**句序在写稿时就定了**（只按终止标点切，见 `_text.split_sentences`），配音不改句子也不改编号；`run.py` 生成 HTML 前再核越界只是兜底，exit 2。
- 台词板写意图，`animate.steps` 写实现：写属性名、时长、缓动会被拒（`change` 超 60 字即视为在实现层写东西）；只声明不实现被 `run.py` 点名 warn。

### 四职务：每条补间都要能说出它在替观众做什么

只说得出"好看"的那条就是该删的那条。成片逐帧 seek，没有鼠标也没有 hover——看到"点了一下"的手感，就是预览逻辑漏进时间线了。

| 职务 | 回答 | 例子 | 反例 |
|---|---|---|---|
| 引导视线 | 现在该看哪里 | 焦点衰减五维、karaoke、入场后收拢 | 无休止漂浮/呼吸 |
| 展示变化 | 什么变成了什么 | 元素补间、`morph`、`count`、`draw`、跨段接续 | 弹一下又弹回去 |
| 推进叙事 | 接下来发生了什么 | 段落 wipe（几何档两页反向运动，见 `look.md`）、整页画布推镜、标题揭示边 | 与内容无关的花活 |
| 操作反馈 | 我刚那下生效没有 | **只在网页预览**（`preview.js`） | 把这份手感带进成片 |

### 三条减法

1. **一屏一件事**：先定"最想让人看懂的一件事"再排先后。
2. **删掉与当前重点无关的干扰**：同屏同时动的不超过三处。
3. **不一次铺满**：最想让人先看到的排最先，其余错峰。

### 快慢、缓动按内容定

- **快慢看信息量**：只变一个元素 0.3~0.6s；要读完一段结构 1.0~1.6s。全片不套同一时长。
- **落点看句读**：补间落在重音上，用 `at` 跟 manifest 走；`at_time` 留给不跟旁白的拍。
- **缓动看语义**：到位停住用 `.out`；持续变化用 `sine.inOut`；`back`/`elastic`/`bounce` **只在"这件事本身意外"时**用——标题逐字弹、图标弹、数字弹都是机械感来源。
#### 曲线的行程预算：`expo` 不是"高级"，它要够长的路

下表是钉固 GSAP 的逐点实采（`_ease.curve`）：**末段要慢**（走完 90% ≤ 全程 50%，54% 已读成匀速滑行）；**过冲落在起点方向**（从下面上来再弹一下是"抖"不是"弹"）。

| 档 | 行程 2% 时 | 行程 50% 时 | 走完 90% 用了 | 用途 |
|---|---|---|---|---|
| `power4.out` | 9.6% | 96.9% | 37% 时长 | 大行程的重量感 |
| `power3.out` | 7.8% | 93.8% | 44% 时长 | 标题/图块落定（缺省） |
| `power2.out` | 5.4% | 87.5% | 54% 时长 | 小幅进出 |
| `sine.out` | 3.9% | 70.7% | 中段仍在动 | 持续变化 |
| `expo.out` | **12.9%** | **97.7%** | 23% 时长 | 只有长行程配它 |

> **硬判据**：补间的首帧位移（1/fps 秒内走过的距离）≥ **4px**。反算：0.5s@30fps，`expo.out` 要 ≥31px、`power3.out` 要 ≥20px。均由 `tests/test_motion_design.py` 按 GSAP 实采样钉住。

#### 位移走弧线，不只走一条轴

**两条轴各配一条缓动**就够造弧：`P(t) = (A·(1 − f_主(t)),  B·(1 − f_副(t)))`，终点在 `(0,0)`。两轴**同缓动**时 P 恒落在「起点→终点」那条弦上，垂距恒为 0——副轴等于没写。主轴吃"重"的那条（`.out`），副轴吃中段最快的（`sine.inOut`），合成一条 C 形弧。

判据三条，由 `tests/test_motion_design.py` 按 GSAP 实采样钉住：

| 判据 | 阈值 | 它拦的是什么 |
|---|---|---|
| 弯曲度（路径离弦的最远距离） | ≥ 4px 且 ≥ 弦长 10% | 两轴同缓动（恒为 0）、副轴幅度太小 |
| 弧顶时刻 | 落在行程 20%~80% | 贴着端点＝两段动作首尾相接，那是折线不是弧 |
| 副轴幅度 / 主轴幅度 | 0.20 ~ 0.45 | 太小读不出弯；太大"从斜下方飞进来" |

**不走弧的地方**：标题与副标题（揭示边要求**文字盒左缘站定不动**）；字幕换句（位移只写在列容器上）。

模板落地在配图容器入场（`_frame_arc_lines`）：主轴 `y` 用 `imageEntrance.ease`，副轴 `x` 用 `arc.ease`，**同起点同时长**。幅度只有一个真源（`arc.x`，写 0 关掉这层），`arc.rhythm` 只轮换向。

#### 同屏几层，就排几个先后：入场阶梯

“不一次铺满”落在模板上是一条**阶梯**：题头组（标题 → 副标题）先走，画面（配图）在题头组末拍之后再晚一个步距（`entranceLadder.step`，默认 `0.14`），层序按**读序**。同时开始的两层在观众眼里是**一层**——错峰等于没写。

判据由 `tests/test_motion_design.py` 钉在产物时刻上：相邻层间隔 ≥2 帧且 ≤0.30s；层序严格递增；后一拍压在前一拍**行程里**（首尾相接＝逐条出现）。

#### 入场的两维节奏：快慢与疏密

2 秒的段要干脆利落，8 秒的段要慢慢铺开——观众读到的是"这一页的呼吸和那一页不同"。入场因此拆成**两个互不干涉**的旋钮：

| 维度 | 读什么 | 旋钮（默认） |
|---|---|---|
| **快慢** | 每一拍**演多久** | `entranceBudget`：`normSeconds` 4.0、`calmSeconds` 12.0、`calmFactor` 1.25 |
| **疏密** | 各拍**隔多远** | `entranceLadder`：`step` 0.14、`spread` 0.12、`fromSeconds` 4.0、`toSeconds` 12.0、`maxStep` 0.30 |

**为什么必须分开**：若间隔也跟着拍长等比缩放，各层相对位置与整体时长同比伸缩，看起来只是"整体快一点/慢一点"——密度没变，读到的仍是均匀节奏。两条曲线**各走各的**，改一个不许动另一个。

- **快慢**：≤4s 压紧（地板 `minFactor` 0.45），>4s 线性铺开，到 12s 收在 1.25 倍**封顶**——再长的段也不该慢成"卡住"。
- **疏密**：步距在 4s→12s 由 0.14 拉到 0.26（`spread`），**只拉开不收紧**：短段拍子本就短，密度够了；压到一帧以内等于把这一层关掉——"看得出先后"是感知下限。上限 `maxStep` 0.30s，之上就是逐条出现，一页 PPT。

判据在 `tests/test_rhythm_density.py`。

**哪些地方没有阶梯**：满幅页、接续页、开屏（苹果 stagger 自有一套）、并置对比的两格。

#### 场景相连：页界不留主体真空

页界不是"翻页"，是**两个场景交叠**：旧的一边退场，新的里边已经在演。画布带被擦开时里面如果是空的，就是"翻过一页空纸"。

此前配图容器的入场补间带 `opacity:0` 门控，等于让画面在揭盖**之后**再出现：页界处实测留下 0.46~0.70s 真空。现在**画面在场交给页面自己的 `clip-path` 揭盖承担**——揭盖擦到哪儿画面到哪儿；容器补间只管**落位**（`y` + 弧线副轴），落位起点仍排在题头组之后，读序红线照旧。

判据在 `tests/test_scene_link.py`：落位不带 `opacity` 门控、落位不早于揭盖、退场与揭盖锚在同一点。

#### 一组元素逐个出场：定窗口、曲线、锚点

同一拍上有一组元素（标题逐字、agenda 行、图里 `.class`）要逐个出场时，三件事按顺序定：**多久演完**（`amount` 窗口）、**间距怎么分**（`ease` 曲线）、**从哪一头起**（`from` 锚点）。四个锚点各读成什么、三条静默失效的写法见 `stagger.md`。


## 二、怎么写这一拍

### 一条判据：写字还是不写

`images.json` 里某一段的 `animate` 就是这一页的编排。**不写 = 静图**：SVG 按 `<img>` 载入，内部脚本不执行。写了就净化内联成活 DOM，由 GSAP 按句子时间轴驱动。

| 画面的变化要 | 写法 |
|---|---|
| 对上某句旁白（第 3 句说到时才变色） | 写 `animate`：净化内联成活 DOM，GSAP 按 `timing_manifest` 逐句驱动，逐帧可复现 |
| 自己走（CSS `@keyframes` / SMIL 氛围循环） | 不写 `animate`；墙钟动画与口播无关、逐帧不可复现，`check_svg.py` 会 warn |
| 完全不动 | 不写 `animate`。不需要为"这一页要静"另加开关——静就是没写 |

同一张图"先静、后动"不必另设开关：第一拍放在要动的那句话上。

### 契约

```json
{"seg4": {"src": "images/seg4.svg", "animate": {"steps": [
  {"at": 0, "target": "#node-a", "set": {"opacity": 1}},
  {"at": 1, "target": "#cam", "to": {"scale": 2.2, "svgOrigin": "500 360"}, "duration": 1.5},
  {"at": 2, "target": ".row", "from": {"opacity": 0, "y": 16},
   "to": {"opacity": 1, "y": 0}, "stagger": 0.12}]}}}
```

块级只认三个键：`steps`（必填、非空）、`params` 与 `bind`（一起写或一起省，写法见「参数演绎」）。`panes[i]` 里的分格编排同一条契约，每格各写各的。`steps` 每一拍二选一：

| 这一拍要 | 写法 | 需要 |
|---|---|---|
| 改某个元素 | `target` + 补间变量（`to`/`from`/`set`/`draw`/`morph`/`count`/`type`） | 目标元素的 `#id` 或 `.class` |
| 推一个参数 | `param` + 数值 `to` | 块级 `params` + `bind` |

例子里 `#cam` 那拍是运镜，只属于满幅版式（`layout:"canvas"`），槽位页照抄生成期即拦（见「镜头」）。

#### 拍级键

| 键 | 规则 |
|---|---|
| `at` | 该段第几句（0 基，小数 = 句内偏移）。整数准，小数按字长线性猜（无词级时间戳，长句偏到 1s 量级）——拆句。精确卡首拍用 `at_time` |
| `at_time` | 与 `at` 二选一（都写或都不写都报错）。数字 = 段内绝对秒，`"+0.5"` = 上一条之后 0.5 秒。**与语音无绑定**，改句长或动 `--gap` 会整体错位 |
| `target` | 图内单个 `#id` 或 `.class`（作用域收到 `#img-<sid>`），不收逗号/后代/伪类。落空不报错、只静默没动画，生成期按文件拦成 error |
| `draw` | 描边自绘（目标必须带 `stroke`）。收起态要写在段起点，否则切页第一秒线先亮满再缩回去 |
| `morph` | 同拓扑 path 形变：命令序列与每命令数值个数一致，`from` 等于 SVG 里的 `d` |
| `set` / `to` / `from` | GSAP 补间变量，至少一个。只收 JSON 可序列化值；非 CSS 属性走 `attr:{}`（**必须是对象**，标量会在跨段烘焙时被当 CSS 写进 `style`）。禁一切 `on*` 回调 |
| `count` | 数字滚动（`to`/`from`/`decimals`/`prefix`/`suffix`/`odometer`），target 指 `<text>`。**整段替换**：单位单独包一层（见下）。`odometer:true` 走表：个位滚满十位才进 |
| `type` | 揭示 `<text>` 现成文本：缺省逐字；`{"chunk":"word"}` 按单元跳（见下） |
| `stagger` | 配 `.class` 目标错峰揭示，只对有补间的拍生效。一组元素写对象形式：**窗口 + 分配曲线 + 锚点**（见 `stagger.md`）|
| `duration` / `ease` / `delay` | 缺省取模板 `animation.animate`。**只能写拍级**，塞进补间变量表会被拒 |
| `repeat` / `yoyo` | `repeat:N` = 再演 N 遍（`-1` 是 error：循环须在片长内收尾），跨度按 `duration × 遍数` |

`param` 拍只收窄表：`at` / `at_time` / `param` / `from` / `to` / `duration` / `ease` / `delay`。

#### 数字带单位：数字单独包一层

`count` 与 `type` 都靠 `textContent = …` 写入，那是**整条子树替换**——同一 `<text>` 里的 `<tspan>` 会在第一帧之前被抹掉（`f()` 建时间线时无条件调一次）。所以下面这条是错的（成片滚出 `1286`，"万"没了，量级差 10⁴，而生成期本来全绿）：

```svg
<text id="num">0<tspan font-size="72"> 万</tspan></text>          <!-- 错 -->
<text><tspan id="num">0</tspan><tspan font-size="72"> 万</tspan></text>  <!-- 对 -->
```

`target` 指 `#num`，单位那段留在外面不动；字号/颜色的差别由 `<tspan>` 自己带。生成期读 SVG 原文树形，命中带 `<tspan>` 的 `<text>` 直接 error（判据见 `tests/test_animate_timeline.py` `CountEatsLabel`）。

同一件事的另外两面：`prefix`/`suffix` 是**纯文本**（不能带样式），要样式就分开包；接续页烘焙同一个语义，这条错了在页界处不是"回弹"，是"字从来就不在"。

### 镜头：谁能调机位

只有**版面归作者的满幅版式**（`layout:"canvas"`）能写相机键（`svgOrigin` / `scale` / `rotation` / `x` / `y`）；槽位页与分格页构图归模板，契约层 error。

要动的场景包进 `<g id="cam">`，补间它的 `scale` / `x` / `y`；`#cam` 里只放主视觉——标题与结论句跟着推会被推出画。未写 `svgOrigin` 时钉本页 `#cam` 并集的中心。留白按**推完那一帧**算：生成期按收尾位把内容投影回画幅，出画打 warn。两层视差同法：背景 `scale:1.05`、主视觉 `scale:1.3`。

### 六种够用的演法

- **运镜**：见上一节。整段只有一个连续动作时，一拍到底比拆三拍稳。
- **自绘 / 数字 / 逐字**：`draw:true` 配 `stagger` 错峰，不必手写递增的 `at`；数字与逐字用 `count` / `type`。跨档位的数（`9→10`、`99→100`）加 `odometer:true`：整片滚时高位是从无到有长出来的。字多的句子改 `type:{"chunk":"word"}`：一次露一个短语（拉丁整词、CJK 两字、空白与标点并前），每组 ≥0.12s 才读得出逐格。
- **自由场景**：`layout:"canvas"` 不生成标题层与句子流，整屏都是舞台——**第一拍要尽早落子**（0.1s 量级），否则切过来是一块空画布。晚于段起点也行，渲染器会在段起点给带 `from` 的目标前置一次 `tl.set`。

- **形变 / 立体感**：同拓扑 `morph` 演 A 态到 B 态；立体感手算投影多边形再 `morph` 串姿态。
- **呼吸 / 聚光**：呼吸 = 一条拍配 `repeat`/`yoyo`、`duration` 0.4~0.7s、遍数写死；聚光压暗对照组比点亮主角省。
- **歪一点**：给元素 `rotation:-4`，别转相机（整页文字一起斜读作"页面坏了"）。
### 参数演绎：一拍推一个量，几何自己算

属性补间是**属性级**的：三个元素一起动就写三条。场景里有**一个主参数**（把 θ 从 0 转到 2π）时改用 `params` + `bind`，几何每帧按参数真值重算。

| 键 | 规则 |
|---|---|
| `params` | 参数名 → 初值。名字要能直接当标识符（字母或下划线开头，≤32 字符）。**SVG 静态值要与初值对齐**（`#tip cx="750"` 而 `theta=0` 也算出 750），否则第一拍前画面跳一下，生成期打 warn 报差值 |
| `steps` | 一拍只写"把哪个参数推到多少"，`duration` 必须 > 0（写 0 等于瞬跳，契约层拒）。**多拍累进**：后一拍起点是前一拍终值（写了 `from` 则以它为准） |
| `bind` | 一条绑定算**一个属性**。`attr` 只收几何属性：`x y cx cy r rx ry x1 y1 x2 y2 width height transform`；`d` / `points` 是复合几何，颜色与透明度走属性补间 |
| `expr` | 算术 `+ - * / % ^ **`（`^` 乘方、右结合）、常量 `pi tau e`、函数 `sin cos tan asin acos atan sqrt abs floor ceil round exp log min max pow`、已声明的参数。**别的都不收**：没有属性访问、下标、lambda、字符串、`random` 或时间函数（逐帧 seek 下不确定的两帧就对不上）。上限 240 字符 |

```json
{"seg2": {"src": "images/seg2.svg", "animate": {
  "params": {"theta": 0},
  "steps": [{"at": 0, "param": "theta", "to": 90, "duration": 1.6},
            {"at": 1, "param": "theta", "to": 180, "duration": 1.6}],
  "bind": [{"target": "#tip", "attr": "cx",
            "expr": "490 + 260*cos(theta*pi/180)"}]}}}
```

实现是自写 tokenizer + 递归下降（**不用 `eval`**），生成期编译成 JS，渲染端一条代理补间每帧重算全部绑定。于是 θ=45° 时尖到圆心仍是 260（走圆弧），属性补间走弦会短一截。

属性拍与参数拍**可以同段共存**，但**同一属性不能两边都写**。

### 跨段接续

**两页同一张 `src`、上一页是整页画布且写了 `animate`，下一页就自动接续**——起点是上一页演完的那幅画面，页界处不换画、不重播入场。

没有开关可写：要它独立重演，就换开两页的 `src`，或去掉上一页的编排。**且只在整页画布上成立**——槽位页构图归模板，页界那条擦除 + 配图入场是版式语义。

机制：生成 HTML 时把上一页补间的收尾态烘焙进本页的内联副本——相机姿态折成 `#cam` 内静态 `<g data-ctv-stage>`，元素级 `opacity`/`attr` 落成起始属性，`x`/`y` 折成 `translate`。约束：

- 上一页必须是整页画布、有 `animate`；两页必须同图。接续页自己不写编排也行（台词板照样成立）。
- 元素级 `transform` 只接 `x`/`y`（`scale`/`rotation` 跳过并 warn）；`repeat`/`yoyo` 按收尾那头接。
- 接续页别给 `<defs>` 里的元素写补间：两份同名 id 在同一份 DOM 里，图内引用只认第一份（生成期按步报 error）。
- 接续页不走擦除、不生成配图入场。

量连续性看柱子边沿，别拿整幅 PSNR（页界本就整幅换色）。

### 体检：哪些错会当场拦住

契约层（`_images_schema`）判形状，读不到图；读 SVG 的三条判据在生成期跑（`_animate.check_animate`）。

| 现象 | 级别 | 怎么消 |
|---|---|---|
| `animate` 挂在非 `.svg` 上 | error | 编排靠内联 SVG 的命名元素，图/视频没有可补间的目标 |
| `animate` 是空对象、`steps` 为空 | error | 不写 `animate` 就是静图；写了就至少给一拍 |
| 块级/拍级出现未知键 | error | 块级只认 `steps`/`params`/`bind`；拍级见上面的键表 |
| `params` 与 `bind` 只写一边 | error | 参数必须同时声明初值与谁读它 |
| 一拍同时写 `target` 与 `param`（或都不写） | error | 二选一 |
| 同属性被属性拍与 `bind` 同时写 | error（生成期） | 一条属性只留一个来源 |
| 参数端点算不出来（除零、定义域外） | error（生成期） | 那一帧 `onUpdate` 一抛，后面全不演 |
| `target` 在 SVG 里找不到 | error（生成期） | 拼错 id/class 不报错、只静默没动画，所以按文件拦 |
| 槽位页/分格页写了相机键 | error（生成期） | 换 `layout:"canvas"`，或删掉机位交给模板 |
| 图里没有带 id/class 的元素 | warn（生成期） | 编排无从落子：给元素命名 |
| 起始帧全空（可渲染元素写死 `opacity=0`，又没有一拍在段首点亮） | warn（生成期） | 结构底随页面到位，或把第一拍提到段首 |
| 拍点落在本页可见窗外 / 起点在窗内而终点越过下段 | warn（生成期） | 窗外等于没演，被切在半路等于没演完 |
| 参数初值与 SVG 静态值不一致 | warn（生成期） | 对齐，否则第一拍前画面跳一下 |

**觉得不同步**用 `python scripts/gen_hyperframes.py … --beat-report` 逐拍列绝对秒与踩点（`in` 句内 / `gap` 句间 / `tail` 段尾 / `before`·`after` 窗外）。
