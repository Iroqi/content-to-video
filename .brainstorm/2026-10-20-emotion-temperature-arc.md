# 2026-10-20 · 情绪色温弧：让 accent 表达"讲到哪儿了"

本轮只做一件事：**重定义缺省 accent 的取色规则**。不碰版式、不碰时间轴、不碰渲染管线。

## 一、现状与前沿案例

| 观察 | 现状（改动前） | 前沿案例在做什么 |
| --- | --- | --- |
| 颜色承担什么 | 8 支 accent 按段序 `% len` 轮询：每段**只保证"和上页不同"**，无方向 | Kurzgesagt 章节配色、Apple 发布会按产品线换主色：色温是一条**有方向的弧**，观众把"冷暖"读成"进度" |
| 峰值在哪 | 随段数漂移，可能落在第二段，也可能落在最后一段 | 结论/转折段吃最亮、最有分量的主色，开场与收束回到冷调 |
| 段数多时 | 8 支用完绕回开头，读成"颜色又回来了" | 同一色相族内做**连续渐变**，相邻段靠中间色区分 |

## 二、做法

1. **色板变成有序弧**（`_theme._ACCENT_PALETTE` 重排 + `_ARC_CYCLE`）：
   天蓝 → 青 → 橙 → 金黄（峰值） → 粉 → 红。重排只改顺序不改成员，
   8 支色的相对亮度仍落在 0.24–0.70，`ensure_text_contrast` 的保底档位不变。
2. **位置映射**（`_theme.arc_accent_indices`）：`pos_k = k·(end−1)/(count−1)`，
   `end = max(min(count, 弧长), 峰值+1)`——段数少也要走到峰值，段数多就整条
   弧压进 count 段。
3. **混色**（`_theme.arc_accent`）：整数位置取原色，小数位置按 sRGB 线性插值
   混两支近邻色，与 CSS `color-mix(in srgb, …)` 同构。段数超过弧长时相邻段
   靠中间色区分，**不再有"两页同色"**。
4. **接入**（`build_from_structured`）：只对**没写 `accent` 的段**排弧；显式
   染色原样保留、也不拉长弧；opening/closing 仍用默认色（结构性页不在章节弧上）。

## 三、为什么不做（留作下一轮）

- **跨段相机接续的自动推断**：`stage:"keep"` 目前要作者手写，可考虑按"同
  `src` + 上一页末拍是运镜"自动盖章——但自动盖章会把作者的显式选择变成默认，
  风险高于收益，先不做。
- **墙钟氛围层的逐帧可复现化**：把 `@keyframes` 折算成补间需要新的渲染原语，
  与"两档动画"的分界冲突，等有真实成片需求再说。
- **按语义（信源关键词）自动选 accent**：会让同一色在不同稿子里含义漂移，
  与"弧是结构信号"的设计相反。
