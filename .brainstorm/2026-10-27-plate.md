# 2026-10-27 · 走向 3b1b：图版（`layout:"plate"`）——把"一屏一句"落成一个版式

上一轮（`2026-10-26-derive.md`）把 `layout:"plate"` 排在候选清单的 **P0**，理由是：

> 它填的是 `slot`（文字主导）与 `canvas`（无文字）之间的空档，正是 3b1b 每一帧的样子。
> 代价：一个新版式要过渲染器三处（卡装配、句子流层是否生成、门禁的版式分派），
> 而且要重答"句子流不是动词的时候字幕挂哪"。**它比 `derive` 贵**，所以排在后面，
> 但它比 `derive` 更接近"看起来像 3b1b"。

本轮就是还这笔账。

---

## 一、先把"图版"定义到能写判据的粒度

3b1b 的一帧长这样：**满幅的图 + 一个标题 + 一句话**。三个元素，没有第四个。
把这句话拆成可实现的约束：

| # | 约束 | 本仓库旧状态 | 图版之后 |
|---|---|---|---|
| 1 | 配图占满整个画幅 | 只有 `canvas` 一种满幅，且它同时**丢掉全部文字** | `plate` 与 `canvas` 共用同一套满幅几何 |
| 2 | 标题上画面，但只一行、压在图上 | `canvas` 不生成标题层；槽位标题定高、可两行、可钳制 | 单行、按字数降字号、压顶部 scrim |
| 3 | 字幕**只有当前一句**，换句换屏、前句不留痕 | 句子流是"一页 N 句 + 焦点衰减 + 滚动 + 景深" | 一屏一句，`.plate-line` 叠放，只给当前句 `.plate-on` |
| 4 | 图本身不动（运镜交给作者） | 静态图一律吃 Ken Burns + 入场收拢 | 满幅页不生成入场补间、不漂 |
| 5 | 硬切，不参与翻页擦除 | 只有 `canvas` 享受这条 | 满幅页统一 `wipe=0` |

一句话：**图版是"画面主导"的那一档，但它把"看懂这张图需要的那两行字"留下了。**

### 为什么不是"给 canvas 加文字层"

试过这个方向，否决了。`canvas` 的语义是"这一张 SVG 就是整个画面"——作者在 SVG 里
自己画标题。真给他叠一层 HTML 标题，等于**同一件事有两个来源**，谁在上谁在下取决于
`z-index` 与 SVG 自己画了什么，而且 `canvas` 的对比度门禁（"画布作者的责任"）会被
HTML 层的自动 scrim 抢掉一半。图版是**另一档**：它的文字层是模板给的，作者只管图。

## 二、一条判据统起来：`FULL_BLEED_LAYOUTS`

实现前盘了一遍"哪些地方判过 `seg_layout(seg) == "canvas"`"，发现分散在九处：渲染装配、
配图入场、运镜、擦除预处理、生成期门禁（四处）、`check_svg`、观感门禁、`run.py` 的缺图
拦截。**加第三档时漏掉任何一处，症状都是静默的**（不会报错，只是那一页多了一个
Ken Burns、或者缺图没被拦住）。

所以先把判据收成一个：

```python
FULL_BLEED_LAYOUTS = ("canvas", "plate")
def is_full_bleed(seg): ...
```

九处全部改成问它。这一条不是重构洁癖——它是"以后还会有第四档"的**唯一**安全带，
也是本轮最容易漏的地方（实测漏了三处，靠测试和截图逐个抓回来）。

## 三、实现（按数据流顺序）

### 1. 契约层（`_segments.py`）

- `LAYOUT_VALUES = ("canvas", "plate", "compare", "agenda")`。
- `PLATE_FIELDS = "title"`：图版**只**认 `title`（不认 `tagline`），
  这是"一页只有两行字"在契约上的表达。
- `needs_image()` 改为 `is_content_sid(seg["id"]) or is_full_bleed(seg)`。
  **这条最隐蔽**：结构性页换成图版以后，那一页整页就是那张图；不算进覆盖率就会
  "报告说全部命中、出片时才发现开屏没图"。
- `plate` **不是** agenda 语义（它不印别人的目录），所以内容段能借、结构页也能借。

### 2. 模板（`_template.py`）：一个新块 `plate.<画幅>`

几何与字号进模板（`--ctv-*` 注入），CSS 只放选择器。竖屏：

| 键 | 值 | 为什么是这个数 |
|---|---|---|
| `titleSize` / `guardChars1` / `guardSize1` / `guardChars2` / `guardSize2` | 60 / 14 / 52 / 20 / 44 | 标题一行优先，14 字以内不降，20 字降到 44px（仍是 26px 下限的 1.7 倍） |
| `titleLineHeight` / `titleInsetX` / `titleInsetTop` | 1.18 / 64 / 72 | 压在顶部，scrim 之外的字不要 |
| `titleScrimHeight` / `captionScrimHeight` | 340 / 300 | 图再亮，两行字也得读得出来 |
| `captionInsetX` / `captionInsetBottom` / `captionMaxLines` | 64 / 84 / 2 | 页底、左右各 64、**两行硬上限** |
| `captionFontSize` / `captionLineHeight` / `captionWeight` | 42 / 1.34 / 600 | 42px ≈ 每行 22 个汉字 |

横屏一套对应的值（58/16/50/22/44、1.16/96/64、260、96/64/2/36、220）。

### 3. 渲染装配（`html_renderer.py`）

- `_prepare_card` 里按 `is_plate` 分支：缺图 `raise ValueError`（装配层就拒，
  不留到生成期）；`title_size` 走图版的降档表；**`tagline_html` 置空**；
  `card_open` 加 `seg-plate`；`verse_html` 换成 `_plate_caption_html`；
  返回值加 `is_plate` 供后续判断。
- `_plate_title_wrap`：`.plate-head > .seg-title.plate-title`。与槽位标题区关键差别是
  **不设行数钳制**——图版标题没有定高容器，钳制会把第二行裁成半截字；只降字号。
- `_plate_caption_html`：`.plate-caption > .plate-clip > N × .plate-line`，每行带
  `data-i` / `data-t0` / `data-t1` / `data-voiced`，emphasis 片段照旧经 `_em_marker()`
  打标、`_ved_layer()` 挂覆盖物（所以词级强调在图版上也是逐字的，不是整句一起亮）。
- `_still_image_carrier_sid`、`_card_timeline_lines`、`generate_html` 的 clips 预处理
  全部改问 `is_full_bleed_card(card)`。

### 4. CSS（`templates/composition.css`）

- 满幅图槽的规则从 `[data-aspect] .seg-canvas .seg-image` 扩成
  `[data-aspect] .seg-canvas .seg-image,[data-aspect] .seg-plate .seg-image`——
  **一条规则两用**，两档的满幅几何永远同步。
- 新增「图版」段：`.plate-head`（含 `::before` 顶部 scrim）、`.plate-title`、
  `.plate-caption`（含 `::before` 底部 scrim）、`.plate-clip`、
  `.plate-line`（绝对定位叠放、默认 `visibility:hidden`、两行钳制）、
  `.plate-line.plate-on`、`.plate-line.plate-on.plate-accent`。
- `.seg-progress` 基规则补 `z-index:3`，底轨规则按 `seg-canvas` / `seg-plate` 两条并列。

### 5. 运行时（`templates/runtime.js`）

```js
const plateShow = (cap, i) => { /* 只给第 i 行 .plate-on，其余撤掉 */ };
const plateSync = (t) => { /* 按 data-t0/data-t1 找当前句 */ };
```

在 `verseSync` 末尾调 `plateSync(tt)`。**为什么必须挂在 `verseSync` 里而不是另起一条
时钟轨**：截图档只拨 `tl.time()`，`onUpdate` 只在跨过 tween 边界时触发；字幕链路已经
有一条"每个帧网格打点"的时钟轨，图版复用同一条，才不会出现"一句之内只有两帧更新、
字幕冻住"。

**踩过的坑**：初版只 toggle `plate-on`、忘了 `plate-accent`，于是当前句里的高亮片段
永远是白的。这个 bug 三道门禁都看不见——**截图才看得出来**（竖屏第 3 句"半径越大，
这一条就越长。"该是 accent 蓝）。

### 6. 生成期门禁（`gen_hyperframes.py`）

`slot_svg_ratio_errors` / `svg_background_warnings` / `_canvas_sids_missing_src` /
`materialize_missing_canvas_placeholders` / `canvas_layout_errors` / `_seg_boxes`
全部改按 `is_full_bleed`；缺图文案改成满幅通用。

新增 `_plate_overlap_errors`——**本轮唯一一个"新类型"的门禁**：

> 图版的字幕层钉在页底、最多两行、字号取自模板。一个长句按
> `每行字数 = (画幅宽 − 2×captionInsetX) ÷ captionFontSize` 折行后占 n 行，
> n 超过 `captionMaxLines` 时 CSS 会把多出的行**钳掉**——观众看到的是半句话。

这是画面上**唯一一处"静态算得出、成片才暴露"的溢出**。门禁按 CJK 字宽 ≈ 字号估行数，
超限就点名该段该句、要求压到多少字以内；另有一条"页顶标题带 + 页底字幕带加起来
超过页高"（两层文字会在画面中间叠着画）。

估算口径与 `_title_font_px` 里 agenda 那条守卫**同一条**（整行离散打包，不按面积猜），
除数/行距/边距全部从模板同一处取——两处各拍一个系数，就会"一个说放得下、一个说完蛋"。

### 7. 其它两道门禁

- `check_svg.py`：`--layout` 加 `plate`，框尺寸/标签/对比度/`opacity=0`/安全边距/空带/
  满幅底板全部按 `layout in FULL_BLEED`（满幅档不给 `canvas` 那种 `c<4.5` 的额外豁免）。
- `perceptual.py`：采样步长 `1.5s`（满幅页画面变化慢），空页判据按 `FULL_BLEED_LAYOUTS`；
  本轮顺手把判词分档——`canvas` 空是"真的一片空"，`plate` 空是"那张图没撑起整幅"。

## 四、验收

**代码**：11 个文件改动（`_segments` / `_source_schema` / `_template` / `check_svg` /
`gen_hyperframes` / `html_renderer` / `perceptual` / `run` / `composition.css` /
`runtime.js` + goldens）。

**测试**：`tests/test_plate_layout.py`（19 条），四组：

- **契约**：取值合法、属满幅、不是 agenda、计入配图覆盖率；
- **装配**：图槽拉满、`.verse` 不生成、每句各占一行、tagline 不入 DOM、标题层在、
  标题不钳制、横屏也出、缺图拒绝装配；
- **时间线**：`duration:0.01` 硬切、无 Ken Burns、无配图入场补间、标题照常入场；
- **门禁**：70 字句被点名、40 字句放过、模板有 `plate` 块。

**全量 1406 条全绿**（基线 1387 + 19）。

**四份 golden 快照**用 `UPDATE_GOLDEN=1` 重生成，逐行确认 diff **只有新增**（plate 的
CSS 段、`--ctv-pl-*` 变量、runtime 的 `plateSync`、`.seg-progress` 的 `z-index:3`），
没有旧行为改变。

**实测**：`/tmp/plate-preview`（竖屏）与 `/tmp/plate-land`（横屏）用 playwright-core +
`/usr/bin/chromium` 截图，GSAP 从 CDN 下载并核对 sha256（`c174bfce…8280`）。验证了
满幅图 + 顶部标题 scrim + 页底一句字幕 + accent 高亮 + 换句切换，两画幅都成立。

**文档**：

- `references/canvas.md` 新增「图版」整节（选型判据只写在这里），画布几何表格加一行，
  `check_svg.py` 命令补 `--layout plate`；
- `references/rendering.md`「画面结构」加图版结构图与几何真源说明，「配图」的
  "三类载体不漂"改成"满幅版式（`canvas` / `plate`）"，翻车速查表加三条图版症状；
- `references/writing.md` 的 `layout` 取值补 `"plate"` 四条后果，`opening_layout` /
  `closing_layout` 补 `"plate"`；
- `SKILL.md` 核心规则、写稿步骤、缺图处理三处同步。

**一次文档结构下沉**：`rendering.md` 加完图版后到了 44.0KB（上限 44KB）。按"超线说明
该拆"的规矩，把「官方校验命令」整节（含噪声表）迁到 `motion.md`——它讲的是"怎么验
动作"，与那份文件"该不该动"是同一个决策时刻。连带 8 处引用（4 份文档 + 3 个 py 注释）
一并改指向，`tests/check_docs.py` 的 `NOISE_DOC` 同步。迁完 37.6KB。

## 五、留给下一轮

1. **语义色板**（上轮 P1）。图版落地后这条更值钱了：一张满幅图里"输入/输出/当前焦点"
   终于有地方用三个颜色区分，而现在的 accent 一支色管一段。
2. **几何门禁四类漏洞**（上轮 P1）：标签压线、箭头指向、同轴对齐、主视觉占比。
   图版把"主视觉占页宽 ≥70%"从文档判据变成了**图版的事实**（它铺满整幅），所以
   这条现在只对槽位版式有意义。
3. **图版的标题与字幕会不会互相"抢同一块图"**：现在只在纵向高度上判，不判"标题正好
   压在图的主体上"。这需要看图内容，`_cam_crop` 的投影思路可以复用，但要有"主体在哪"
   的先验——暂时留给作者用快照看。
4. **`plate` 与 `keep` 的组合**：现在不组合（`keep` 是跨段接续，图版是硬切）。如果
   以后要"图版的图跨两页接着演"，得先想清楚字幕层跟着谁走。
