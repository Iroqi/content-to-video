# 第 3 步 · SVG：画出来，再让它动

**怎么画**（几何、密度、对比度、字号、数据自查）→ **怎么跟着话变**（`evolve` 图内演进、`derive` 参数演绎）→ **怎么演**（两档动画、`director` 原语、跨段接续，已拆到 `references/motion.md`）。只做静态示意图的读到「文字与尺寸」为止；要跟着旁白逐拍演，接着读 `references/motion.md`「SVG 动画：两档」。

> **动笔前先读这五节**：「画布几何」「不铺满幅底」「图内文字的对比度」「数据图的几何自查」「文字与尺寸」——画错不会有任何报错，只会在成片上看出来。整页画布（`layout:"canvas"`）再加「整页画布的密度与层次」。
>
> 选不选 SVG 见 `references/writing.md`「哪些段值得交给 canvas」与 `references/imagery.md`；画面出问题按 `references/rendering.md`「画面翻车速查表」查。

## SVG 矢量示意图

数据图、公式、示意图走这一条；不带文字的画面先走生图。**图不等于简笔线框图**：渐变、光影层次、等距视角、装饰细节都该上。

数据红线：数字直接来自信源或可追溯数据源，估算值标出来；不用截断坐标轴、面积失真这类误导性比例，不藏单位；不编造数据点。

来源三条，手绘优先：

- **手绘 SVG**：按该段内容自己写 `.svg` 放入 `images/`。
- **官方 registry 现成块**（先搜再手画）：`npx hyperframes catalog --query "<效果>"` 搜（**必须写英文**，中文返回空且不提示）、`hyperframes add <name>` 装。进导演档必须重写成补间驱动（不许墙钟动画与 `Math.random`）。
- **SVG 图库**：logo、通用图标用成熟开源库（simple-icons、lucide、tabler），同一期同一套、统一线宽，来源与 license 记进 provenance。

要不要动、怎么动是**独立决策**，见 `references/motion.md`「SVG 动画：两档」。映射走 `{"seg4": {"src": "images/seg4.svg"}}`——外部 SVG 以 `<img>` 载入（内部脚本不执行）。

### 画布几何：根节点尺寸按版式分两种

**先看这段是哪种 `layout`，两种根节点尺寸不一样，写错判 error。**

| 版式 | 根节点尺寸（竖屏） | 横屏 | 比例 | 门禁 |
| --- | --- | --- | --- | --- |
| 槽位（不写 `layout`，默认） | 980×735 | 1067×800 | 4:3 | `check_svg.py`（默认档） |
| 整页画布（`layout: "canvas"`） | 1080×1440 | 1920×1080 | 3:4 / 16:9 | `check_svg.py --layout canvas --aspect ...` |
| 图版（`layout: "plate"`） | 1080×1440 | 1920×1080 | 3:4 / 16:9 | `check_svg.py --layout plate --aspect ...` |

**槽位版式写 4:3**，写死在根节点上：

```svg
<svg xmlns="http://www.w3.org/2000/svg" width="980" height="735" viewBox="0 0 980 735">
```

- 竖屏 980×735、横屏 1067×800 都是 4:3，照竖屏尺寸画一份两画幅通用。
- 画布 `cover` 铺满：viewBox 不是 4:3 时短边对齐、长边居中裁掉，贴边的文字/图例/描边会缺一块。改根节点尺寸再重排，**别靠缩内容凑比例**。
- 图库图标（多为 24×24）不能整幅当配图，只能套进 `<g transform="translate(…) scale(…)">` 当画布里的一个元素。

**整页画布写当前画幅原生尺寸**（竖屏 1080×1440、横屏 1920×1080），不是 4:3——照 980×735 画会被 `check_svg --layout canvas` 判"根节点比例不是 3:4"拒收。真源是 `scripts/_template.py` 里 `canvas.vertical` / `canvas.landscape`，**别手写 px 当权威值**——用 `canvas_kit.py` 出图自带门禁自查。

- 整页画布不 `cover` 裁切、整幅铺满，viewBox 与画幅不一致时整张图被拉变形。
- **图内两行文字压字只有 `hyperframes check` 能量到**（Layout 阶段 `content_overlap`）。最常踩：`canvas_kit` 的 `bars` 把数值标签写在 `base_y + label 档字号`，下方再起一行两行只差十来像素——留够一行字号（`TIERS` 最大档 1.2 倍以上）。

画完跑 `python scripts/check_svg.py images/`（整页画布加 `--layout canvas --aspect portrait|landscape`，图版给 `--layout plate`，**档位与稿件对得上**；两种版式混用给 `--layout auto`）。它报的每条自带口径；本文件只写它**管不到**的：图内文字溢出、互相压字、刻度与比例。

### 不铺满幅底

根节点下**不要写铺满 viewBox 的底板**（`<rect>` / `<polygon>` / `<path>` 三种写法一样算满幅）。确实要自画满幅底（浅色页、照片感场景）时忽略那条 `[warn]` 即可。

机器已盯这条：`check_svg.py` 与生成期 `gen_hyperframes` 按**同一份判据**打 `[warn]`。判不了的两类留给真浏览器：CSS class 控宽高的 `<rect>`，以及 98% 阈值之下的"几乎满幅"。

透明处透出主题渐变与该段 `--seg-accent` 的氛围光，示意图自动染上本段主色。四条连带：

- **图内留白从此算版式**：竖屏槽位左边缘正落在 `segCard.padding` 的 50px 轴上，图内再缩进 60 就是 110px，明显不同轴。要么缩进收到 0（贴边不被裁靠上面那条 4:3 + `cover`），要么明确当图例、不追求对齐。
- **图内文字只在起指示作用时才写**：轴标签、刻度、单位、数值、图例、步骤名，判据是"不写这行字这张图就读不出来"。**标题不在其中**——卡片标题就是这张图的标题。
- **辉光开始参与配色**：透明后 `--seg-accent` 直接压在图区中心（竖屏 15%、横屏 13%），下笔前先看这段用什么 accent；次要文字跟着提亮一档。
- **局部底板照旧可画**，取消的只是"整幅满铺"。

### 图内文字的对比度：定色在前，自查在后

**SVG 以 `<img>` 载入，内部文字不属于 HTML 文本流，没有任何一道检查会量它**，所以取色表放在自查之前。

要机器量对比度/压字：把该 SVG 文件**内容**临时内联成 DOM 副本跑 `hyperframes check`。**副本只用来问门禁，绝不能当产物**——交付的 `index.html` 必须保持 `<img>` 形态。**唯一例外**是写了 `director` 的那张：交付时就是内联活 DOM，但内联前必过 `scripts/_svg_sanitize.py` 净化（见 `references/motion.md`「SVG 动画：两档」）。

**判定线**（WCAG）：正文与标签 ≥ 4.5:1；图内最大字号档（≥24px，或 ≥18.66px 加粗）≥ 3:1，低于 3:1 重画；次要文字按 ≥ 7:1 取色。

**深色主题取色表**（底 = 页面渐变叠上该段 accent 辉光；**页底**列不叠辉光，**最坏**列是全部预置 accent × 渐变 stop × 竖屏 15%/横屏 13% 全组合的最低值）：

| 用途 | 取色 | 对比度 |
|---|---|---|
| 图内最大字号 | `#f2f6fc` | 页底 17.7–18.6，最坏 12.7 |
| 主标签 | `#dbe6f5` | 页底 15.2–16.0，最坏 10.9 |
| 次要说明下限 | `#a8bdd6` | 最坏 7.2，刚好守住 ≥7 |
| 不要用 | `#6b7c93` | 页底 4.5–4.7、最坏 3.2，两档都越线 |
| 不要当文字色 | `#060709` `#0d0f13` `#080a0c`（页底渐变各档） | 1.0:1，出现在 `fill` 上就是瞎字 |

**三条最常踩的**：

- **深色文字只能待在明确的浅色底板上**：符号常写成近黑 `#0c1320` 摆到浅色渐变圆盘上（圆盘上 15.1:1），圆盘一挪或换了渐变立刻瞎掉。改任何底板颜色都要复核压在它上面的文字；`fill` 能就近写死就别靠 `<g>` 继承。
- **页底色不得当文字色**：填充色只要对主题渐变最坏一档低于 3:1 就是瞎字——`check_svg.py` 按页底各档 stop 逐一算 WCAG 对比度，槽位版式直接判 error。
- **半透明按合成后的颜色算**：50% 的 `#dbe6f5` 叠在 `#0c1320` 上合成 `#747c8a`，只剩 4.4:1。要弱化文字就换更暗的实色。唯一例外是导演元素 `opacity="0"`——那是**起始态**（终帧才亮），`0.1~0.79` 中间档照报。

**机械能查到的边界**：`check_svg.py` 对字面 hex 填充按**主题渐变最坏一档**算一次 WCAG 对比度。槽位版式低于 3:1 判 error、低于 4.5:1 判 warn；**整页画布只 warn**。渐变底、`class` 里的色、局部底板上的字一概管不到。

### 整页画布（段落 `layout: "canvas"`，结构性页用顶层 `opening_layout` / `closing_layout`）：这一张 SVG 就是整个画面

**什么时候换整页**（选型判据只写在这一节）：

- **内容装不下 4:3 槽位**：数据关系、长时序、多层系统图——硬塞的结果是把字号压到 26px 下限以下。
- **这一页本身就该是一张海报**：章首、转折、结论、金句。
- **这一段只需要画面**：过场、留白、真实场景照片。
- **节奏：主动穿插**。内容段 ≥5 段给 2–3 段换画布，段数少就 1 段，挑章首或转折。**两条边界**：别连着两段都用；旁白最密、最需逐句跟读的那段**别换**（画布连句子流 DOM 都不生成）。
- **开屏/结尾也可以整页**：顶层写 `opening_layout`/`closing_layout: "canvas"`。代价：投影卡整个不上画面——章节列表、要点总结、`cta` 尾行都没了，全得画进图里。

**什么时候别换**：该段口播要靠字幕跟读（画布不生成句子流层，也没有"页底句子流"兜底）；不想自己把标题画进 SVG；一期要出两个画幅却只打算画一张 SVG。

字段语义见 `references/writing.md` 段落 `layout`；版式与门禁变化见 `references/rendering.md`「画面结构」。这张 SVG 和槽位版式只有六处不同：

- **几何换成整个画幅**：竖屏 `width="1080" height="1440" viewBox="0 0 1080 1440"`，横屏 `1920×1080`。两画幅都要出片就**各画一张**（生成期按文件验：根标签读不出纯数字 `width/height` 或 `viewBox`、或比例与画幅不等比，直接 exit 1）。
- **按画幅原尺寸画，别靠放大画布凑**：成片按 `画幅宽 ÷ viewBox 宽` 整体缩放（推荐的根标签里 `width` 与 `viewBox` 同宽，两者是一回事；写成 `width="2160" viewBox="0 0 1080 1440"` 这种缩放形式时，折算认的是 viewBox——字号坐标都写在它那一套里）。按 2560×1440 画的 16:9 塞进 1920 画幅，28px 折算只剩 21px——跌破 26px 下限就是读不出来。字号写成 px 才能验；写成 `em`/`%`/class 时只有图真在被缩小（viewBox 宽 > 画幅宽）才打 `[warn]`。
- **安全边距照页面走**：竖屏四周留 50px、横屏留 96px，图内文字越界就是出血。`text-anchor="end"` 的落点按量出来的字宽倒推，不按字符数估（量法见「数据图的几何自查」）。
- **"不铺满幅底"在这里更要紧**：留透明才能透出模板那三层背景；例外与 warn 口径见上面「不铺满幅底」。
- **图内可以有标题，字号按整页读**：标题 72–76px、小标题 38–48px、正文 30–40px、kicker/图例 26–28px。字号越大越要自己复查对比度——**这一版的 `Contrast` 门禁数不到你**。字体名写死（`'Microsoft YaHei','PingFang SC',…`）：`<img>` 载入读不到页面 `--ctv-font-*` 变量。生成期那条 `[warn]`（"该段 N 句旁白不会上画面 / 这张 SVG 里有 M 个 `<text>`"）是要点有没有画进图里唯一的机械判据。
- **机械劳动交给脚手架**：`python scripts/canvas_kit.py --spec spec.json --aspect portrait -o images/seg1.svg` 吐一张按画幅原生尺寸画的透明底画布 + 一份能塞进 images.json `director` 的 steps 草稿（`--emit-steps` 另存）。`-o` 与 `--emit-steps` 落在技能目录内会被守卫拦下，先 `cd` 到项目目录再跑。**完整 spec 结构与示例见 `python scripts/canvas_kit.py --help`**（尾部印同一份例子，七种 kind 各一条最小可跑片段）；写错时脚本报错当场列出该 kind 的合法键与必填键，键集不必背。最小可抄骨架：

```json
{
  "aspect": "portrait",
  "elements": [
    {"kind": "text", "id": "t", "x": 80, "y": 200, "content": "季度营收", "tier": "title"}
  ]
}
```

  动笔前有两件报错替代不了的事：**`axis` 的 `from`/`to` 是轴两端的像素坐标、不是起止数据值**（竖轴把较大的 y 写在 `from`、数值就朝上长；`at` 是那条轴所在的像素线）；**`tier` 只有三档**（画布档要更大的字就手写 SVG 绕过脚手架）。

  **它收走的只是机械部分**（画布几何、三档字号、线宽、取色压暗、初始 `opacity` 分档）（`draw`/`count`/`type` 不会被写 `opacity="0"`，写了就永远不亮）。旋钮 `duration`/`ease`/`stagger`/`repeat`/`yoyo` 写进元素即可（`yoyo` 必须带 `repeat`）；`roughness` 0–10 是图形侧的手绘旋钮——`panel`/`polyline`/`bars`/`circle`/`rule` 的坐标按 `roughness × 该画幅线宽` 做 seeded 抖动，**坐标轴与文字不吃这个键**：轴是数据标尺（刻度与标签全钉在它上面），字抖一下就不成字。**构图仍归人**——坐标由 spec 给；草稿节拍只用 `at` 不用 `at_time`。

**给上 `--sentences <该段句数>`，草稿才是真能直接用的那份**。不给时自动拍按元素顺序一路 `at=0,1,2…`，内容元素比旁白句子多时最后几拍落到句序之外，生成期按 `error` 整条拒掉（"at=N 越界：该段只有 M 句旁白"）。给了句数，游标按它取模回绕；**显式钉拍**（元素里写 `beat`）的越界提前打 `[warn]`。`--emit-steps <path>` 另存的草稿是 `{"steps": [ … ]}`，直接 `"director": {"steps": <这份数组>}`。

照片当画布不做比例与字号校验，但配一张照片就等于该段整段时间屏幕上不出现任何标题——生成期照样给一条 `[warn]`。想留标题就把要点画成 SVG；确实要"只有画面"的过场，忽略它就行。

### 整页画布的密度与层次：这一页经得起暂停吗

判据不是"画了多少个元素"，是**随便暂停一帧，画面还成不成立**。用 `npx -y hyperframes snapshot --at <秒>` 截出来看。

- **竖向不许有整条空带**（`check_svg.py --layout canvas` 会 warn，阈值 25% 页高）：标题在上 1/4、主视觉占中部并**撑到接近页宽**、注脚与结论压在下 1/4，三段之间用中景元素连起来。
- **一页至少三层**：背景层（模板那三层，别铺满幅底盖掉）、中景（主视觉 + 局部底板/面板/分隔带做明度层级）、前景（标注文字、数值、accent 强调）。中景自己也有"面板 < 底板 < 页底"三档明度。
- **主视觉要有尺寸下限**：占页宽 ≥70%、占页高 ≥45%。
- **辅助线要敢用亮档**：轴线、网格、分隔线在 dark 页底上不要低于 `#64748b` 一档，线宽 ≥3px。层次靠**明度差与大小差**做，不靠透明度。
- **字号最多三档 + 一档 accent**：脚手架三档竖屏 64/40/32、横屏 62/33/28；整页画布量级照「整页画布」那节。最大档与最小档比值 ≥2。一个 accent 负责"现在看这里"，其余走中性灰阶。
- **数信息单元**：一页有几个独立可看的东西（一块图、一行结论、一组标注各算一个）？**少于 3 个就别当整页画布做**——那它本质是字卡，按海报重写，或退回槽位版式。
- **导演页还要看"起始帧"**：前 1 秒画面是空的，而整页画布**没有转场遮这一下**（见 `references/rendering.md`「动画」）。只要不铺满幅底，第一帧至少不是死平一块色；把**结构底**（坐标轴、外框、分隔带、面板格子）不写进 `director.steps`，让它和页面同时到位、只逐拍长"内容"，或把第一拍放在 `at_time` 0.1s。这条现在是**生成期门禁**：SVG 里所有可渲染元素都从 `opacity=0` / `visibility:hidden` 起步时，`gen_hyperframes` 按段落打 `[warn]`「起始帧全空」——开场没有钩子、观众对着空画面不知所以然（画布页没有标题层也没有字幕层）。

### 图版（段落 `layout: "plate"`）：满幅主视觉 + 标题 + 一句字幕

整页画布交出的代价是**文字层全没了**；图版交出的只是**句子流**。它保留两层最小文字，
其余全部让给画面：

```text
┌──────────────────────────┐
│ 标题（一行，压在顶部 scrim 上） │
│                          │
│        满幅主视觉          │
│                          │
│ 一句字幕（页底，随旁白换句）    │
└──────────────────────────┘
```

**什么时候用图版**（选型判据只写在这一节）：

- **这一页的画面本身就是内容**，但观众仍需要一句话帮他读图（照片、场景图、单张
  复杂示意图、地图、界面截图）。
- **字幕按句跟读、但不要"一摞句子往上滚"**：3b1b 的字幕是一屏一句，说到下一句
  屏幕换一句，前一句不留痕。图版就是这个节奏。
- **节奏上比整页画布更轻**：整页画布要"整页重新构图"，图版只要一张能撑满整幅的图，
  所以它可以出现在旁白较密的段——但**别和整页画布连排**，两页都是满幅图，观众
  分不出这是两个版式。

**什么时候别用**：

- 段落里句子多、信息密度高（图版不滚，一句超过 `captionMaxLines` 行就被钳掉半句，
  生成期直接报 `error`，见下）。
- 需要 tagline / 副标题 / 多行要点：图版只有标题那一行，多出来的字没有地方放。
- 双人对话：字幕层不带说话人标签切换的富余位置，轮次信息会糊。

**和整页画布共用的部分**（同一份几何，`FULL_BLEED_LAYOUTS` 一个判据管到底）：

- **根节点写画幅原生尺寸**（竖屏 1080×1440、横屏 1920×1080），`check_svg.py --layout plate`
  按满幅档验比例、对比度、安全边距、空带与"不铺满幅底"。
- **配图拉满整幅**：圆角/外发光/1px 内描边全撤，`cover` 铺满不裁边。
- **不参与擦除转场**、**不做配图 Ken Burns 运镜**、**不生成配图入场补间**——画面一揭开
  就在位，镜头语言交给 `director` / `evolve` / `derive`。
- **进度条与底轨抬到 `z-index:2`**，标题层与字幕层在 `z-index:2` 之上。

**图版独有的四条**：

1. **必须有配图**。缺图在装配层 `raise ValueError`、在生成期按 `error` 拒——图版没图
   就只剩两行字压在空页上。
2. **标题带不钳行数、只降字号**。字数降档走模板 `plate.<画幅>` 的
   `guardChars1/guardSize1/guardChars2/guardSize2`，下限 `MIN_READABLE_FONT_PX`
   （26px）。压在顶部 scrim（`titleScrimHeight`）上，为了字始终可读；**标题仍然一行
   优先**，越长字越小，两行是一个上限而不是目标。
3. **字幕一屏一句，页底居中**。DOM 是 `.plate-caption > .plate-clip > N × .plate-line`，
   每行带 `data-i` / `data-t0` / `data-t1`，运行时 `plateSync(t)` 只给当前那句加
   `.plate-on`（换句换屏、前句不留痕），当前句里的 emphasis 片段加 `.plate-accent`
   走高亮色。**没有句子历史、没有滚动、没有焦点衰减**——整页画布那套"一页上 5 句在等"
   的语义在这里是错的。
4. **字幕两行是硬上限**（`captionMaxLines: 2`），超了不是缩字号而是**报错**：图版不滚，
   第三行直接被 CSS 钳掉，屏幕上就是一句念了一半的话。生成期 `canvas_layout_errors`
   按 `每行字数 = (画幅宽 − 2×captionInsetX) ÷ captionFontSize` 估行数，占位超限就点名
   该段该句要压到多少字以内；页顶标题带 + 页底字幕带加起来超页高另报一条"两层文字
   会叠着画"。**这两条都只能靠压短句子解决**——这正是图版要的写稿节奏：一句一个事实。

**写稿侧**：图版段落按"一句一屏"写，单句控制在 `每行字数 × captionMaxLines` 以内
（竖屏 42px 字号下约 44 字）。图要撑满整幅，所以**别在图的四周留大边距**——那块边距
会被 `cover` 拉成 0，看起来像构图偏了。

**预览体检**：`npx -y hyperframes snapshot --at <秒>` 挑"第 2 句正在说"和"换句那一帧"
两个时刻各截一张：字幕该只有一句、该在页底、该没被钳；标题该在 scrim 上而不是
压在主体上。

### 数据图的几何自查

手绘数据图（柱状、折线、饼环、散点、时间轴）里**长度/角度/坐标本身就是数据**，而这条错误链上没有任何检查看得到：

- **先定标尺，再画图形**：把映射写成一行线性式（`y = y0 - (v - vmin) * (h / (vmax - vmin))`）放进 SVG 注释，所有柱高/点位由它反算，不凭手感逐个调。刻度取整档（1/2/5×10ⁿ），别为了对齐图形改数据。
- **用两端点回算验证每一档**：最大值柱顶减最小值柱顶应等于"量程 × 标尺"，对不上是映射写错。**pie / 环形先查总和**：各扇区角度相加必须等于 360（`占比 × 3.6`）。
- **量文字，不数文字**：定宽元素（刻度、数值标签、图例）按实测宽度排版——`text-anchor="end"` 的落点倒推字宽。两条量法：浏览器 `getBBox()` 读左右缘，或 `npx -y hyperframes snapshot` 按时刻截一帧（命令见 `references/motion.md`「官方校验命令」）。整页画布安全边距（竖屏 50px / 横屏 96px）同样按量出来的右缘判。
- **公式就是图内文字**：`E = mc^2` 这类本体用 `<text>` 画——上下标靠 `baseline-shift` 或两个 `<tspan dy>`，字体栈照「文字与尺寸」，下标字号同样受 26px 下限约束。

### 文字与尺寸

图内文字按"**进入内容画布后**的最终可读性"设计，不是按原始文件尺寸设计。

图内只有起指示作用的文字，**没有"标题"这一档**（见本文件「不铺满幅底」）；最大一档 35–40px 给图例名或底板大字，正文级从 35px 起步（槽位按 980×735、整页画布按当前画幅原生尺寸）；内容很密就优先减少文字、扩大图形。**26px 是下限**：再小就读不出来了——宁可换行或加长底板，也别缩字号。

底板内还要**估一次宽度**：一行汉字数 ≈（容器宽 − 左右内边距）÷ 字号。980 画布留 48px 内边距、52px 字号 → 一行约 17 个汉字。溢出时换行或加宽底板。

SVG 以 `<img>` 载入时是独立文档，页面 `--ctv-font-family` 渗不进去，`<style>` 里要自带中文无衬线字体栈（如 `"Microsoft YaHei", "PingFang SC", "Noto Sans SC", "Noto Sans CJK SC", "Noto Sans CJK JP", sans-serif`——Linux 沙箱里 `Noto Sans SC` 会回落到无 CJK 字形的 NotoSans-Regular，`Noto Sans CJK SC/JP` 才是能匹配上的名字，别省）。

## 槽位版式的演进（`evolve`：图跟着话变，但版面不动）

**要解决的那件事**：槽位版式的图默认是 `<img>`——一张静态示意图，旁白讲到第三个
状态，图还停在第一个状态。观众听到"从 X 变成 Y"，画面上没有任何对应动作，这一屏
就只剩字幕在推进。整页画布能演，但它要交出版面（标题层、句子流层都不生成）。

第三条路：**留在槽位，只让图里的元素跟着旁白演进**。images.json 写 `evolve`：

```json
{
  "seg2": {
    "src": "images/seg2.svg",
    "evolve": {"steps": [
      { "at": 0, "target": "#bar-a", "to": { "attr": { "height": 260 } } },
      { "at": 1, "target": "#bar-b", "to": { "attr": { "height": 380 } }, "duration": 0.7 },
      { "at": 2, "target": ".label",  "to": { "opacity": 0.35 }, "stagger": 0.1 },
      { "at": 2, "target": "#delta",  "from": { "opacity": 0 }, "to": { "opacity": 1 } }
    ]}
  }
}
```

- **steps 的写法与 `director` 完全一样**（`at` / `at_time` / `set` / `to` / `from` /
  `draw` / `morph` / `count` / `type` / `stagger` / `duration` / `ease` / `repeat`），
  **同样净化内联、同样按句驱动、同样逐帧可复现**。区别只有两条：
  1. **不接管编排**：标题、tagline、句子流、配图入场收拢、Ken Burns 运镜全部照旧，
     这条补间只叠在图内元素上。所以字幕还在，版式还是槽位。
  2. **图里不调机位**：`svgOrigin` / `scale` / `rotation` 这类相机写法在契约层报错
     ——镜头归模板，作者再推一层就是两层意图打架，画面读成"图在自己乱动"。要整页
     推镜请换成 `layout:"canvas"` 写 `director`。
- **起点态取图上的静态值**：`{"to": {"opacity": 0.35}}` 读作"从当前可见压暗到
  0.35"，不是"从无到有"。真要从无到有就显式写 `from`。默认语义因此是**结构底就位、
  内容从初态长到终态**——配图落位那半秒不会是一块空框。
- **与 `director` 同段互斥**，与 `stage:"keep"` 也不组合：`evolve` 按段独立，
  每段从同一张图的静态初态起演，不跨段接续。
- 体检：target 落空（error）、图内调机位（error）、起始帧全空（warn）、节拍出窗
  （warn）——与 director 同一套判据、同一个落点函数。

**什么时候用它**：这一页有一张图要**变**（数据在长、状态在换、对象在转移），
但读者需要字幕跟着读。典型是"图上有一个量在动"的段落；如果整页都该重新构图，
那是 `director` 的活。

## 参数演绎（`derive`：一拍推一个量，几何自己算）

`director` / `evolve` 的补间是**属性级**的：要让三个元素一起动，就写三条，各自
写 `duration` / `ease` / 起点，靠作者保证它们"同一时刻、同一节奏"。想画一个角在
转、指针跟着转、弧长同时长出来，就得把三条时长抄成一样，抄错一条就是"说着同步、
看着脱节"。而且**中间态是插值**：指针从 A 点到 B 点走的是直线（弦），不是圆弧。

3b1b 的做法不是这样：一个场景有**一个主参数**（把 θ 从 0 转到 2π），所有几何都由它
算出来。`derive` 补的就是这一层：

```json
{
  "seg2": {
    "src": "images/seg2.svg",
    "derive": {
      "params": { "theta": 0 },
      "steps": [
        { "at": 0, "param": "theta", "to": 90, "duration": 1.6 }
      ],
      "bind": [
        { "target": "#arm", "attr": "x2", "expr": "490 + 260*cos(theta*pi/180)" },
        { "target": "#arm", "attr": "y2", "expr": "367 - 260*sin(theta*pi/180)" },
        { "target": "#tip", "attr": "cx", "expr": "490 + 260*cos(theta*pi/180)" },
        { "target": "#tip", "attr": "cy", "expr": "367 - 260*sin(theta*pi/180)" }
      ]
    }
  }
}
```

配这张图只要三个元素：`#arm` 是一条从圆心伸出的线（`x1/y1` 钉在圆心，`x2/y2` 随 θ 转），
`#tip` 是针尖，`#hub` 是圆心。**多拍累进**：后一拍的起点是前一拍的终值——"先转到 90°、
讲到第二句再转到 180°"就是两条 step，不必自己算衔接：

```json
{
  "seg2": {
    "src": "images/seg2.svg",
    "derive": {
      "params": { "theta": 0 },
      "steps": [
        { "at": 0, "param": "theta", "to": 90, "duration": 1.6 },
        { "at": 1, "param": "theta", "to": 180, "duration": 1.2, "ease": "power1.inOut" }
      ],
      "bind": [
        { "target": "#arm", "attr": "x2", "expr": "490 + 260*cos(theta*pi/180)" },
        { "target": "#tip", "attr": "cx", "expr": "490 + 260*cos(theta*pi/180)" },
        { "target": "#tip", "attr": "cy", "expr": "367 - 260*sin(theta*pi/180)" }
      ]
    }
  }
}
```

- **`params`**：参数名 → 初值。名字要能直接当标识符（字母/下划线开头，≤32 字符），
  因为同一个名字要出现在表达式里、进 JS 变量表。
- **`steps`**：一拍只写"**把哪个参数推到多少**"。锚点与 director 同一套（`at` 句序 /
  `at_time` 绝对秒或 `"+N"` 相对串，二选一），`duration` / `ease` / `delay` 同义。
  **多拍累进**：后一拍的起点是前一拍的终值（写了 `from` 则以它为准），所以
  "先转到 90°，讲到第二句再转到 180°"就是两条 step，不用自己算衔接。
  `duration` 在这里**必须 > 0**（写 0 会让整段演绎退化成一次瞬跳，契约层直接拒）。
- **`bind`**：一条绑定算**一个属性**。`attr` 只收几何属性：`x y cx cy r rx ry x1 y1
  x2 y2 width height transform`。`d` / `points` 是复合几何（要整条重写路径），颜色与
  透明度归 `director`——参数演绎只管形状。
- **表达式**：算术 `+ - * / % ^ **`（`^` 是乘方，右结合）、常量 `pi tau e`、白名单函数
  `sin cos tan asin acos atan sqrt abs floor ceil round exp log min max pow`，以及
  `params` 里声明过的参数。**别的都不收**——没有属性访问、没有下标、没有 lambda、
  没有字符串、没有 `random` 或时间函数（成片逐帧 seek，任何非确定的东西都会让两帧
  对不上）。表达式上限 240 字符：一条 bind 只该算一个属性值，要算整张图请拆成多条。
  解析器是自写的 tokenizer + 递归下降，**不用 `eval`**，渲染页里同样不出现 `eval`
  （生成期就把表达式编译成 JS 字面代码）。

**为什么中间态是真几何**：每一帧都按参数真值重算 `bind`，而不是在两条路径之间插值。
θ=45° 时针尖到圆心距离**仍然是 260**（走的是圆弧）；属性级补间走弦，会短一截，
短多少取决于跨度——观众说不上来哪里怪，但"不像在转圈"。

**和 `director` / `evolve` 一起用**：可以同段共存（一个管出场、一个管连续演绎），
但**同一个属性不能同时被两者写**。两条时间线都在写它时，先写的白写，而谁后写取决于
脚本挂载顺序——作者算不准。这种冲突在生成期按 error 拦下（文案里点名是哪一步）。

**SVG 静态值要和 `params` 初值对齐**：`#tip cx="750"` 而表达式在 `theta=0` 处算出 750，
第一拍之前画面就稳定；两边不一致（比如改过表达式忘了改 SVG）时第一帧会跳一下，
生成期打 `[warn]` 报出差值。`transform` 与 class 多元素目标不做这个比对（前者是复合串，
后者各写各的静态值）。

**体检清单**（`gen_hyperframes.py` 的 `_derive_prepare`）：target 落空（error）、
同属性与 director/evolve 冲突（error）、`at` 句序越界（error）、端点处算不出来
（error：除零/定义域外——那一帧 `onUpdate` 一抛，后面的拍全部不演）、节拍出窗
（warn）、起始帧读数与初值不一致（warn）。

**逐帧可复现**：属性只由 `(时刻 → 进度 → 参数 → 表达式)` 决定，没有状态、没有缓存，
同一时刻算两遍得到同一串属性。渲染端是一条代理补间（每拍一个 0→1 的进度变量，
`onUpdate` 里重算全部绑定），所以"三拍串联"天然是前一拍接着后一拍走。

**什么时候用它**：图上有一个**连续量**在驱动多个元素——角度、半径、比例、进度、坐标。
典型是圆的参数化、向量分解、函数图像上的一点跟着走、比例条同步伸缩。
如果只是"这个元素从 A 变到 B"，`evolve` 更直接；如果要整页重新构图，那是 `director`。
