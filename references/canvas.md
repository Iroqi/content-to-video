## 方式 C：SVG 矢量示意图

数据图、公式、示意图走这一条。**定位：图内必须出现准确文字（术语、步骤名、数值、图例）或必须精确几何关系时的首选**；不带文字的画面先试 B。**图不等于简笔线框图**：渐变、光影层次、等距视角、装饰细节都该上。

数据与公式红线——数据必须直接来自信源或可追溯数据源：

- 不为"好看"改数字；估算值必须在画面或文案里标明，不得画成事实。
- 不使用误导性比例（截断坐标轴、面积失真对比等）；不隐藏或省略单位。
- 不编造不存在的数据点、关系或会改变含义的关键关系。

四条获取路径：

- **官方 registry 现成块**（先搜再手画）：`npx hyperframes catalog --query "<效果>"` 搜、`hyperframes add <name>` 装。**查询必须写英文**（中文返回空且不提示）。拿来的块要么落在槽位/装饰这类不进导演的位置，要么重写成导演能驱的形态（不许墙钟动画与 `Math.random`，见 `references/rendering.md`「动画」）。
- **手绘 SVG**：按该段内容自己写 `.svg` 放入 `images/`。
- **SVG 图库 / 现成素材**：logo、通用图标用成熟开源库（simple-icons、lucide、tabler），同一期同一套、统一线宽，来源与 license 记进 provenance。
- **SVG 动画**：两档——**氛围循环**（墙钟，`<img>` 载入）和**时间轴同步的「导演」**（净化内联，GSAP 逐句驱动），选型见 `directing.md`「SVG 动画：两档」。分界：画面得对上某句话就用导演。

映射走普通 `src`：

```json
{
  "seg4": {"src": "images/seg4.svg"}
}
```

外部 SVG 以 `<img>` 载入（内部脚本不执行），仍只从干净知名来源获取。

### 画布几何：根节点尺寸按版式分两种

**先看这段是哪种 `layout`，两种根节点尺寸不一样，写错判 error。**

| 版式 | 根节点尺寸（竖屏） | 横屏 | 比例 | 门禁 |
| --- | --- | --- | --- | --- |
| 槽位（不写 `layout`，默认） | 980×735 | 1067×800 | 4:3 | `check_svg.py`（默认档） |
| 整页画布（`layout: "canvas"`） | 1080×1440 | 1920×1080 | 3:4 / 16:9 | `check_svg.py --layout canvas --aspect ...` |

**槽位版式写 4:3**，写死在根节点上：

```svg
<svg xmlns="http://www.w3.org/2000/svg" width="980" height="735" viewBox="0 0 980 735">
```

- 内容画布竖屏 980×735、横屏 1067×800 **都是 4:3**，照竖屏尺寸画一份两画幅通用。
- 画布 `cover` 铺满（见 `references/rendering.md`）：viewBox 不是 4:3 时短边对齐、长边居中裁掉，贴边的文字/图例/描边会缺一块。要改就改根节点尺寸再重排，**别靠缩内容凑比例**。
- 图库图标（多为 24×24）**不能整幅当配图**，只能套进 `<g transform="translate(…) scale(…)">` 当 4:3 画布里的一个元素。

**整页画布写当前画幅原生尺寸**（竖屏 1080×1440、横屏 1920×1080），不是 4:3——照 980×735 画会被 `check_svg --layout canvas` 判"根节点比例不是 3:4"拒收。真源是 `scripts/_template.py` 里 `canvas.vertical` / `canvas.landscape`。

- 整页画布不 `cover` 裁切、整幅铺满，viewBox 与画幅不一致时整张图被拉变形。
- **别手写 px 当权威值**。用 `python scripts/canvas_kit.py --aspect portrait -o …` 出图，它按模板尺寸出并自带画布门禁自查。
- **图内两行文字压字只有 `hyperframes check` 能量到**（Layout 阶段 `content_overlap`）。最常踩的一处：`canvas_kit` 的 `bars` 把数值标签写在 `base_y + label 档字号`（竖屏 32px、横屏 28px），你在同一面板下方另起一行时两行容易只差十来像素。留够一行字号（`TIERS` 最大档的 1.2 倍以上）。

画完跑 `python scripts/check_svg.py images/`（整页画布加 `--layout canvas --aspect portrait|landscape`，**档位与稿件对得上**；两种版式混用给 `--layout auto`）。它报的每条自带口径；本文件只写它**管不到**的部分——图内文字是否溢出、**互相压字**、刻度与比例是否画对。

### 不铺满幅底

根节点下**不要写铺满 viewBox 的背景 `<rect>`**。撤掉满幅底之后，透明处透出主题渐变和该段 `--seg-accent` 的氛围光，示意图直接落在页面上，自动染上本段主色。

- **图内留白从此算版式**：竖屏槽位左边缘正落在 `segCard.padding` 的 50px 轴上，图内再缩进 60 就是 110px，明显不同轴。要么缩进收到 0（贴边不被裁靠上面那条 4:3 + `cover`），要么明确当图例、不追求对齐。
- **图内文字只在起指示作用时才写**：轴标签、刻度、单位、数值、图例、步骤名，判据是"不写这行字这张图就读不出来"。**标题不在其中**——卡片标题就是这张图的标题。
- **辉光开始参与配色**：透明后 `--seg-accent` 直接压在图区中心（竖屏 15%、横屏 13%），下笔前先看这段用什么 accent；次要文字跟着提亮一档。
- **局部底板照旧可画**，取消的只是"整幅满铺"。

**整页画布同一条，而且更吃紧**：别铺 `#0b1020` 这类满幅底板。SVG 留透明，模板那三层背景（见 `references/rendering.md`「画面结构」）就从内容背后透出来。确实要把整页换成另一种底色（浅色页、照片感场景）才自己画一张满幅 rect——那等于放弃这三层，`check_svg.py --layout canvas` 会 warn，有意为之就忽略。

### 图内文字的对比度：定色在前，自查在后

**SVG 以 `<img>` 载入，内部文字不属于 HTML 文本流，没有任何一道检查会量它**，所以取色表放在自查之前。

**想要一道真门禁：做一次性内联副本，别改产物。** 把 `<img src="images/x.svg">` 换成该 SVG 文件**内容**，对副本跑 `hyperframes check`。**副本只用来问门禁，绝不能当产物**——内联后是同源活 SVG、脚本照执行，交付的 `index.html` 必须保持 `<img>` 形态。**唯一例外**是写了 `director` 的那张：交付时就是内联活 DOM，但内联前必过 `scripts/_svg_sanitize.py` 净化（见 `references/directing.md`「SVG 动画：两档」）。

**判定线**（WCAG）：正文与标签 ≥ 4.5:1；图内最大字号档（≥24px，或 ≥18.66px 加粗）≥ 3:1，低于 3:1 重画；次要文字按 ≥ 7:1 取色。

**深色主题取色表**（底 = 页面渐变叠上该段 accent 辉光；**页底**列不叠辉光，**最坏**列是全部预置 accent × 渐变 stop × 竖屏 15%/横屏 13% 全组合的最低值）：

| 用途 | 取色 | 对比度 |
|---|---|---|
| 图内最大字号 | `#f2f6fc` | 页底 17.7–18.6，最坏 12.7 |
| 主标签 | `#dbe6f5` | 页底 15.2–16.0，最坏 10.9 |
| 次要说明下限 | `#a8bdd6` | 最坏 7.2，刚好守住 ≥7 |
| 不要用 | `#6b7c93` | 页底 4.5–4.7、最坏 3.2，两档都越线 |
| 背景深蓝族 | `#0c1320` `#16233a` `#1a2536` | 1.0–1.3:1，出现在 `fill` 上就是瞎字；不铺满幅底后它们只属于**局部底板** |

**三条最常踩的**：

- **深色文字只能待在明确的浅色底板上**。符号常写成近黑 `#0c1320` 摆到浅色渐变圆盘上（圆盘上 15.1:1）——圆盘一挪或换了渐变，这行字立刻瞎掉。改任何底板颜色都要复核压在它上面的文字；`fill` 能就近写死就别靠 `<g>` 继承。
- **背景色族不得当文字色**（深色主题下）：`check_svg.py` 的家族集 = "深蓝族 ∪ 当前主题渐变各档 stop"。
- **半透明按合成后的颜色算**：50% 的 `#dbe6f5` 叠在 `#0c1320` 上合成 `#747c8a`，只剩 4.4:1。要弱化文字就换更暗的实色。唯一例外是导演元素 `opacity="0"`——那是**起始态**（终帧才亮），`0.1~0.79` 中间档照报。

**机械能查到的边界**：`check_svg.py` 对字面 hex 填充按**主题渐变最坏一档**算一次 WCAG 对比度。槽位版式低于 3:1 判 error、低于 4.5:1 判 warn，背景族当文字色直接 error；**整页画布只 warn**。渐变底、`class` 里的色、局部底板上的字一概管不到。

### 整页画布（段落 `layout: "canvas"`，结构性页用顶层 `opening_layout` / `closing_layout`）：这一张 SVG 就是整个画面

**什么时候换整页**（选型判据只写在这一节）：

- **内容装不下 4:3 槽位**：数据关系、长时序、多层系统图——硬塞的结果是把字号压到 26px 下限以下。
- **这一页本身就该是一张海报**：章首、转折、结论、金句。
- **这一段只需要画面**：过场、留白、真实场景照片。
- **节奏：主动穿插**。内容段 ≥5 段给 2–3 段换画布，段数少就 1 段，位置挑章首或转折。**两条边界**：别连着两段都用；旁白最密、最需要逐句跟读的那段**别换**（画布连句子流 DOM 都不生成）。
- **开屏/结尾也可以整页**：顶层写 `opening_layout`/`closing_layout: "canvas"`。代价：投影卡整个不上画面——章节列表、要点总结、`cta` 尾行都没了，全得画进图里。

**什么时候别换**：该段口播要靠字幕跟读（画布不生成句子流层，也没有"页底句子流"兜底）；不想自己把标题画进 SVG；一期要出两个画幅却只打算画一张 SVG。

字段语义见 `references/writing.md` 段落 `layout`；版式与门禁变化见 `references/rendering.md`「画面结构」。这张 SVG 只有六条和槽位版式不同：

- **几何换成整个画幅**：竖屏 `width="1080" height="1440" viewBox="0 0 1080 1440"`，横屏 `1920×1080`。两画幅都要出片就**各画一张**（生成期按文件验：根标签读不出纯数字 `width/height` 或 `viewBox`、或比例与画幅不等比，直接 exit 1）。
- **按画幅原尺寸画，别靠放大画布凑**：成片把 SVG 按 `画幅宽 ÷ SVG 宽` 整体缩放。按 2560×1440 画的 16:9 塞进 1920 画幅，28px 折算只剩 21px——跌破 26px 下限就是读不出来。字号写成 px 才能验；写成 `em`/`%`/class 时只有图真在被缩小（SVG 宽 > 画幅宽）才打 `[warn]`。
- **安全边距照页面走**：竖屏四周留 50px、横屏留 96px，图内文字越界就是出血。`text-anchor="end"` 的落点按量出来的字宽倒推，不按字符数估（量法见「数据图的几何自查」）。
- **"不铺满幅底"在这里更要紧**：留透明才能透出模板那三层背景；例外与 warn 口径见上面「不铺满幅底」。
- **图内可以有标题，字号按整页读**：标题 72–76px、小标题 38–48px、正文 30–40px、kicker/图例 26–28px。字号越大越要自己复查对比度——**这一版的 `Contrast` 门禁数不到你**。字体名写死（`'Microsoft YaHei','PingFang SC',…`）：`<img>` 载入读不到页面 `--ctv-font-*` 变量。生成期那条 `[warn]`（"该段 N 句旁白不会上画面 / 这张 SVG 里有 M 个 `<text>`"）是要点有没有画进图里唯一的机械判据。
- **机械劳动交给脚手架**：`python scripts/canvas_kit.py --spec spec.json --aspect portrait -o images/seg1.svg` 吐一张按画幅原生尺寸画的透明底画布 + 一份能塞进 images.json `director` 的 steps 草稿（`--emit-steps` 另存）。`-o` 与 `--emit-steps` 落在技能目录内会被守卫拦下，先 `cd` 到项目目录再跑。

    **一份能照抄的完整例子**（竖屏柱状图）。spec 顶层是 `{"aspect"?, "theme"?, "accent"?, "elements": [...]}`：

    ```json
    {
      "aspect": "portrait",
      "elements": [
        {"kind": "panel", "id": "panel", "x": 80, "y": 300, "w": 920, "h": 700},
        {"kind": "text",  "id": "t",    "x": 80, "y": 200, "content": "季度营收", "tier": "title"},
        {"kind": "axis",  "id": "ax",   "orient": "y", "at": 940, "from": 400, "to": 940,
         "ticks": [{"v": 400, "label": "8"}, {"v": 670, "label": "4"}, {"v": 940, "label": "0"}]},
        {"kind": "bars",  "id": "bars", "base_y": 940,
         "bars": [{"x": 160, "w": 120, "h": 210, "label": "Q1"},
                  {"x": 320, "w": 120, "h": 350, "label": "Q2"},
                  {"x": 480, "w": 120, "h": 280, "label": "Q3"},
                  {"x": 640, "w": 120, "h": 560, "label": "Q4"},
                  {"x": 800, "w": 120, "h": 420, "label": "Q5"}]},
        {"kind": "text",  "id": "lab",  "x": 500, "y": 1010, "content": "Q1–Q5", "tier": "label"}
      ]
    }
    ```

    `--help` 尾部印同一份例子，另有七种 kind 各一条最小可跑片段。**键集不必背**：写错时脚本报错当场列出该 kind 的合法键与必填键。

    动笔前要知道两件报错替代不了的事：**`axis` 的 `from`/`to` 是轴两端的像素坐标、不是起止数据值**（竖轴把较大的 y 写在 `from`、数值就朝上长；`at` 是那条轴所在的像素线），以及 **`tier` 只有三档**（画布档要更大的字就手写 SVG 绕过脚手架）。

    **它收走的只是机械部分**：画布几何、三档字号、线宽、取色压暗、初始 `opacity` 分档（`draw`/`count`/`type` 那三种**不会**被写 `opacity="0"`，写了就永远不亮）。公共旋钮 `duration`/`ease`/`stagger`/`repeat`/`yoyo` 都能写进元素（`repeat`/`yoyo` 只挂内容元素，`yoyo` 必须带 `repeat`）。**构图仍归人**——所有坐标由 spec 给。

    草稿的节拍只用 `at`（句序）不用 `at_time`。产物生成后按 `check_svg` 的 canvas 口径自查一遍。

**给上 `--sentences <该段句数>`，草稿才是真能直接用的那份**。不给时自动拍按元素顺序一路 `at=0,1,2…`，内容元素比旁白句子多时最后几拍落到句序之外，生成期按 `error` 整条拒掉（"at=N 越界：该段只有 M 句旁白"）。给了句数，游标按它取模回绕；**显式钉拍**（元素里写 `beat`）的越界提前打 `[warn]`。`--emit-steps <path>` 另存的草稿是 `{"steps": [ … ]}`，直接 `"director": {"steps": <这份数组>}`。

照片当画布**不做比例与字号校验**，但配一张照片就等于该段整段时间屏幕上不出现任何标题——生成期照样给一条 `[warn]`。想留标题就把要点画成 SVG；确实要"只有画面"的过场，忽略它就行。

### 整页画布的密度与层次：这一页经得起暂停吗

判据不是"画了多少个元素"，是**随便暂停一帧，画面还成不成立**。用 `npx -y hyperframes snapshot --at <秒>` 截出来看。

- **竖向不许有整条空带**（`check_svg.py --layout canvas` 会 warn，阈值 25% 页高）：标题在上 1/4、主视觉占中部并**撑到接近页宽**、注脚与结论压在下 1/4，三段之间用中景元素连起来。
- **一页至少三层**：背景层（模板那三层，别铺满幅底盖掉）、中景（主视觉 + 局部底板/面板/分隔带做明度层级）、前景（标注文字、数值、accent 强调）。中景自己也有"面板 < 底板 < 页底"三档明度。
- **主视觉要有尺寸下限**：占页宽 ≥70%、占页高 ≥45%。
- **辅助线要敢用亮档**：轴线、网格、分隔线在 dark 页底上不要低于 `#64748b` 一档，线宽 ≥3px。层次靠**明度差与大小差**做，不靠透明度。
- **字号最多三档 + 一档 accent**（脚手架三档竖屏 64/40/32、横屏 62/33/28；整页画布照实测量级：标题 72–76 / 小标题 38–48 / 正文 30–40 / 标注 26–28）：最大档与最小档比值 ≥2。一个 accent 负责"现在看这里"，其余走中性灰阶。
- **数信息单元**：一页有几个独立可看的东西（一块图、一行结论、一组标注各算一个）？**少于 3 个就别当整页画布做**——那它本质是字卡，按海报重写，或退回槽位版式。
- **导演页还要看"起始帧"**：前 1 秒画面是空的，而整页画布**没有转场遮这一下**（见 `references/rendering.md`「动画」）。只要不铺满幅底，第一帧至少不是死平一块色；把**结构底**（坐标轴、外框、分隔带、面板格子）不写进 `director.steps`，让它和页面同时到位、只逐拍长"内容"，或把第一拍放在 `at_time` 0.1s。

### 数据图的几何自查

手绘数据图（柱状、折线、饼环、散点、时间轴）里**长度/角度/坐标本身就是数据**，而这条错误链上没有任何检查看得到：

- **先定标尺，再画图形**：把映射写成一行线性式（`y = y0 - (v - vmin) * (h / (vmax - vmin))`）放进 SVG 注释，所有柱高/点位由它反算，不凭手感逐个调。刻度取整档（1/2/5×10ⁿ），别为了对齐图形改数据。
- **用两端点回算验证每一档**：最大值柱顶减最小值柱顶应等于"量程 × 标尺"，对不上是映射写错。**pie / 环形先查总和**：各扇区角度相加必须等于 360（`占比 × 3.6`）。
- **量文字，不数文字**：定宽元素（刻度、数值标签、图例）按实测宽度排版——`text-anchor="end"` 的落点倒推字宽。两条量法：浏览器 `getBBox()` 读左右缘，或 `npx -y hyperframes snapshot` 按时刻截一帧（命令见 `references/rendering.md`「官方校验命令」）。整页画布安全边距（竖屏 50px / 横屏 96px）同样按量出来的右缘判。
- **公式就是图内文字**：`E = mc^2` 这类本体用 `<text>` 画——上下标靠 `baseline-shift` 或两个 `<tspan dy>`，字体栈照「文字与尺寸」，下标字号同样受 26px 下限约束。

数据与公式的**内容**红线见「方式 C」那条三行。

### 文字与尺寸

图内文字按"**进入内容画布后**的最终可读性"设计，不是按原始文件尺寸设计。

图内只有起指示作用的文字，**没有"标题"这一档**（见本文件「不铺满幅底」）；最大一档 35–40px 给图例名或底板大字，正文级从 35px 起步（槽位按 980×735、整页画布按当前画幅原生尺寸）；内容很密就优先减少文字、扩大图形。**26px 是下限**：再小就读不出来了——宁可换行或加长底板，也别缩字号。

底板内还要**估一次宽度**：一行汉字数 ≈（容器宽 − 左右内边距）÷ 字号。980 画布留 48px 内边距、52px 字号 → 一行约 17 个汉字。溢出时换行或加宽底板。

SVG 以 `<img>` 载入时是独立文档，页面 `--ctv-font-family` 渗不进去，`<style>` 里要自带中文无衬线字体栈（如 `"Microsoft YaHei", "PingFang SC", "Noto Sans SC", "Noto Sans CJK SC", "Noto Sans CJK JP", sans-serif`——Linux 沙箱里 `Noto Sans SC` 会回落到无 CJK 字形的 NotoSans-Regular，`Noto Sans CJK SC/JP` 才是能匹配上的名字，别省）。
