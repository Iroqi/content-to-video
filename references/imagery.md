# 第 4 步 · 素材：选哪条路线 + 怎么落盘

本文件答第 4 步的两个问题：**观众应该看到什么**（选哪条路线）、**素材从哪里来**（检索照片 / 生图 / 手绘 SVG / 现成视频）。"这一页要不要交给导演演"在写稿那一步答完（见 `references/writing.md`「哪些段值得交给 canvas」）；手绘 SVG 与导演编排在 `references/canvas.md`，本文件不复述。

## 三条路线的统一规则

### 1. 先选“表现方式”，再选素材来源

| 内容特征 | 首选方式 | 原因 |
|---|---|---|
| 有明确真实人物、产品、地点、事件、新闻现场 | **位图·检索照片** | 真实实体要真实影像，避免生成图替代事实 |
| 画面里**不需要出现可读文字**：抽象概念、原理、氛围、场景 | **位图·生图** | 一句 prompt 出一版，风格易统一 |
| 画面里**必须有准确文字/数字**，或必须精确矢量几何、严谨数据 | **C SVG 矢量示意** | 信息准确性只能自己画，生图文字不可信 |
| **运动本身携带信息**：真实过程、逐步演进、场景变化 | **视频** | SVG 画不出真连续；`stage:"keep"` 只能接静帧 |

**位图与 C 的分界线只有一条：图内要不要文字。** 要（标签、步骤名、数值、图例、公式）→ C；不要 → 选位图，哪怕内容复杂。手绘 SVG 返工率高（构图、对比度、文字宽度全靠人肉自查），生图**文字崩率高**，所以它只接不带文字的活。

**视频与位图的分工别搞反**：位图是一帧，视频是段时间。同一件事能画成静帧（SVG + `draw`/`count` 逐拍演）就优先画——它逐帧可复现、能对上旁白的某一秒；只有"过程本身"是信息（真实物理过程、镜头运动、场景变换）才用视频，代价是走页面墙钟、同秒抓帧不保证一致（见「视频素材」）。

数据图和公式归到 C：**坐标刻度、柱长比例、扇区角度全自己算自己标，没有任何一道门禁替你检查几何**。何时从 4:3 槽位换整页画布见 `canvas.md`「整页画布」。

按**信息结构**定形式：

| 信息结构 | 首选形式 | 路线 |
|---|---|---|
| 数值比较 / 占比 / 趋势 / 双变量关系 | bar / pie / line / scatter | C (SVG) |
| 时间演进（要标年份） | 时间线 | C (SVG) |
| 步骤 / 机制流程（要标步骤名） | 流程图 | C (SVG) |
| 层级 / 关系 / 系统结构（要标节点名） | 树状图 / 网络图 / 架构图 | C (SVG) |
| 几何 / 空间关系，**不带文字** | 生图（isometric / 3D 风格词） | **位图** |
| 外观、场景、氛围 | 图片 | 位图（检索 or 生图） |
| 真实过程、镜头运动、场景变化 | 短视频 | 视频 |

同一张图能不说清楚就不写文字，降级交给生图（省一次重画、免掉图内文字对比度自查）。图只承担**增量信息**：标题和 verse 已说清时不画，不为"高级感"堆 3D / 仪表盘 / 拼贴。

### 2. 统一使用同一个内容画布

- 内容画布：竖屏 980×735，横屏右侧槽位 1067×800（4:3 按整数像素取整）。
- 配图规格两条：**按 4:3 出图**、**像素要够铺满**。`cover` 只保证填满、**不保证清楚**——放大超过 1.25 倍（`_media_size.UPSCALE_WARN`）打 `[warn]` 点名哪段、素材多大、要放大几倍；超过 2.0 倍（`UPSCALE_SEVERE`）直说细节基本没了。**别把这条 warn 当噪音**：它是"这一段成片是不是糊的"唯一的机器证据。位图按最接近 4:3 的档位出；**SVG 不验尺寸**（矢量放大不失真）。
- 视频按 4:3 出片最省事（同样走 `cover`），但**成片只显示前段**，比段落长的视频会被截断（生成期 `[warn]` 报实测时长 vs 段落时长，见「视频素材」）。
- **整页画布（`layout:"canvas"`）是唯一例外**：铺整个画面（1080×1440 / 1920×1080），尺寸对账按整幅算（规格见 `canvas.md`「整页画布」）。

### 3. 统一的质量标准

无论来源，都审五条：**内容准确**（对应本段在讲的对象，不接受"气氛类似但事情不对"）、**主体明确**（第一眼看出主角，不塞无关元素）、**可读可看**（图内文字在成片观看尺寸下清楚；位图/视频像素要够铺满，不够就是糊的，没有任何门禁替你说）、**风格统一**（混用位图/SVG/视频可，统一背景明暗、主体尺度、主色与视觉密度）、**来源可追溯**（检索照片留 provenance，生图/SVG/视频记录生成工具与来源）。

### 4. 统一的制作流程

每段同一条链：选路线 → 得到媒体文件 → 落 `images/` 并写 `images.json` → **人工审关键帧**（主体、构图、文字可读性、与旁白关系）。最后一步不因方式不同省略。

### 5. images.json 是唯一统一入口

三种路线最终都映射到同一份 `images.json`：

```json
{
  "seg1": {"src": "images/seg1.png"},
  "seg2": {"src": "images/seg2.jpg"},
  "seg3": {"src": "images/seg3.mp4", "type": "video", "poster": "images/seg3-cover.png"}
}
```

字段（封闭键集，写清单外的键不生效且 `_normalize_images` 打 `[warn]` 点名；裸字符串路径 `{"seg1": "images/seg1.png"}` 直接报错）：

- `src`：必填，相对 HTML 输出目录的媒体路径。
- `type`：可选，`auto`/`image`/`video`/`gif`，缺省 `auto`（按扩展名判：`.mp4/.webm/.mov/.avi/.mkv`→video，`.gif`→gif，其余→image）。
- `loop`/`muted`/`autoplay`/`playsinline`：可选，视频播放属性，默认均 `true`。**必须写 JSON 布尔**——字符串 `"false"` 被拒（渲染端 `opts.get(flag, True)` 把字符串当真值，"关掉循环"会变"永远循环"）。
- `volume`/`duck`/`fade_in`/`fade_out`/`media_start`：可选，**仅视频**的音轨旋钮（口径见「视频素材」）。
- `poster`：可选，视频封面，与 `src` 同校验口径（禁绝对路径、禁越出项目根）。
- `director`：可选，**仅 `.svg`**，导演档编排块（见 `directing.md`「SVG 动画：两档」）。写了才净化内联、由 GSAP 逐句驱动；不写就是普通 `<img>` 静态图。
- `stage`：可选，**仅 `.svg`**，只认 `"keep"`——跨段接续（见 `directing.md`「跨段接续」）。
- `provider`/`source_url`/`license`/`attribution`/`query`：可选，素材来源记账；二次整理保留旧值不要覆盖，画面不读。

## 位图素材：检索照片 / 生图

位图是一张静帧，落盘后两条来源走完全相同的一条路（4:3 规格 + `images.json` 映射），所以并在一节讲。

### 检索流程

1. 从段落标题和正文提炼检索词；中文实体尽量加英文别名或型号。
2. 检索来源页，不要只看缩略图；**逐张打开原图**，确认不是标题党、截图、带角标或无关图。
3. 下载到 `images/`，命名 `<sid>.<ext>`，写映射并保留 provenance。

### 生图规格与 prompt

每段一张**横版 4:3** 图，尺寸选所用能力最接近 4:3 的档位（如 1152×864）；同一批保持同一背景明暗与风格词。Prompt 先写"讲什么"再写"怎么画"（主体/场景 → 核心动作或结构 → 视觉关系 → 风格 → 背景与色调）。`diagram / chart / schematic / infographic` 这类词会把轴标签和文字带进来，末尾补 `no text, no labels, no letters, no numbers`。出图后**逐张看有没有崩字**——生图文字崩率高（错字、缺笔、乱码），崩在图里的字改不动。

### 选图标准（两条来源共用）

- 主体与段落讲的是同一个人、产品、地点或事件。
- 长边低于约 1200px 时进成片容易发虚。
- **入库前裁成 4:3**，保留哪块主体由看图的人判断。

### 透明通道：位图也能直接贴背景（无需抠图）

带 alpha 的**透明 PNG / WEBP** 与 SVG 等价：渲染端把它当 `<img>` 放进同一张场景图，透明处透出主题渐变与 `--seg-accent` 辉光，不必抠图。边界：

- **透明只在「同一 scene 内」成立**：`hyperframes render` 一次性把背景+前景渲成帧，不存在"透明 PNG 叠另一段渲染好的背景视频"这种 ffmpeg overlay 流程。
- **透明由出图端保证，契约层不校验像素**：前景被填了不透明底色就会盖死画布（信源问题）。看到前景盖背景，回去查出图端有没有填底色。

## 视频素材：VideoGen / 现成视频

| 来源 | 获取方式 | `images.json` |
|---|---|---|
| AI 视频 | 当前环境任一可用的视频生成能力 | `{"src":"images/seg3.mp4","type":"video"}` |
| 现成视频 | 自有或已生成的 mp4/webm/mov | 同上 |
| GIF | 已有 GIF（走 `<img>`，与位图同档） | `{"src":"images/seg3.gif"}` |

### 播放规则

视频默认 `loop muted autoplay playsinline`，四开关都能在 `images.json` 显式关掉（布尔坑见字段一节）。GIF 用自身循环，不受这些开关影响。**封面用 `poster` 提供**，避免首帧空白（与 `src` 同校验口径）。

### 音轨：要原声就一定要写 data-has-audio

视频是**唯一不经过第 3 步 TTS、却照样混进成片**的声音。混音只读两类源：`<audio>` 元素，和**声明了 `data-has-audio="true"` 的 `<video>`**。

关掉 `muted`（＝我要原声）时渲染端**自动**补 `data-has-audio="true"`——不该由人记这个属性名：漏了它等于一条都不混，成片有画面没原声，而全流程零报错。反过来，**静音时绝不能写它**（契约二选一，两个都挂会让 lint 判据失效）。

代价：原声和口播抢同一段频谱，默认处置见下。

#### 让路：默认那一版必须是不盖旁白的那一版

关掉 `muted` 时的默认处置是**脚本替他落一个让路默认**：

- **没写 `volume`** → 渲染端落 `data-volume="0.25"`（实测可听档下沿）并打 `[warn]` 点名这一段、说清压成多少、怎么改回去。**1.0 不是默认**——等响默认 = 默认交付没法听的片子。
- **另开一条让路 EQ**（`data-fx-chain`，默认开）：只压整轨响度会把环境声、音乐、现场厚度一起拧小，所以再在人声占住的频段（1.6k / 2.5k / 4k Hz，−3/−3/−2 dB）开窄带槽，床铺其余部分保持原样。
- **要原声当主体**（采访原声、现场同期声）就显式写 `volume: 1.0` **并**给 `duck: false`：前者收回响度，后者撤掉 EQ。缺一个都还是被压着的。

#### 四个音轨旋钮

四个旋钮 + `duck` **只对 video 成立**（位图 / SVG / GIF 写了会被契约层拒）：

| `images.json` | 落到标签 | 说明 |
|---|---|---|
| `volume` | `data-volume` | 增益倍数，1 = 0 dB。不写时由渲染端落让路默认 0.25 |
| `duck` | `data-fx-chain` | 人声频段让路 EQ；`false` = 撤掉（原声当主体时用） |
| `fade_in` | `data-fade-in` | 淡入，锚片段自己的入点 |
| `fade_out` | `data-fade-out` | 淡出，锚片段自己的出点 |
| `media_start` | `data-media-start` | 从源片第几秒起播（trim） |

取值范围不必查：写错时报错自带范围与含义。两条手拼属性要记住：**`media_start` 只能叫 `data-media-start`**（写成 `data-playback-start` 会渲染出"裁过的画面配没裁过的声音"）；**`data-fx-chain` 里的 JSON 引号必须写 `&quot;`**（裸双引号截断整条属性，渲染器已转义，别手拼）。
